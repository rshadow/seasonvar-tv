# Seasonvar для Android TV

Клиент оригинального [seasonvar.ru](https://seasonvar.ru/) для телевизора и Android-приставки. Целевое устройство для проверки — Ugoos X5M с Android 14.

Приложение должно давать доступ к сериалам и своей учётной записи Seasonvar через интерфейс, которым удобно управлять обычным пультом.

## Планируемые возможности

- Вход в свой аккаунт Seasonvar и сохранение сессии.
- Выбор сезона, озвучки и серии с переходом к просмотру.
- Личные списки сайта: «На чём остановились», «Хочу посмотреть», «Посмотрел», обновления.
- Воспроизведение видео с Seasonvar с паузой, перемоткой и продолжением просмотра.
- Чтение и сохранение отметок просмотра в аккаунте сайта.
- Полная навигация стрелками, OK и «Назад», без обязательного сенсорного ввода.

Реализованы «Сегодня», «Обновления», «Топ», «Новинки» и «Лучшие сериалы» с постерами и описаниями, бейдж «новинка» по метке сайта в AJAX-подборках, «Настройки» с группой «Сеть» и «О программе». В «О программе» есть кнопка и адрес проекта на GitHub — [ADR-0052](docs/adr/0052-about-github-link.md). Работают текстовый поиск и системный голосовой ввод. Карточка сериала показывает полное описание и состав без обрезания на общей прокручиваемой странице, рейтинги IMDb/КиноПоиска при наличии, сезоны, переводы и серии; «Все серии» открывает сетку при наличии больше 12 эпизодов выбранного перевода — [ADR-0030](docs/adr/0030-all-episodes-threshold.md). «Смотреть» и нажатие на серию открывают встроенный Media3-плеер с паузой, перемоткой и локальным продолжением — [ADR-0031](docs/adr/0031-native-playback.md). Работают форма входа, сохранение сессии, выход и шесть личных разделов: «На чём остановились», «Есть обновления», «Нет новых серий», «Хочу посмотреть», «Посмотрел», «История просмотров» — [ADR-0033](docs/adr/0033-account-and-resume.md). Прогресс вошедшего пользователя автоматически сохраняется в аккаунте раз в минуту, на паузе, при выходе и смене серии. После минимум 30 секунд реального воспроизведения достижение 90% отмечает серию просмотренной; неотправленная позиция остаётся в очереди для своего аккаунта — [ADR-0056](docs/adr/0056-automatic-account-playback-marks.md). Удаление отметки сезона доступно через удержание OK в личной ленте и кнопку в полной карточке, с общим подтверждением — [ADR-0057](docs/adr/0057-remove-account-list-marks.md). Точное продолжение по времени в карточке пока использует локальную позицию. При открытии карточки известные сезон, серия и озвучка из записи имеют приоритет перед локальным продолжением — [ADR-0040](docs/adr/0040-details-entry-context.md). Если указанная озвучка не найдена, выбирается стандартная — [ADR-0042](docs/adr/0042-standard-translation-fallback.md). Парсеры заранее заполняют единую частичную модель `SeriesEntry` в [CatalogModels.kt](app/src/main/java/ru/seasonvar/tv/data/CatalogModels.kt), включая `initialSelection`; неизвестные поля остаются пустыми — [ADR-0041](docs/adr/0041-shared-catalog-entry.md).

Если сайт сообщает об ограничении просмотра, карточка показывает причину. При отсутствии доступной серии вместо «Смотреть» есть «Обновить данные» с новым запросом страницы — [ADR-0032](docs/adr/0032-unavailable-playback.md).

В плеере доступны предыдущая и следующая серия той же озвучки: вверх открывает выбор кнопок панели, вниз возвращает управление видео. После выхода в карточке выбирается последняя серия плеера — [ADR-0046](docs/adr/0046-player-episode-navigation.md).

В настройках пункт «При запуске» позволяет выбрать раздел, который открывается первым; выбор сохраняется на устройстве — [ADR-0045](docs/adr/0045-start-page-setting.md).

Левое меню разделено подписями «Каталог», «Мои списки» (после входа) и «Система». Заголовки не получают фокус; переходы между пунктами сохраняют прежнее управление — [ADR-0044](docs/adr/0044-visual-menu-groups.md).

Рядом с поиском находится кнопка человека: она открывает логин и пароль с системной клавиатурой. После подтверждения входа кнопка показывает аватар при наличии, в меню появляются все шесть личных разделов — [ADR-0036](docs/adr/0036-personal-lists.md). Пароль не сохраняется; сессия шифруется Android Keystore. Личные списки хранятся только в памяти и очищаются при выходе. У каждого раздела своя позиция ленты и выбранная карточка. «История просмотров» читает историю сайта, показывает сезон и серию на миниатюрах, дату в большой карточке и подгружает следующие страницы — [ADR-0039](docs/adr/0039-account-viewing-history.md). Прогресс и сообщение сайта показаны одной строкой над лентой; в открытой карточке прогресс находится рядом с управлением просмотром — [ADR-0043](docs/adr/0043-account-progress-in-controls.md). В конце строки управления показываются сезон отметки из общего количества сезонов и отмеченные серии из общего числа серий выбранного сезона. Прогресс уточняется в фоне. Миниатюры личных списков содержат название и сезон, а в истории также номер серии — [ADR-0038](docs/adr/0038-compact-account-marks.md).

Метаданные располагаются рядом с постером, затем идут управление и серии; полное описание находится внизу на всю ширину. Фокус получают только действия — [ADR-0029](docs/adr/0029-series-controls-before-description.md).

## Локальный запуск

На подготовленном компьютере открыть эмулятор:

~~~bash
make emulator
~~~

После загрузки Android TV во втором терминале:

~~~bash
make run
~~~

Управление — Enter/OK и клики мышью по кнопкам. В меню стрелки сразу показывают выбранный раздел; OK или стрелка вправо переводят фокус в его содержимое. В ленте стрелки перемещают фокус и прокручивают список. OK открывает карточку выбранного сериала. Esc и «Назад» пульта закрывают карточку сериала и возвращают фокус на выбранную карточку в ленте. В карточке фокус начинается на «Смотреть». Вверх из строки действий листает верхние сведения; при 1–12 сериях вниз с выбранной серии сразу прокручивает описание, вверх возвращает к ленте и затем к управлению. При 13 и более сериях вниз выбирает «Все серии», следующие нажатия вниз читают описание; вверх возвращает к кнопке и выбранной серии. Из ленты или настроек они возвращают фокус в меню текущего раздела. Два быстрых нажатия (до 500 мс) закрывают приложение. Раздел можно сменить через постоянно видимое меню; стрелка влево из настроек переводит фокус в меню.

В плеере OK/Enter/пробел переключает паузу, влево/вправо перематывают на 10 секунд. Esc/«Назад» возвращает в карточку на прежний элемент. Позиция сохраняется на устройстве; повторный запуск этой серии продолжает просмотр. Автоматического перехода к следующей серии пока нет.

Для первого запуска на другом компьютере: Python 3.12+, make и curl, затем `make bootstrap`, `make licenses`, `make deps` и `make avd`. Все команды подготовки, сборки, проверки и отладки собраны в [Makefile](Makefile); подробности — в [docs/development.md](docs/development.md).

## APK и автосборка

[GitHub Actions](https://github.com/rshadow/seasonvar-tv/actions/workflows/android.yml) проверяет каждый push в `main` и pull request. В артефактах запуска доступен debug APK, а для `main` и ручных запусков также подписанный APK с SHA256.

Подписанный файл называется `seasonvar-tv-<versionName>-universal.apk`: один APK для `armeabi-v7a`, `arm64-v8a`, `x86` и `x86_64` — [ADR-0051](docs/adr/0051-universal-apk-filename.md).

Теги `v<versionName>` дополнительно создают [GitHub Release](https://github.com/rshadow/seasonvar-tv/releases) с установочным APK. Подробности — [ADR-0050](docs/adr/0050-github-actions-builds-and-releases.md) и [руководство по выпуску](docs/development.md#автосборка-и-выпуск-на-github).

## Текущее состояние

Собрано [описание API и запросов сайта](docs/api/README.md). В нём раздельно отмечены сведения из исходников, проверки сети и реальные ответы пользователя.

По кнопке с лупой в левом верхнем углу открывается поиск с системной Android-клавиатурой и кнопкой голосового ввода слева от поля. Результаты показываются в общей ленте с описаниями. Голосовой ввод запускает системный обработчик распознавания, если он установлен — [ADR-0024](docs/adr/0024-search-and-system-input.md).

Пользователь подтвердил поисковый запрос сайта в браузере; [пример ответа](docs/api/examples/autocomplete-game-of-thrones.json) содержит 14 результатов. Вход, аватар, личный список и восстановление сессии проверены на Ugoos. Сохранение прогресса аккаунта проверено через POST и повторное чтение на эмуляторе; исходная отметка тестового запроса восстановлена. Анонимный MP4 и локальная позиция воспроизводятся в эмуляторе.

Старый `api.seasonvar.ru` не разрешается через Quad9. Клиент получает публичный HTML оригинального сайта и JSON поиска. «Обновления», «Топ» и «Новинки» загружаются отдельными AJAX POST, без предварительного запроса главной; «Сегодня» берётся из главной, «Лучшие сериалы» — из отдельной страницы `/?mode=top`. На экране «Настройки» под подзаголовком «Сеть» независимо выбираются обход блокировок и DNS («Системный» / «Quad9 DoH»). По умолчанию обход включён, DNS — Quad9 DoH. Обход использует TCP/TLS-алгоритм из [локального загрузчика](docs/api/access.md). При его выключении остаётся выбранный DNS. Настройки сохраняются и применяются к новым запросам страниц, постеров и видео; проверка HTTPS-сертификата работает в обоих режимах.

## Разработка

Для оценки отзывчивости на приставке использовать `make run-profile DEVICE=<serial>` после `make devices`: это оптимизированная сборка с R8 и возможностью профилирования. Обычный `make run` ставит debug-сборку. Карточки появляются по кадрам, чтобы меню оставалось доступным — [ADR-0025](docs/adr/0025-responsive-section-switching.md).

Кнопки прямоугольные с небольшим скруглением; компактное левое меню прокручивается при нехватке места — [ADR-0023](docs/adr/0023-compact-rectangular-menu.md).

Карточки ленты имеют фиксированный размер и показывают русское название, а при его отсутствии — оригинальное. Правило — [ADR-0019](docs/adr/0019-fixed-series-cards.md).

Цвета, отступы и размеры кнопок настраиваются в [themes.xml](app/src/main/res/values/themes.xml), подключение к Compose и типографика — в [SeasonvarTheme.kt](app/src/main/java/ru/seasonvar/tv/ui/theme/SeasonvarTheme.kt). Палитра взята из CSS оригинального сайта; правила и источники — [ADR-0008](docs/adr/0008-centralized-ui-theme.md).

Раздел «Лучшие сериалы» сохраняет выдачу отдельной страницы сайта, краткие описания и число сезонов — [ADR-0022](docs/adr/0022-best-series-page.md).

Раздел «Новинки» получает отдельную AJAX-подборку `mode=newest` с теми же карточками и независимым состоянием — [ADR-0021](docs/adr/0021-newest-via-ajax.md).

Раздел «Топ» получает серверную подборку через AJAX `mode=pop` с отдельным кэшем и состоянием ленты — [ADR-0020](docs/adr/0020-top-via-ajax.md).

Правила сегодняшней ленты — [ADR-0010](docs/adr/0010-today-feed.md), подборки «Обновления» — [ADR-0016](docs/adr/0016-updates-feed.md) и [ADR-0017](docs/adr/0017-updates-via-ajax.md), галочки обхода — [ADR-0011](docs/adr/0011-network-bypass-setting.md), выбора DNS — [ADR-0012](docs/adr/0012-dns-provider-setting.md).

Принят нативный стек **Kotlin + Compose for TV + Media3 ExoPlayer** — [ADR-0002](docs/adr/0002-native-kotlin-compose-media3.md).

[ADR-0003](docs/adr/0003-performance-principles.md) закрепляет показ каталога из кэша с обновлением в фоне, кеширование постеров под размер карточек, фоновую обработку данных, ленивые списки, восстановление фокуса и позиции, управление ресурсами плеера и измерения release-сборки на Ugoos.

Media3 1.11.1 получает временный MP4 из свежего плейлиста оригинальной страницы. Ссылки не сохраняются в кэше или истории; локальная позиция содержит только идентификаторы и время.

Локальная сборка, запуск и управление прототипом проверены в эмуляторе Android TV API 34 на macOS Apple Silicon. Проверены загрузка сегодняшней ленты, описаний и постеров, переключение сети и сохранение настройки после перезапуска. На 2026-11-02 раздел «Обновления» показывает 50 позиций боковой подборки сайта; отдельные озвучки одного сезона сохраняются. Проверки: `make check` — 284 JVM-теста, 22 теста Python и Lint без ошибок. Карточка по [ADR-0029](docs/adr/0029-series-controls-before-description.md) проверена в эмуляторе: сведения сверху, описание на всю ширину внизу, фокус только на действиях, переход к «Все серии» из середины списка и возврат после чтения. В эмуляторе также проверены реальное видео, пауза, перемотка и локальное продолжение. На Ugoos также воспроизведён и исправлен HTTP 404 из-за обрезания имени видео на скобке или запятой; для явно ограниченного сезона показывается причина сайта.

Пароли, API-ключи и cookie в репозиторий не добавляются. Секреты Seasonvar, включая ключ и пароли подписи Android, хранятся в корневом `secrets.env`, исключённом из Git, согласно [ADR-0049](docs/adr/0049-project-local-secrets.md). Другие секреты локальных инструментов берутся из `~/secrets.env`. Значения не выводятся. Подписанный APK собирается командой `make release`: `app/build/outputs/apk/release/app-release.apk`, см. [ADR-0048](docs/adr/0048-release-apk-signing.md).

## Безопасность GitHub

CodeQL проверяет Kotlin/Java, Python и workflow; Gradle dependency graph и Dependency review проверяют зависимости, Dependabot готовит еженедельные PR обновлений. Серверные переключатели защиты секретов и импорт правил main/релизных тегов выполняет владелец по [инструкции](docs/github-security.md). Конфигурация принята в [ADR-0058](docs/adr/0058-github-security-checks.md); наличие файлов не означает, что правила уже активированы на GitHub.
