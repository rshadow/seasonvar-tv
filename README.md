# Seasonvar для Android TV

Клиент оригинального [seasonvar.ru](https://seasonvar.ru/) для телевизора и Android-приставки. Целевое устройство для проверки — Ugoos X5M с Android 14.

Приложение должно давать доступ к сериалам и своей учётной записи Seasonvar через интерфейс, которым удобно управлять обычным пультом.

## Планируемые возможности

- Вход в свой аккаунт Seasonvar и сохранение сессии.
- Каталог, поиск, карточки сериалов, выбор сезона, озвучки и серии.
- Личные списки сайта: «На чём остановились», «Хочу посмотреть», «Посмотрел», обновления.
- Воспроизведение видео с Seasonvar с паузой, перемоткой и продолжением просмотра.
- Чтение и сохранение отметок просмотра в аккаунте сайта.
- Полная навигация стрелками, OK и «Назад», без обязательного сенсорного ввода.

Это план функций; реализованного приложения пока нет.

## Текущее состояние

Собрано [описание API и запросов сайта](docs/api/README.md). В нём раздельно отмечены сведения из исходников, проверки сети и реальные ответы пользователя.

Пользователь подтвердил поисковый запрос сайта в браузере; [пример ответа](docs/api/examples/autocomplete-game-of-thrones.json) содержит 14 результатов. Вход, личные списки, запись прогресса и воспроизведение ещё нужно проверить на текущем сайте.

Старый `api.seasonvar.ru` не разрешается через Quad9. В среде агента основной сайт также пока недоступен по HTTPS. Эти ограничения не означают, что сайт недоступен из браузера пользователя.

## Разработка

Базовое направление — нативный Android-клиент на Kotlin с ТВ-интерфейсом. Нативный видеоплеер имеет смысл подключать после подтверждения способа получения актуальной ссылки на поток. Найденный в стороннем клиенте WebView-плеер не подтверждает наличие готового MP4/HLS URL.

Следующий технический шаг — проверить цепочку «вход → личный список → сезон → озвучка → серия → видео → сохранение прогресса». После появления исходников здесь должны быть добавлены реальные команды сборки, запуска и установки APK.

Пароли, API-ключи и cookie в репозиторий не добавляются. Локальные инструменты загружают секреты только из `~/secrets.env` и не выводят их значения.
