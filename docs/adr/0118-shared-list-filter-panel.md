# ADR-0118: Общая панель фильтров списка

Дата: 2026-11-08

Статус: Принято

Кнопка открытия заменена на значок со счётчиком по [ADR-0120](0120-filter-icon-button.md).

Порядок сброса и оформление кнопок уточнены в [ADR-0119](0119-filter-reset-and-action-buttons.md): сброс применяется сразу, «Применить» расположено слева.

Для будущего «Каталога» размещение фильтров пересмотрено в [ADR-0126](0126-catalog-inline-filters.md): постоянно видимая область на собственной странице. Общая модальная панель сохраняется для остальных списков.

Дополняет [единый заголовок списков](0096-unified-catalog-header.md), [формат строки настройки](0015-settings-item-format.md) и [стабильную разметку](0114-stable-async-layout.md).

## Контекст

У личных списков, «Лучших сериалов» и общего каталога разные возможности фильтрации. Пользователь выбрал максимально единообразное управление и попросил реализовать один пункт TODO для проверки. Раздельные формы для каждого списка со временем расходились бы по виду и поведению.

## Решение

- Использовать один компонент панели, который получает доступные поля текущего списка, их варианты, значения по умолчанию и применённые условия. Адаптер списка отвечает за загрузку данных и запрос; панель не знает маршруты Seasonvar. Неподдерживаемые поля отсутствуют. Если фильтров нет или их поддержка ещё не установлена, кнопки панели тоже нет.
- В существующей верхней строке размещать текстовую кнопку «Фильтры» перед переключением вида и обновлением. При активных ограничениях показывать число условий: «Фильтры · 2». Несколько выбранных жанров считаются одним условием; сортировка отдельным ограничением не считается. Размер кнопки и высота строки не меняются при загрузке и смене числа. Краткие выбранные значения размещать в той же строке второстепенным текстом, с сокращением по ширине; не добавлять строку над карточками.
- Открывать модальную панель справа поверх текущего экрана с затемнённым фоном. Заголовок — «Фильтры — <список>». На узком экране ширина ограничивается доступной областью. Основные поля и фиксированные нижние действия имеют заранее выделенные места; прокручивается только содержимое панели. Размеры и интервалы брать из общей темы.
- Строки следуют ADR-0015: название и при необходимости пояснение слева, значение или галочка справа; одна точка фокуса на всю строку. OK открывает выбор внутри той же панели. Одиночный выбор использует радиокнопки, множественный — галочки; большие наборы вариантов прокручиваются. «Назад» из выбора возвращает к строке, из основной панели закрывает её с отменой черновика.
- Для большого каталога основные поля показывать сразу, расширенные объединять по смыслу: рейтинги и сезоны, качество и субтитры, условия личных списков, дополнительные параметры. Группы открываются внутри той же панели. Не строить все будущие виды условий заранее: расширять общий компонент по мере реализации подтверждённых возможностей.
- При открытии копировать применённые условия в черновик. Изменение варианта не вызывает запрос списка. «Сбросить» возвращает черновик к значениям без ограничений; «Применить» отправляет его один раз. При неизменном выборе закрывать панель без запроса выдачи. На запросе применения блокировать повторное подтверждение.
- Новые условия и новую выдачу принимать вместе после успешного ответа. Пока запрос идёт, прежние карточки и счётчик остаются прежней выдачей. Ошибка сохраняет применённые условия, данные и черновик, показывает короткое уведомление по ADR-0113 и позволяет повторить. Пустой успешный результат считается результатом: кнопка фильтров и возможность сброса остаются доступны.
- После закрытия возвращать фокус на «Фильтры», стрелка вниз ведёт в карточки. Фокус не выходит из модальной панели в меню или список. Переходы и интервалы одинаковы в ленте и сетке. Обновление без изменения условий сохраняет позицию; при новой выдаче сохранять выбранную карточку, если она осталась, иначе применять штатный выбор доступной карточки.
- Хранить принятые условия отдельно для каждого раздела и для владельца личных списков. При возврате и повторном запуске восстанавливать выбор; после смены аккаунта не переносить чужие условия или черновик. Устаревшие значения сверять со свежими справочниками сайта. Ключи фильтров учитывать в запросах и кэше; поздний ответ прежних условий не заменяет новую выдачу.
- Ограничения одного экрана не должны менять другие списки, «Продолжить», домашние ленты, историю или постоянные отметки. При реализации проверять, сохраняет ли сайт условия в сессии, и не принимать общий фильтр каталога за фильтр соседней подборки.

## Первый этап

Реализовать один функциональный пункт TODO: «Личные списки: жанр и страна». Общая панель получает два одиночных выбора из свежих опций `/resume`, каждый с вариантом без ограничения. Она доступна в «На чём остановились», «Есть обновления», «Нет новых серий», «Хочу посмотреть» и «Посмотрел». История и производное «Продолжить» в этот этап не входят. Остальные пункты TODO остаются открытыми.

Наличие обработчика `marks_filter` в исходнике само по себе не подтверждает работу непустых параметров. Перед подключением проверить авторизованный ответ, выбор вкладок, пустой результат и отсутствие изменения отметок. [Контракт фильтров](../api/catalog-filters.md) обновлять по результатам проверки.

## Альтернативы и последствия

Отдельная форма каждого раздела проще в первом пункте, но дублирует фокус, применение, сброс и обработку ошибок. Все возможные поля с неактивными неподдерживаемыми строками перегружают телевизионный экран. Постоянная полоса фильтров уменьшает область карточек и усложняет D-pad. Общая модальная панель сохраняет пространство списка и даёт один способ управления; адаптеры и наборы полей добавляются постепенно.

Проверять панель на пульте: открытие, выбор, отмену, сброс, применение, ошибку, пустую выдачу, длинные варианты, восстановление фокуса и независимость разделов. Основная визуальная проверка — в эмуляторе; установка на приставку требует отдельного запроса.
