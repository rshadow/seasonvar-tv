# ADR-0153: переход от актёра к его сериалам

Статус: принято. Дата: 2026-11-13. Дополняет [ADR-0150](0150-compact-actor-photos.md) и [ADR-0151](0151-actor-row-below-poster-preview.md).

## Контекст

Сайт возвращает у каждого актёра ссылку `/actor/...` и по ней выдаёт сериалы. Пользователь хочет открывать этот список из ряда актёров. Локальная фильтрация каталога не используется.

## Решение

Фотография и имя актёра образуют одну кнопку. OK открывает серверную выдачу по точному пути из HTML карточки. Ссылки ограничены оригинальным доменом Seasonvar; отсутствие корректной ссылки не заменяется поиском по имени или придуманным адресом.

Список использует общие `CatalogPane`, `SeriesListEngine`, порционный разбор, предзагрузку, кеш постеров и глобальный кеш данных карточек. HTML сохраняется через общий `HtmlResponseCache` в текущей публичной или приватной области. Кешированная выдача показывается сразу с фоновым обновлением. Сохраняются порядок сайта и точные ссылки сезонов; число сезонов в подписи не превращается в номер выбранного сезона.

Список открывается отдельной внутренней `ActorSeriesActivity` на всю ширину экрана: заголовок с именем актёра, описание выбранной карточки, сериалы, переключатель вида и обновление. Карточка сериала использует существующий экран выбора сезона, озвучки и серии, меню аккаунта и запуск плеера. Фильтров и строки поиска на этом экране нет.

«Назад» из карточки возвращает к выбранному сериалу с прежним видом, фокусом и прокруткой. Из списка — к исходной фотографии актёра. Переход к другому актёру из вложенной карточки сохраняет эту цепочку через стек экранов Android. Входящий Activity не экспортируется. Смена аккаунта очищает видимую выдачу и закрывает вложенную карточку перед загрузкой новой области кеша.

## Альтернативы и последствия

Включение актёра в существующий раздел поиска смешало бы историю запросов с переходами из карточек. Отдельный экран сохраняет контекст исходного списка и использует общий механизм отображения. При длинной цепочке актёров Android удерживает несколько экранов; сетевые клиенты и кеши остаются общими на уровне приложения.
