# ADR-0101: Скрытие разделов бокового меню

Дата: 2026-11-07. Статус: принято.

Уточняет [ADR-0044](0044-visual-menu-groups.md) и [ADR-0045](0045-start-page-setting.md).

## Контекст

Пользователь хочет оставлять в боковом меню только нужные разделы. Настройка должна открывать список с галочками, изначально включёнными, и автоматически убирать заголовки пустых групп.

## Решение

- В «Настройки → Приложение» добавить «Разделы меню». Строка показывает число включённых пунктов; OK открывает прокручиваемый список с названиями слева и галочками справа. Каждая доступная строка — одна точка фокуса по ADR-0015.
- Список включает публичные, производные, личные и системные разделы в порядке меню. Личные пункты можно настроить и до входа; само меню показывает их только вошедшему пользователю.
- Все пункты изначально включены. OK переключает галочку, сразу сохраняет изменение и оставляет диалог открытым. «Готово» возвращает фокус к строке настройки. «Назад» закрывает диалог и возвращает в меню; уже сохранённые переключения остаются.
- «Настройки» всегда включены: строка отмечена, недоступна для переключения и поясняет, что нужна для возврата скрытых пунктов. Поиск и аккаунт над меню не входят в этот список.
- После фильтрации пунктов полностью убирать пустые группы вместе с заголовками и отступами. Включение любого пункта возвращает его группу. У оставшихся пунктов сохраняются порядок и ключи; скрытие не очищает кэш, выбор карточек и позиции списков.
- Верхние кнопки поиска и аккаунта ведут вниз к первому видимому пункту, а не обязательно к «Сегодня».
- «При запуске» предлагает только видимые пункты, доступные текущему аккаунту. Скрытый стартовый раздел заменяется первым доступным; при скрытии всех необязательных пунктов это «Настройки». Сохранённое предпочтение не стирается и снова применяется после включения раздела. Скрытый личный стартовый пункт не ждёт восстановления входа. После входа скрытый «На чём остановились» также не открывается автоматически.
- В SharedPreferences `interface` сохранять набор `hidden_sections` со стабильными идентификаторами. Отсутствие настройки и новые пункты означают видимость. Неизвестные значения и попытки скрыть обязательные элементы игнорировать. Настройка общая для устройства.

## Альтернативы

- Хранить включённые пункты: новые разделы исчезали бы у пользователей с прежним сохранённым списком.
- Позволить скрыть настройки: пользователь потерял бы способ вернуть пункты.
- Показывать заголовки пустых групп: занимает место и противоречит запросу пользователя.

## Проверка

`make check` проверяет сохранение выбора после пересоздания, обязательный доступ к настройкам, фильтрацию групп, порядок пунктов и старт приложения с учётом скрытия и входа. В эмуляторе через `make run-profile DEVICE=<serial>` проверить галочки по умолчанию, скрытие всей группы и возврат одного пункта, сохранение после перезапуска, D-pad и возврат из диалога.

Проверено в profile-сборке эмулятора: все галочки включены по умолчанию; скрытие всех публичных списков убирает «Каталог», включение одного возвращает его заголовок. При скрытии всех необязательных пунктов перезапуск открывает «Настройки», а выбор стартового экрана содержит только их. При скрытом «Сегодня» переход из поиска ведёт к «Обновлениям». После возврата галочек и перезапуска восстановился прежний стартовый раздел. `make check` прошёл: 470 JVM-тестов, 39 Python-тестов, проверка зависимостей, сборка и Android Lint.
