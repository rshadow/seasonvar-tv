# ADR-0075: Предпочитаемая озвучка в настройках

Дата: 2026-11-05

Статус: Заменено [ADR-0076](0076-translation-priority-list.md)

Дополняет выбор при открытии карточки по ADR-0040 и откат к стандартной озвучке по ADR-0042.

## Контекст

Пользователь выбрал явное предпочтение в настройках. При открытии выбора нужен актуальный список с сайта; между запусками сохраняется только выбор пользователя. Переключение перевода в одном сериале не должно менять глобальное предпочтение.

## Решение

- В группе «Приложение» настроек добавить «Предпочитаемая озвучка»: название и пояснение слева, выбранное значение справа, одна точка фокуса на строку по ADR-0015. OK открывает диалог с радиокнопками и поиском по названию. Использовать стандартную Android-клавиатуру.
- При каждом открытии диалога выполнять GET главной Seasonvar и читать `select[data-filter="golosa"] option[value]`. Служебное `all` исключать; порядок и названия задаёт сайт. Подтверждение 2026-11-05: 104 перевода, без предположения о постоянном количестве.
- Справочник не хранить на диске и не использовать вместо нового запроса. Отображать загрузку и различать ошибки сети, HTTP и разметки; дать повторить загрузку. Закрытие отменяет запрос и очищает временный список. Ошибка и отсутствие сохранённой озвучки в свежем списке не меняют настройку.
- Постоянно хранить только строковое значение выбранного перевода. Не привязывать его к числовому ID сезона или перевода. На странице нового сезона сопоставлять с названием доступного перевода без учёта регистра и повторных пробелов; неоднозначное совпадение не угадывать.
- Первый пункт «Как на сайте» отключает предпочтение и сохраняет прежний порядок выбора. Отдельный пункт «Стандартная» явно выбирает стандартный вариант. Выбранное ранее название остаётся доступным в диалоге, даже если исчезло с сайта; об отсутствии сообщать отдельно.
- При открытии карточки приоритет имеют явно известная озвучка источника и совместимое локальное продолжение. При несовпадении явно указанной озвучки действует ADR-0042. Затем применять предпочтение; при его отсутствии в сезоне или неоднозначности выбирать стандартную по ADR-0042. Без предпочтения сохранять прежний выбор сайта.
- Известная серия остаётся обязательным параметром: если озвучка не задана, подбирать вариант, содержащий эту серию, по тому же порядку приоритетов. Не подменять неизвестную или недоступную серию другой ради предпочтения. Смена сезона заново применяет настройку к доступным переводам этого сезона.
- Ручной выбор в карточке не изменяет настройку. Изменение настройки применяется при следующем открытии карточки или сезона; активное воспроизведение не переключать. Продолжение по времени использовать только при совпадении сезона, озвучки и серии.
- Загружать и разбирать HTML в фоне. Длинный список отображать лениво, со стабильными ключами, поиском и фокусом на текущем значении. После выбора возвращать фокус на строку; при отмене — в меню настроек по ADR-0015. Размеры и цвета брать из общей темы.

## Альтернативы

- Запоминать последнюю выбранную в карточке озвучку: пользователь выбрал настройку, а разовое переключение не должно менять остальные сериалы.
- Хранить справочник и обновлять его периодически: пользователь потребовал актуальный запрос при каждом открытии и сохранение только выбора.
- Задать студии в исходниках: список устаревает и ограничивает доступные значения.
- Предпочтение поверх истории и продолжения: меняет уже известный выбор и может лишить пользователя сохранённой позиции.

## Последствия и проверка

Выбор действует локально для приложения, независимо от входа. Для загрузки справочника нужен доступ к сайту; сохранённое предпочтение применяется к уже доступным данным сезона без дополнительного запроса справочника. Отсутствующая в конкретном сезоне озвучка заменяется стандартной, а настройка сохраняется для других сериалов.

Автономные тесты покрывают структуру фильтра и ошибки, новый запрос при каждом открытии, отмену устаревшего ответа, сохранение только явного выбора, сравнение названий при разных ID сезонов, приоритет контекста и продолжения, откат и сохранение известной серии. Проверки запускаются штатной командой `make check`.

2026-11-05: `make check` — 334 JVM-теста, 39 Python-тестов, Android Lint без ошибок; `make run-profile DEVICE=emulator-5554` — сборка с R8 и установка с сохранением данных. В эмуляторе проверены загрузка живого списка, выбор AlexFilm стрелками/OK, поиск со стандартной клавиатурой, возврат фокуса на настройку, сохранение после перезапуска, фокус на текущем значении и отмена Esc без изменения предпочтения. После проверки восстановлено исходное «Как на сайте». Приставка и код плеера не изменялись.
