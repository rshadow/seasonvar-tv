# ADR-0192. Первый показ публичных списков из кеша

Статус: принято. Дата: 2026-11-19. Заменяет [ADR-0191](0191-first-response-for-public-lists.md).

## Контекст

Ожидание сайта при первом открытии замедляет доступ к публичной выдаче и лишает пользователя сохранённых карточек при ошибке сети.

## Решение

Публичные подборки, каталог и фильмография актёра при открытии показывают подходящий кеш и запрашивают актуальные данные. Список обновляется сразу после получения свежей выдачи по правилам сверки из [ADR-0190](0190-shared-list-reconciliation.md). Если кеша нет, экран ждёт ответа сайта.

## Альтернативы и последствия

Ожидание сайта исключает подмену карточек при первом открытии ценой дополнительной задержки. Применение ответа при следующем открытии продлевает показ устаревшей выдачи. При выбранном подходе пользователь может увидеть изменение состава или порядка открытого списка после ответа сайта.
