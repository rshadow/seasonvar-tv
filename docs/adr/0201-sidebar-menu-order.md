# ADR-0201: Порядок и видимость бокового меню

Дата: 2026-11-21

Статус: Принято. Уточняет [ADR-0044](0044-visual-menu-groups.md) и [ADR-0101](0101-menu-section-visibility.md).

## Контекст

Пользователь может скрывать разделы, но часто нужный пункт остаётся внизу группы. Для перестановки на телевизоре подходят кнопки со стрелками из списка приоритетов озвучек.

## Решение

«Настройки → Приложение → Разделы меню» открывает один список групп и вложенных пунктов. В строках «Каталог», «Для меня» и «Мои списки» стрелки перемещают всю группу на одну позицию. Стрелки в строках пунктов перемещают их внутри группы. «Система» закреплена внизу; настройки всегда доступны.

Вместо удаления в строке пункта кнопка с глазом переключает видимость. Скрытый пункт остаётся в настройке на сохранённом месте. Фокус сохраняется на перемещаемой строке; у края доступна обратная стрелка или переключатель видимости. Изменения применяются сразу. «Готово» возвращает фокус к строке настройки.

Порядок хранится отдельно от существующего набора скрытых пунктов по стабильным идентификаторам. При отсутствии сохранённого порядка используется штатный. Новые пункты дополняют свою группу. Гость может настроить личные группы; боковое меню показывает их после входа. Недоступный стартовый раздел заменяется первым доступным в сохранённом порядке.

## Альтернативы и последствия

Перенос пунктов между группами затрудняет поиск и меняет смысл заголовков. Режим захвата добавляет состояние и требует запоминать управление. Видимые стрелки повторяют знакомое действие и позволяют настроить весь список одним пультом.
