# ADR-0018: Бейдж «Новинка» из разметки сайта

Дата: 2026-11-02

Статус: Принято

## Контекст

Пользователь выбрал бейдж «новинка» по образцу Seasonvar. В HTML карточек AJAX-подборки он задан классом `rside-p-new`; CSS выводит надпись на бордовой полосе вверху постера.

## Решение

- Хранить признак `isNew` в модели карточки и получать его только из точного класса `rside-p-new`. При отсутствии метки бейдж не показывать. Не определять новинку по номеру серии, году или времени загрузки.
- Показывать полосу «новинка» по верхнему краю миниатюры и большого постера выбранного сериала. Использовать бордовый `surface`, светлый `onSurface`, полужирный текст по центру и скруглённые верхние углы.
- Размеры отступов хранить в `themes.xml` (`seasonvar_badge_padding_horizontal`, `seasonvar_badge_padding_vertical`), подключать через `SeasonvarTheme.dimensions`; текст — в `strings.xml`. Правила темы сохраняются по [ADR-0008](0008-centralized-ui-theme.md).
- Бейдж не получает фокус и не является отдельной кнопкой. Ключ карточки и правила навигации не меняются.
- Использовать метку из уже загруженного или сохранённого HTML, без дополнительных сетевых запросов. В «Сегодня» признак пока не извлекается: отдельный подтверждённый маркер для его разметки не установлен.

## Альтернативы

- Вычисление новинки по первой серии или свежести кэша меняет смысл метки сайта.
- Отдельная строка вне постера меняет высоту карточек и расположение элементов ленты.

## Последствия

Видимость бейджа повторяет метку сайта и сохраняется при чтении кэша. Парсер проверяется на размеченных и обычных карточках, похожем имени класса и сохранённом реальном AJAX-ответе. В снимке 2026-11-02 помечены 10 из 50 позиций. Поля и источник оформления записаны в [web-api.md](../api/web-api.md).
