# ADR-0090: Единое меню действий сериала

Дата: 2026-11-06

Статус: видимая подпись в карточке пересмотрена в [ADR-0111](0111-season-progress-below-controls.md); остальные решения приняты.

Уточняет [ADR-0081](0081-account-list-status-actions.md), [ADR-0087](0087-flat-long-press-actions.md) и [ADR-0088](0088-stable-mark-menu-loading.md).

## Контекст

Удержание OK на миниатюре уже открывает удобное плоское меню. В полной карточке были отдельные закладка для статуса и корзина. Пользователь выбрал одну реализацию меню с двумя способами вызова.

## Решение

- После входа в аккаунт в строке управления карточкой расположена одна квадратная кнопка с тремя вертикальными точками и подписью «Меню сериала» при фокусе. Отдельной корзины и закладки нет.
- Короткое OK по этой кнопке и долгое OK по миниатюре вызывают один обработчик открытия и один `MarkRemovalDialog` в режиме действий. Специальный режим только для статусов удалён.
- Меню содержит четыре статуса сайта и постоянную строку удаления отметки. Чтение статуса, обновление, состояние недоступного удаления и стабильное положение пунктов соответствуют ADR-0088.
- Вызов из полной карточки использует текущий выбранный сезон. Смена озвучки и серии сохраняет контекст карточки.
- Удаление выполняется через пункт общего меню с прежним подтверждением; первый фокус в подтверждении остаётся на «Отмена».
- После закрытия меню из карточки фокус возвращается к кнопке с точками. После вызова из каталога — к исходной миниатюре либо существующему соседу, если она исчезла из списка. Esc и «Назад» равнозначны.
- Гостевой режим сохраняет прежнее поведение: действия с аккаунтом недоступны до входа.

## Альтернативы

Сохранить прямые закладку и корзину. Это оставляет разные наборы действий для одной сущности и требует дополнительного места в карточке.

## Последствия

Оба входа используют одинаковые пункты, загрузку, запись и подтверждение удаления. В строке управления карточки на одну кнопку меньше. Протокол сайта и сохранение прогресса не меняются.
