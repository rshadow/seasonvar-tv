# ADR-0173: загрузка выбранного стартового раздела

Статус: принято. Дата: 2026-11-16. Дополняет [ADR-0045](0045-start-page-setting.md) и пересматривает начальную подготовку «Сегодня» из [ADR-0170](0170-list-visibility-and-background-refresh.md).

## Контекст

Создание модели «Сегодня» начинало загрузку независимо от выбранного экрана. Восстановление аккаунта повторно обновляло этот список. При старте личного раздела временный фокус на публичном пункте тоже мог пометить его как посещённый и запустить запрос.

## Решение

Все публичные модели начинают загрузку при активации своего раздела. Интерфейс активирует публичный список после применения выбранного раздела; повторные композиции того же выбора не создают дополнительных сигналов.

Пока личный старт ждёт проверки аккаунта или перехода в разрешённый раздел, временный пункт меню не активирует список и не считается видимым для координатора обновлений. Область содержимого показывает загрузку. После проверки открывается выбранный личный раздел либо доступный запасной раздел по ADR-0045/0101. Любое пользовательское действие, отменяющее отложенный старт, разрешает обычную загрузку выбранного пункта.

Публичный и системный старт не ждут аккаунт. В настройках и на экране о программе публичные списки не запускаются. Посещённые разделы сохраняют обновление при смене аккаунта, сети и даты. Расписание лент Android TV и восстановление аккаунта остаются самостоятельными операциями.

## Альтернативы и последствия

Удалить только загрузку из конструктора недостаточно: автоматический фокус и промежуточная композиция после проверки аккаунта могут активировать запасной раздел. Ожидание аккаунта для любого старта задержало бы публичные и системные экраны без необходимости.

Изменение убирает ненужную подготовку данных. Ускорение первого кадра или сетевого ответа из этого не следует; результаты сравнения хранятся в [документации проверки](../development.md#холодный-запуск-настоящего-приложения).
