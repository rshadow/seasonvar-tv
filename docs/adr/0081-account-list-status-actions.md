# ADR-0081: Добавление в личные списки и смена статуса

Дата: 2026-11-05

Статус: Принято

Меню долгого OK упрощено позднее в [ADR-0087](0087-flat-long-press-actions.md). Остальные решения действуют.

Дополняет [ADR-0057](0057-remove-account-list-marks.md). Его текстовая кнопка удаления в полной карточке заменяется иконкой корзины; подтверждение сохраняется.

## Контекст

Действия аккаунта нужны и в полной карточке, и через удержание OK на миниатюре. Пользователь выбрал иконки для действий со списками и корзины. Кнопка просмотра и выборы сезона/озвучки сохраняют понятные текстовые значения.

## Решение

- В полной карточке после выбора озвучки показывать квадратную кнопку с иконкой закладки «Личный список», а при известной постоянной отметке — соседнюю корзину «Удалить из списка». Размеры, закругления, центрирование и выделение фокуса использовать общие с поиском и обновлением. Под строкой управления показывать подпись сфокусированной иконки; место под неё сохранять, чтобы экран не сдвигался.
- Закладка открывает выбор «Хочу посмотреть», «Смотрю», «Посмотрел», «Не буду смотреть». При открытии читать актуальную отметку выбранного сезона с сайта и выделять текущий статус. Каждая опция получает один фокус; OK сразу сохраняет выбор. При ошибке показывать сообщение и оставлять возможность повторить. Отдельная кнопка сохранения не нужна.
- После входа удержание OK работает на миниатюрах всех списков и поиска. Меню содержит «Открыть сериал», «Личный список» и, если отметка известна, «Удалить из списка». Для гостя действия записи не предлагаются. В самой миниатюре дополнительных точек фокуса нет.
- Корзина открывает прежнее подтверждение с первым фокусом на отмене. Удалять только постоянную отметку выбранного сезона; история и локальное продолжение сохраняются.
- При отмене или сохранении возвращать фокус к исходной закладке либо миниатюре. После удаления — к корзине, если она ещё есть, иначе к кнопке просмотра. Если после смены статуса миниатюра исчезла из текущей подборки, выбирать соседа по ADR-0057; не сбрасывать список в начало.
- Использовать оригинальный POST jsonMark.php: wanttosee/seria=-1, watched/seria=-2, notWatched/seria=-3. «Смотрю» — положительная отметка серии через pauseadd. Уже существующую положительную отметку, её озвучку и время сохранять. Если её нет, использовать известную выбранную серию/озвучку; неизвестную озвучку заменять стандартной, а при отсутствии известной серии брать первую реальную серию. Не придумывать серию при недоступном списке.
- Перед записью проверять авторизацию и версию сессии. Проверять msg=success, затем повторно читать отметку того же сезона и сверять статус/позицию. Ответ POST без подтверждения не считать успехом. Повтор того же статуса не требует POST.
- Ручная смена статуса сериализуется с удалением и автоматическими отметками. Дождаться отправляемой записи, убрать старые ожидающие отметки того же сезона и отсеять уже запланированные события. Новое воспроизведение может снова создать отметку по прежней политике.
- Обновлять связанные личные и публичные подборки, метку «Смотрю» и сведения открытой карточки после подтверждения. Не удалять другие сезоны по предложению ответа сайта и не менять локальную позицию.

## Альтернативы

Только удержание OK скрывает действие от части пользователей. Несколько отдельных иконок статусов увеличивают плотность строки и требуют запоминать их значения. Одна закладка оставляет подписи вариантов в понятном списке. Запись без повторного чтения и без общей очереди может показать ложный успех или быть перезаписана отложенным прогрессом.

## Последствия

Два входа используют одну модель операции, общий диалог и один протокол. «Смотрю» не является независимым серверным статусом: оно связано с конкретной серией. «Не буду смотреть» соответствует чёрному списку сайта, отдельный раздел приложения пока не добавляется. Автономные тесты не используют реальный аккаунт; явная сетевая проверка make status-probe восстанавливает исходную отметку.
