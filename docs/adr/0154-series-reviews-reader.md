# ADR-0154: чтение рецензий в двух колонках

Статус: принято. Дата: 2026-11-13.

## Контекст

Seasonvar размещает развёрнутые рецензии в отдельной вкладке карточки. Пользователь выбрал экран с двумя колонками и отдельную кнопку справа, чтобы редкое действие не смешивалось с управлением просмотром.

## Решение

Кнопка «Рецензии» находится в строке действий у правого края. Слева остаются просмотр, сезон, озвучка и меню; свободное пространство отделяет группы. Размер кнопки и место счётчика заданы общей темой и существуют с первого кадра. Неизвестное количество не показывается как ноль. Начальный фокус остаётся на «Продолжить»/«Смотреть». Вправо из последнего действия открывает фокус кнопки рецензий, влево возвращает его в левую группу.

Кнопка открывает отдельный нативный экран: слева ленивый список авторов и начала текста, справа полный текст выбранной рецензии с автором и датой, если они указаны. Колонки, область метаданных и строка состояния сохраняют размеры при загрузке, пустом ответе и ошибке. Цвета, размеры и интервалы берутся из общей темы.

После загрузки выбран первый отзыв, его текст уже виден. Вверх/вниз слева выбирают рецензию. Вправо или OK переводит к чтению, вверх/вниз прокручивают текст, влево возвращает к выбранной строке. «Назад» закрывает экран и восстанавливает фокус на кнопке «Рецензии» исходной карточки, в том числе открытой из списка актёра.

Первые записи читаются из HTML текущей страницы сезона, уже сохранённого общим кешем карточек. При приближении к концу списка загружается оставшаяся выдача по проверенному запросу чтения `ajax.php` с ID сезона и курсором `review.last`. Сохраняется порядок сайта. Новые записи добавляются без сброса выбранной рецензии, прокрутки списка или читаемого текста. При ошибке остаётся доступна загруженная часть и повтор загрузки. Обновление выполняется явной кнопкой и сохраняет выбранную запись, если она осталась в ответе.

В общем кеше 5000 карточек хранится только счётчик. Полные разобранные рецензии живут в модели экрана и освобождаются при его закрытии; исходный HTML использует существующий `HtmlResponseCache`, его срок свежести и разделение публичной и приватной областей. Выход из аккаунта очищает приватные копии по общим правилам. Счётчик в карточке берётся из её HTML, без отдельного запроса.

Показывается обычный текст с абзацами и переносами. HTML и скрипты не исполняются. Этот экран предназначен для чтения; контракт источника и границы проверки находятся в [документации API](../api/web-api.md#комментарии-и-рецензии--проверка-2026-11-13).

## Альтернативы и последствия

Одна колонка полных текстов заставила бы прокручивать длинную рецензию для перехода к следующей. Диалог поверх карточки оставил бы меньше места для чтения. Две колонки требуют отдельного перехода фокуса между выбором и текстом, зато сохраняют список доступным при чтении длинных записей. Кнопка справа занимает постоянную ширину; длинные названия действий могут переноситься внутри левой группы.
