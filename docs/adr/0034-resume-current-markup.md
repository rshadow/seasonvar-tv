# ADR-0034: Личный список по текущей разметке отметок сайта

Дата: 2026-11-03

Статус: Принято. Уточняет источник списка из [ADR-0033](0033-account-and-resume.md). Правило имени аккаунта пересмотрено в [ADR-0035](0035-account-display-name.md).

## Контекст

После реального входа на Ugoos шапка аккаунта и восстановление сессии работали, но приложение показывало пустой список. В авторизованном ответе `/resume` отсутствовал блок `.pgs-marks-bn` из старого открытого клиента. Настоящие отметки находились в `.pgs-marks-el` внутри вкладок `data-tabr`.

Проверка выполнялась структурной диагностикой внутри приложения: теги, имена атрибутов, публичные классы разметки и количества элементов. Имена, URL, cookie и содержимое истории в логи, фикстуры и документы не сохранялись.

## Решение

- «На чём остановились» объединяет вкладки `marks-new` («Есть обновления») и `marks-nonew` («Нет новых серий»), сохраняя порядок сайта и строк внутри каждой вкладки. Обе содержат текущие отметки просмотра. `marks-want` и `marks-watched` остаются отдельными будущими разделами.
- Читать каждую `.pgs-marks-el` как отдельную запись: точный путь из ссылки `/serial-…`, название из `.pgs-marks-name`, сезон из `.pgs-marks-seas`, текст отметки из `.pgs-marks-current` и сообщение сайта из `.pgs-marks-mess`. Фрагмент ссылки не подменяет подтверждённое время продолжения.
- Ключ карточки строить по вкладке и `data-marksel`. Разные отметки одного сезона не удалять по совпадению URL; они имеют разные ключи. Публичные каталоги сохраняют прежние ключи.
- Если текущие вкладки присутствуют, они определяют результат, в том числе пустой. Не заменять пустые текущие отметки списками «Хочу посмотреть»/«Посмотрел». Старый `.pgs-marks-bn` поддерживается только при отсутствии текущих вкладок.
- Сохранять различие между подтверждённым пустым списком, истёкшей сессией и ошибкой разметки. Неполная строка или повторяющаяся идентичность не превращается в успешный пустой результат.
- Шапка сайта может содержать кнопку с изображением и отдельное раскрывающееся меню профиля. Для имени предпочитать `alt` изображения, а не служебную подпись ссылки «Профиль». Аватар брать из изображения шапки.

## Альтернативы и последствия

Только вкладка с обновлениями скрыла бы текущие сериалы без новых эпизодов. Объединение всех четырёх вкладок смешало бы текущий просмотр, планы и завершённые сериалы. Выбор двух вкладок соответствует назначению «На чём остановились» и сохраняет возможность добавить остальные разделы отдельно.

Первоначальное предположение по стороннему клиенту остаётся в ADR-0033 как история решения; текущий контракт подтверждён ответом оригинального сайта. Положительные тесты на синтетических ответах не заменяют проверку реальной авторизованной разметки.

## Проверка

Синтетическая фикстура `account-resume-current.html` повторяет проверенную структуру без личных значений. Регрессии проверяют обе вкладки, скрытые вкладки без обновлений, сезон/текст отметки, пустой результат, сохранение разных отметок одного сезона и ошибку неполной строки.

На Ugoos подтверждены непустой личный список, успешно загруженный аватар и восстановление сессии после обновления без пароля. `make check`: 136 JVM-тестов, 17 Python-тестов и Lint прошли; R8-сборка также прошла.

Проверены открытие карточки из личной ленты и возврат Esc на ту же запись с сохранением фокуса.
