# ADR-0061: AGP 9, встроенный Kotlin и SDK 37

Дата: 2026-11-04

Статус: Принято

Частично пересматривает [ADR-0060](0060-compatible-dependency-updates.md): версии инструментария и отдельную подмену R8.

## Контекст

AGP 9.5.0 требует Gradle не ниже 9.6.0 и Build Tools не ниже 36.0.0. Gradle 9.8.2 несовместим с прежним AGP 8.13.2. OkHttp Android 5.5.1 требует SDK 37 для компиляции. Поэтому три обновления Dependabot проверяются последовательно: инструментарий AGP, Gradle Wrapper, сеть.

## Решение

- Перейти на AGP 9.5.0, сначала с минимально поддерживаемым Gradle 9.6.0; дальнейшее обновление Wrapper проверять отдельным PR.
- Использовать встроенную поддержку Kotlin в AGP. Удалить применение `org.jetbrains.kotlin.android`, закрепить KGP 2.4.21 в classpath корневого `build.gradle.kts` и оставить Compose Compiler 2.4.21.
- Использовать штатный D8/R8 из AGP, удалив подмену из ADR-0060.
- Компилировать с SDK 37.0, Build Tools 36.0.0 и JDK 17. Сохранить minSdk 26 и targetSdk 36: повышение SDK компиляции нужно библиотекам и не меняет целевое поведение приложения на устройстве.
- Закреплять инструменты и проверяемые архивы для всех поддерживаемых компьютеров в `toolchain.lock.json`. Пакет платформы называется `platforms;android-37.0`; это фактическое имя из индекса Google. В DSL явно задан `minorApiLevel = 0`, чтобы выбирать тот же SDK на каждом компьютере.
- Подпись и её проверка используют `apksigner.jar` из закреплённых Build Tools 36.0.0.

После отдельного обновления в PR №4 текущая версия Wrapper — Gradle 9.8.2. Контрольные суммы дистрибутива и Wrapper JAR сверяются с официальным сервером Gradle; таймаут загрузки остаётся 60 секунд.

Команда `make wrapper` пересоздаёт Wrapper для версии и контрольной суммы, указанных в `gradle-wrapper.properties`. При обновлении проверять размер и checksum SDK-архивов, `make check`, `make ci-lint`, `make codeql-build` и `make build BUILD_TYPE=release`. Проверять запуск оптимизированной profile-сборки в эмуляторе. Каждый PR сливать после обязательных проверок GitHub на актуальном main. Новый Lint проверяет создание `FocusRequester` внутри композиции: запрос фокуса карточки запоминать через `remember`, сохраняя общий реестр для возврата в список.

В PR GitHub Actions дополнительно выполняет `make build-profile`: проверяется оптимизация R8, а APK с отладочной подписью публикуется как `seasonvar-tv-profile` для ручной проверки в эмуляторе. Релизный ключ в PR не используется. Debug-тесты и Lint сохраняются.

## Альтернативы

- Сохранить AGP 8 и ограничить новые версии Gradle и OkHttp. Не позволяет принять запрошенные обновления.
- Отключить встроенный Kotlin и новый DSL. Это временный режим совместимости, который будет удалён; проект не использует сторонние плагины, требующие такого режима.
- Объединить все обновления без промежуточных проверок. Сложнее установить причину регрессии и откатить отдельную библиотеку.

## Последствия

Настройка другого компьютера использует тот же локальный bootstrap. Kotlin компилирует AGP с явно закреплённой версией компилятора; отдельный Android Kotlin plugin больше не применяется. Обновления сетевого транспорта дополнительно требуют проверки реального видео по правилам проекта.
