# ADR-0026: Обновление без сдвига содержимого

Дата: 2026-11-02

Статус: Уточнено [ADR-0096](0096-unified-catalog-header.md) в части размещения сообщений состояния.

## Контекст

При обновлении каталога над описанием появлялась строка «Обновляем список…». Она меняла высоту доступной области и сдвигала вёрстку. Пользователь выбрал индикацию на самой кнопке обновления.

## Решение

- Пока идёт запрос, вращать значок обновления внутри существующей квадратной кнопки. Контейнер, фокус, цвета, размеры и положение кнопки сохранять. Анимацию останавливать при завершении запроса, при его отмене или уходе с экрана.
- Анимацию создавать только при загрузке. Угол читать в `graphicsLayer`, чтобы каждый кадр менял отрисовку иконки и не вызывал композицию или измерение каталога. Один оборот — 1000 мс, линейно; длительность хранить в `themes.xml` как `seasonvar_refresh_rotation_duration_ms`, получать через `SeasonvarTheme`.
- Не добавлять строку статуса между заголовком, описанием и лентой. Статус ошибки или сохранённых данных показывать в уже существующей строке под заголовком, высотой в одну строку. Описание и лента продолжают отображаться во время запроса.
- При обновлении загруженного пустого списка сохранять его пустое состояние и кнопку повторной попытки. Начальная загрузка без данных по-прежнему имеет отдельное состояние загрузки.
- Во время загрузки сохранять доступность кнопки для фокуса, но игнорировать повторное нажатие: оно не должно отменять и запускать запрос заново. Для доступности указывать состояние обновления и неопределённый прогресс; дополнительная видимая подпись не нужна.
- Использовать один механизм в публичных каталогах и поиске.

Уточняет индикаторы состояния из [ADR-0003](0003-performance-principles.md), оформление кнопки из [ADR-0023](0023-compact-rectangular-menu.md) и отзывчивость из [ADR-0025](0025-responsive-section-switching.md).

## Альтернативы

- Дополнительная строка загрузки меняет вёрстку и отвлекает от текущего содержимого.
- Блокирующий диалог мешает навигации по уже загруженному списку.
- Отключение кнопки через `enabled=false` может лишить её фокуса.
- Постоянно работающая скрытая анимация расходует кадры без необходимости.

## Последствия

Обновление видно на кнопке, список остаётся доступен с пульта. Ошибка не скрывает сохранённые результаты и не вставляет новую область в содержимое. Проверка на медленной сети проводится в эмуляторе через команды Makefile; задержку после проверки возвращать в исходное состояние.
