# ADR-0044: Визуальные группы главного меню

Дата: 2026-11-03. Статус: принято.

## Контекст

В общем меню появились публичные подборки, личные списки и системные экраны. Пользователь выбрал визуальное разделение небольшими подписями групп и попросил отдельный заголовок для системных пунктов.

## Решение

Показывать группы в следующем порядке:

```text
Каталог
  Сегодня
  Обновления
  Топ
  Новинки
  Лучшие сериалы

Мои списки
  На чём остановились
  Есть обновления
  Нет новых серий
  Хочу посмотреть
  Посмотрел
  История просмотров

Система
  Настройки
  О программе
```

«Мои списки» вместе с пунктами видны только после входа. Поиск и кнопка аккаунта остаются над меню.

Заголовки — небольшой текст второстепенного цвета с дополнительным отступом между группами. Они доступны средствам чтения как заголовки, не являются кнопками и не получают фокус. Кнопки всех групп используют общее оформление и одинаковое выделение выбранного раздела. Меню сохраняет вертикальную прокрутку.

Переключение раздела по фокусу, вход в содержимое, возврат и сохранение позиции следуют [ADR-0013](0013-navigation-without-back-buttons.md) и последующим уточнениям. Переход через границу группы не требует дополнительного нажатия. Размеры и цвета берём из общей темы по [ADR-0008](0008-centralized-ui-theme.md).

## Альтернативы и последствия

Разделитель без подписи не объясняет назначение групп. Дополнительные подложки и разные цвета кнопок сильнее перегружают меню. Отдельные вкладки добавляют действия для перехода между списками.

Подписи занимают немного высоты; нижние пункты остаются доступны прокруткой. Группировка не добавляет экранов или уровней навигации.

Проверено в эмуляторе Android TV API 34: порядок всех пунктов, пропуск заголовков стрелками, прокрутка до системных пунктов, вход в настройки и возврат через Esc. `make check` прошёл: 211 JVM-тестов, 17 Python-тестов и Android Lint.
