# ADR-0070: Раздел «Анонсы»

Дата: 2026-11-04

Статус: Принято

## Контекст

На оригинальном сайте есть пункт «Скоро на нашем сайте». Пользователь выбрал для ТВ короткое название «Анонсы». Проверка агентом 2026-11-04 установила маршрут GET /?mode=soon: 36 записей, сезоны, ориентировочные даты и краткие описания. Это отдельная страница, а не AJAX-подборка.

## Решение

Добавить «Анонсы» в общедоступную группу меню после «Лучших сериалов», а также в выбор первого раздела. Состояния и описания основного экрана собирать из полного реестра моделей PublicFeed, как для личных списков, без отдельного ручного перечисления лент. Использовать общий экран каталога: описание сверху, миниатюры снизу, обновление и прежние правила управления пультом.

Загружать напрямую https://seasonvar.ru/?mode=soon. Сохранять все строки активной панели в порядке сайта, без сортировки и фильтрации по дате. Проверять заголовок и структуру: блокировка не считается пустым списком.

Данные заранее разбирать в SeriesEntry по ADR-0041: ID и точная ссылка сезона, название и оригинал, номер сезона, постер, краткое описание. Новое необязательное поле expectedReleaseDate хранит текст ориентировочной даты без требования точного календарного формата; update сохраняет подпись сайта целиком. На миниатюре выводить дату полностью, без повторяющейся подписи; пояснение об ориентировочном сроке остаётся в описании выбранного сериала. Даты относятся к премьере в оригинале, не обещают готовый перевод.

Использовать стабильный ключ ID сезона: перенос даты не меняет выбор. Открывать именно сезон из ссылки по ADR-0040; не придумывать доступные серии до их появления на сайте.

Кэш announcements.html отделён от других лент и действует 24 часа. Применять общие фоновое обновление, сохранение позиции и фокуса, показ сохранённых данных при ошибке. Не заменять исправный кэш невалидным ответом.

## Альтернативы

- Добавить AJAX mode=soon по аналогии с другими лентами: такой контракт не подтверждён.
- Извлекать анонсы из главной: создаёт лишнюю зависимость.
- Сортировать по распознанной дате и скрывать неизвестные: меняет выдачу сайта и теряет записи.

## Последствия

Появляется ещё один публичный раздел с общими механиками каталога. Тесты используют обезличенную панель из реального ответа и проверяют все 36 записей, поля, неопределённую дату, пустой список, ошибки, запрос и независимый кэш. Штатная команда проверки протокола — make site-announcements.

Проверка в эмуляторе 2026-11-04: загружены 36 анонсов; проверены D-pad-переключение разделов, сохранение выбранной карточки и позиции, открытие третьего сезона «Властелина колец» и возврат Esc в список. Вход в аккаунт и настройки сохранены при обновлении тестовой сборки. make check: 289 JVM-тестов, 51 Python-тест, Android Lint; make ci-lint и make build-profile с R8 — успешно.
