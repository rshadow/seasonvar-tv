# ADR-0076: Упорядоченный список предпочитаемых озвучек

Дата: 2026-11-05

Статус: Принято

Заменяет [ADR-0075](0075-preferred-translation.md). Сохраняет приоритет контекста из ADR-0040 и откат неизвестной явно заданной озвучки из ADR-0042.

## Контекст

Для разных сериалов доступны разные студии. Пользователь выбрал несколько предпочтений в явном порядке и управление кнопками «Выше», «Ниже», «Удалить». Одиночная настройка не выходила в релиз; по решению пользователя совместимость и перенос её значения не требуются.

## Решение

В настройках оставить одну строку «Предпочитаемые озвучки»: название и пояснение слева, первая озвучка с числом остальных справа. Пустой список обозначать «Стандартная». Вся строка получает один фокус по ADR-0015.

По OK открывать отдельный диалог управления:

~~~text
Предпочитаемые озвучки
Первая доступная используется для просмотра.

1  AlexFilm                  [ ↑ ] [ ↓ ] [ × ]
2  LostFilm                  [ ↑ ] [ ↓ ] [ × ]
3  AniDub                    [ ↑ ] [ ↓ ] [ × ]

Поднять LostFilm выше
[ + Добавить озвучку ]
Если ни одна не доступна — стандартная.
~~~

- Номер и название выравниваются слева; справа каждой строки — три квадратные кнопки с небольшими общими закруглениями. Иконки центрированы, фон прозрачен, активный фокус использует обычное выделение темы. Под списком показывать пояснение сфокусированного действия с названием озвучки.
- Названия и номера не получают фокус. Стрелки влево/вправо переключают доступные действия строки, вверх/вниз — действия соседних строк. «Выше» у первой и «Ниже» у последней строки недоступны и пропускаются фокусом. Из последней строки вниз переходить на добавление; в конце диалога фокус останавливается.
- Перестановка меняет приоритет на одну позицию и сохраняет фокус на той же озвучке. Если прежнее действие стало недоступным, выбирать доступную стрелку либо удаление. После удаления выбирать ближайшую оставшуюся строку; после последней — «Добавить озвучку».
- «Добавить озвучку» снизу слева открывает список сайта с поиском и стандартной клавиатурой. При каждом открытии заново выполнять запрос фильтра golosa по контракту docs/api/web-api.md. Уже добавленные названия исключать с нормализацией регистра и пробелов. Выбранное значение добавлять в конец и возвращать фокус к добавленной строке. Отмена добавления возвращает к кнопке добавления; отмена управления — в меню настроек.
- Изменения порядка, добавление и удаление сохранять сразу; отдельных кнопок «Сохранить» и «Назад» нет. Для изменения порядка и удаления сеть не нужна. Справочник сайта не сохранять; ошибка сети не меняет список предпочтений.
- Хранить только упорядоченный список строковых названий без пустых значений и дублей. Числовые ID переводов не переносить между сезонами. Старую одиночную настройку не читать и не мигрировать.
- В новом сезоне выбирать первую однозначно сопоставленную доступную озвучку из списка. Неоднозначное название пропускать и проверять следующее. Если подходящих нет или список пуст, выбирать стандартную по ADR-0042.
- Явная озвучка источника и совместимое локальное продолжение имеют приоритет над предпочтениями. При известной серии без заданной озвучки искать её в переводах по тому же порядку приоритетов. Не заменять известную серию другой. Ручной выбор в карточке не изменяет список предпочтений; текущее видео не переключается.
- Использовать обычные компоненты Compose и существующие кнопки/тему. Для списка приоритетов применяется отдельный диалог управления вместо радиокнопок одиночного выбора из ADR-0015. Оба длинных списка отображать лениво со стабильными ключами, сеть и парсинг выполнять в фоне.

## Альтернативы

- Набор галочек без порядка: не определяет, какую из доступных студий предпочесть.
- Перетаскивание мышью: не подходит для основного управления пультом.
- Меню действий на каждой строке: требует дополнительного открытия для каждой перестановки.
- Сохранять прошлую одиночную настройку и создавать миграцию: пользователь разрешил заменить нерелизованную реализацию.

## Последствия и проверка

Можно один раз задать порядок студий для разных сериалов. Отсутствующая студия остаётся в предпочтениях для других сезонов. Удаление предпочтения не меняет историю или отметки аккаунта. Стандартная озвучка остаётся общим запасным вариантом, её не требуется добавлять отдельной строкой.

Автономные тесты проверяют сериализацию порядка, нормализацию и дубли, добавление только из актуального ответа, перестановку на границах и удаление последнего значения, отмену/повтор запроса, выбор первой доступной студии, неоднозначность, приоритет истории и продолжения, известную серию и смену сезона. Команды: `make check`, `make run-profile DEVICE=emulator-5554`. Проверка D-pad в эмуляторе дополняет тесты фокуса и компоновки; приставка используется только по явной команде пользователя.

2026-11-05: `make check` — 341 JVM-тест, 39 Python-тестов и Android Lint без ошибок. Profile-сборка с R8 проверена в эмуляторе: добавлены AlexFilm, LostFilm, AniDub из актуального списка сайта, порядок сохранился после перезапуска. Две перестановки AniDub дали ожидаемый порядок и фокус на той же озвучке; недоступные стрелки пропускались. Проверены последовательное удаление до пустого списка, фокус на добавлении, отмена добавления и возврат в меню настроек. После проверки восстановлен исходный пустой список. Приставка и код плеера не изменялись.
