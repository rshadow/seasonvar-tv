# ADR-0038: Компактная строка отметок аккаунта

Дата: 2026-11-03. Статус: принято. Пересматривает формат строк из [ADR-0037](0037-account-mark-details.md).

## Контекст

Подпись «Статус на сайте» не объясняет назначение сообщения, а две отдельные строки занимают лишнее место. Пользователь предложил объединить отметки либо выровнять вторую вправо.

## Решение

В большой карточке над лентой и в открытой карточке показываем одну текстовую строку: «Отметка просмотра: … · …». Первая часть — `.pgs-marks-current`, вторая — исходное сообщение `.pgs-marks-mess`, например «Новые серии». Общую подпись «Статус на сайте» убираем. Сообщение сохраняет формулировку сайта.

Пустые значения и лишний разделитель не показываем. Если остаётся только сообщение, выводим его без префикса. Длинный текст переносится по доступной ширине, без обрезания. Текст не получает фокус. Миниатюры по-прежнему не показывают отметки аккаунта; правила хранения и смены сезона из ADR-0037 действуют.

## Альтернативы и последствия

Выравнивание сообщения вправо создаёт большой разрыв между связанными данными и требует отдельного поведения при нехватке ширины. Общая строка через разделитель компактнее и естественно переносится на узком экране. Две независимые строки больше не используются.
