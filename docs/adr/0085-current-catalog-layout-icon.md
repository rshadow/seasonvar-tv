# ADR-0085: Иконка текущего вида каталога

Дата: 2026-11-05

Статус: Принято

## Контекст

Переключатель ADR-0083 показывал значок следующего вида. Поэтому при открытой ленте пользователь видел сетку, а прежний значок ленты напоминал другую плитку. Пользователь подтвердил понятные значки, соответствующие текущему расположению карточек.

## Решение

- Кнопка показывает текущий вид: четыре одинаковых квадрата в два ряда для сетки и три одинаковых вертикальных прямоугольника в один ряд для горизонтальной ленты.
- Значки имеют одинаковый холст, расположены по центру и используют общие размер и цвет иконок из темы. Размер кнопки, закругления и подсветка фокуса сохраняются.
- Одно нажатие переключает вид текущего списка. Доступное название описывает действие («Показать сеткой» / «Показать лентой с описанием»), а семантическое состояние сообщает текущий вид («Сетка» / «Лента с описанием»).
- Выбор по каждому списку, размеры карточек и навигация ADR-0083/0084 сохраняются.

## Альтернативы

- Значок следующего вида обозначает действие, но пользователь принимает его за текущую раскладку.
- Вертикальный список с текстовыми строками плохо соответствует горизонтальной ленте приложения.

## Последствия

Иконка напрямую соответствует виду каталога на экране. Нажатие меняет и раскладку, и её значок; отдельная подпись в шапке не требуется.

Уточняет обозначение кнопки в [ADR-0083](0083-catalog-layout-selection.md). Основание: пользователь подтвердил сетку из четырёх квадратов и горизонтальную ленту из трёх вертикальных карточек.
