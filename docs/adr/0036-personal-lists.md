# ADR-0036: Четыре вкладки личного списка

Дата: 2026-11-03. Статус: принято.

## Контекст

После входа уже доступен общий раздел «На чём остановились». Пользователь просит добавить остальные четыре списка аккаунта. Текущая страница `/resume` содержит их отдельными вкладками; разметка проверена на авторизованном аккаунте 2026-11-03 и описана в [ADR-0034](0034-resume-current-markup.md).

## Решение

После входа показываем в левом меню пять личных разделов после «Сегодня»:

| Раздел | Вкладки `data-tabr` страницы `/resume` |
| --- | --- |
| На чём остановились | `marks-new`, затем `marks-nonew` в порядке страницы |
| Есть обновления | `marks-new` |
| Нет новых серий | `marks-nonew` |
| Хочу посмотреть | `marks-want` |
| Посмотрел | `marks-watched` |

Каждый раздел загружает авторизованный `GET /resume` при первом открытии и по кнопке обновления. Парсер выбирает только нужные вкладки, включая скрытые на сайте. Сохраняем порядок строк и отдельные отметки одного сезона. Отсутствующая вкладка или повреждённая строка означает ошибку разметки; существующая пустая вкладка после проверки авторизации означает пустой список. Старый `.pgs-marks-bn` поддерживается только для общего раздела.

Используем общие карточки каталога, фоновые запросы и обработку ошибок. У каждого раздела свой экземпляр `PersonalListViewModel`, выбранная карточка, позиция ленты и фокус. Наведение на пункт меню сразу открывает раздел; вправо или OK переводит фокус в содержимое. Escape/Назад из карточки возвращает в ту же ленту. Меню прокручивается, когда все пункты не помещаются.

При обновлении остаются прежние карточки, индикатор работает на кнопке. При выходе, истечении или смене сессии очищаются все личные списки и их позиции. Личный HTML и списки остаются только в памяти, хранение cookie соответствует [ADR-0033](0033-account-and-resume.md).

## Альтернативы

- Один общий список: скрывает различия между запланированными, просмотренными и текущими сериалами.
- Подменю внутри аккаунта: добавляет нажатия для перехода между разделами.
- Общий сохранённый снимок страницы для всех списков: потребует отдельного срока жизни и согласования обновления; сейчас каждый раздел обновляется независимо.

## Последствия

Четыре вкладки доступны без изменения способов входа и воспроизведения. При первом открытии каждого раздела выполняется отдельный запрос. Добавление и удаление отметок, серверное сохранение прогресса и продолжение с точного времени аккаунта остаются отдельными задачами. Тесты используют синтетические ответы, не личные данные.
