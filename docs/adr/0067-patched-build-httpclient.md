# ADR-0067: Исправленный Apache HttpClient в инструментарии сборки

Дата: 2026-11-04

Статус: Принято

## Контекст

Dependabot №57 обнаружил CVE-2020-13956 в транзитивном Apache HttpClient. Версии до 4.5.13 могут неверно выбрать узел назначения для некорректного URI.

Реальный полный граф показывает HttpClient 4.5.14 в корневом classpath AGP 9.5.0 и отдельную уязвимую 4.5.6 в androidLintTool. Обновления только корневого classpath недостаточно. В конфигурациях APK этой библиотеки нет.

## Решение

Закрепить уже используемую AGP исправленную 4.5.14 в buildHttpClientVersion в gradle.properties. Добавить ограничение корневого buildscript и правило разрешения зависимости в отдельном androidLintTool. POM и JAR официального Maven Central закрепить в toolchain.lock.json с SHA-256 после сверки SHA-1.

Добавить HttpClient в make check-resolved-dependencies. Проверка должна обнаруживать старую версию в любой конфигурации, в том числе в Lint при исправленном AGP. Подтвердить отказ на сохранённом реальном графе до исправления и успешную проверку заново разрешённого графа.

Подготовить отдельный PR для этого предупреждения. После подготовки отдельного следующего PR для Commons Lang проверить оба изменения вместе локально: make check, make ci-lint, make codeql-build и make build BUILD_TYPE=release. Перед слиянием должны пройти обязательные проверки GitHub.

## Альтернативы

- Закрыть предупреждение вручную: оставляет старую библиотеку.
- Ограничить только buildscript: не исправляет отдельный classpath Android Lint.
- Перейти на HttpClient 5: меняет координаты и API сторонних инструментов без необходимости.

## Последствия

Изменяется инструментарий, сетевой клиент приложения остаётся OkHttp. Полный граф защищает от возврата старой версии в независимой конфигурации. После слияния нужно проверить публикацию исправленного графа main; успех сборки не подтверждает закрытие предупреждения в интерфейсе Security.
