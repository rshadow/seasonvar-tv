# ADR-0132: Компактная страница каталога

Дата: 2026-11-10

Статус: Принято

Завершает выбор компоновки из [ADR-0126](0126-catalog-inline-filters.md). Порционный источник определён в [ADR-0131](0131-windowed-list-parsing.md).

## Контекст

Постоянные фильтры должны оставлять место описанию выделенного сериала и результатам. Полная форма условий и крупные карточки одновременно на телевизоре не помещаются.

## Решение

Отдельная кнопка каталога находится между поиском и аккаунтом. При открытии фокус получает первое условие. Верхняя строка условий содержит страну и производство, жанры, год, число сезонов и рейтинг. Вторая — «Применить» слева, озвучку, качество и субтитры, личные ограничения, сортировку и «Сбросить» справа. Кнопки показывают выбранные значения; длинные подписи сокращаются, полные значения доступны в диалоге соответствующего условия.

Условия выбираются в диалогах с общими строками выбора и радиокнопками. Страна может исключаться; несколько жанров независимо включаются, исключаются или не учитываются. Год, число сезонов и рейтинговая группа имеют сравнение. Личные ограничения заблокированы до входа. Применение выполняет один запрос; сброс сразу возвращает отсутствие ограничений и сортировку по добавлению. Общие значения сохраняются локально, личные — отдельно для владельца.

Ниже фильтров постоянно располагается описание выделенного сериала, затем горизонтальный список. Для компактного каталога используется меньшая минимальная ширина карточки из общей темы; расчёт размеров, компонент списка, окно подготовки и кэши общие. Переключатель плитки на этой странице не показывается, чтобы описание оставалось видимым. Компоновка других списков сохраняется.

Высота строк фильтров берётся из общей темы. Подписи действий центрирует `ThemeButton`; строки выбора используют общее `FilterRow`. Загрузка и блокировка сохраняют места кнопок. Список не теряет выделение после диалога или возвращения из карточки.

## Альтернативы и последствия

Полная форма вытесняет описание. Общая выдвижная панель скрывает выбранные условия и отвергнута для каталога. Компактные кнопки оставляют место описанию, но требуют отдельного диалога для подробных условий. Крупные постеры показываются в полной карточке; каталог предназначен для подбора из большого списка.
