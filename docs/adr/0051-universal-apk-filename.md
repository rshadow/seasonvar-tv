# ADR-0051: Суффикс universal в имени APK

Дата: 2026-11-03

Статус: Принято

Уточняет формат имени из [ADR-0050](0050-github-actions-builds-and-releases.md).

## Контекст

APK содержит библиотеки для `armeabi-v7a`, `arm64-v8a`, `x86` и `x86_64`. Пользователь попросил явно обозначить универсальную сборку в имени файла.

## Решение

Распространяемый подписанный APK называть `seasonvar-tv-<versionName>-universal.apk`. Например, `seasonvar-tv-0.2.0-universal.apk`; для prerelease — `seasonvar-tv-0.3.0-beta.1-universal.apk`.

`make release-package` использует это имя при копировании APK и в `SHA256SUMS`. GitHub Actions загружает полученный файл в артефакты и Releases по существующей маске `*.apk`. Формат тега остаётся `v<versionName>`; суффикс относится только к имени APK.

## Альтернативы

- **Имя без архитектуры.** Не объясняет, какую сборку скачивает пользователь.
- **Отдельный APK для каждой ABI.** Сейчас не требуется: распространяется один файл со всеми четырьмя архитектурами.

## Последствия

Новые пакеты имеют явный суффикс `-universal`. Состав APK, подпись, `versionName` и `versionCode` от переименования не меняются. Упаковка обновляет имя в контрольной сумме и удаляет прежние APK из каталога выпуска.
