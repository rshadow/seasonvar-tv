# ADR-0028: Компоновка карточки по странице сайта

Дата: 2026-11-02

Статус: Компоновка и фокус пересмотрены в [ADR-0029](0029-series-controls-before-description.md). Рейтинги и правила выбора сохраняются. Первоначально пересматривал [ADR-0027](0027-tv-series-details.md).

Просмотр и локальное продолжение реализованы позднее в [ADR-0031](0031-native-playback.md); прежние упоминания заглушек описывают состояние на момент этого решения.

## Контекст

В первой карточке пользователь одобрил названия, строку жанров/страны/года, ленту и сетку серий. Отдельная прокрутка описания, обрезанные режиссёры/актёры, кнопка «О сериале» и большая кнопка просмотра оказались неудобны. Согласована компоновка ближе к оригинальному сайту: постер слева, название и описание справа, полные сведения ниже, затем просмотр и серии.

На странице [«Наруто»](https://seasonvar.ru/serial-2779--Naruto_pssrhvg-0-season.html) агент анонимно подтвердил дополнительные рейтинги IMDb и КиноПоиска, а также список из 220 серий. Рейтинги нужно показывать только при наличии в ответе сайта.

## Решение

```text
┌────────────────┬──────────────────────────────────────────────────┐
│ Главное меню   │ ┌──────────┐  Наруто                              │
│                │ │          │  Naruto                             │
│ Сегодня        │ │  Постер  │  Жанры · возраст · страна · год       │
│ Обновления     │ │          │  IMDb: 8.40 · КиноПоиск: 7.81         │
│ Топ            │ └──────────┘  Полное описание сайта.               │
│                │               Естественная высота всего текста.  │
│                │                                                  │
│                │ Режиссёр: полный список, с переносами строк       │
│                │ В ролях: полный список, с переносами строк        │
│                │ Другие имеющиеся сведения                        │
│                │                                                  │
│                │ [▶ Смотреть]  [Сезон ▾]  [Перевод ▾]              │
│                │ Серии                                            │
│                │ … [37] [38] [39] [40] [41] [42] …                 │
│                │                ↓                                 │
│                │          [Все серии]                            │
└────────────────┴──────────────────────────────────────────────────┘
```

- Правая карточка прокручивается целиком, меню остаётся на месте. У описания нет отдельной прокрутки, ограничения высоты и раскрывающей кнопки. Длинные страницы закономерно выходят за первый экран.
- Названия и метаданные находятся справа от постера. Жанры, возраст, страна и год сохраняют отдельную строку с переносом при необходимости. Рейтинги идут рядом с ними отдельной строкой: «IMDb: значение · КиноПоиск: значение»; отсутствующее значение не создаёт заглушку или пустое место. Сохраняется точность сайта, например `8.40`.
- Режиссёры, актёры и прочие сведения размещаются под постером на всю ширину карточки. Текст переносится и не обрезается. Кнопка и окно «О сериале» удалены.
- «Смотреть», сезон и перевод образуют компактный ряд. Ширина кнопки определяется подписью, высота — общим размером компактных кнопок темы. Если ряд не помещается, элементы переносятся. Единственный вариант остаётся текстом без фокуса; если номер единственного сезона не указан, пустая подпись «Сезон» не выводится.
- «Все серии» — отдельная строка под лентой. Из любой серии вниз переводит фокус на эту кнопку за одно нажатие; вверх с неё возвращает на выбранную серию. Кнопка не является последним элементом горизонтального списка.
- Сетка открывается на выбранном эпизоде; вверх/вниз перемещают по строкам, влево/вправо — по столбцам. Число столбцов зависит от ширины экрана. «Назад» закрывает сетку и возвращает фокус на «Все серии».

## Чтение и навигация

Начальный фокус — блок сведений в начале карточки: длинная страница не должна сама пролистывать название и описание ради кнопки просмотра. Вверх/вниз листают всю правую страницу с перекрытием соседних экранов. Внизу переходят к «Смотреть». Вправо с блока сведений сразу переводит фокус на действие просмотра, автоматически показывая его. Влево возвращает в меню.

В строке действий влево/вправо меняют действие, вверх возвращает к сведениям, вниз — к выбранной серии. В ленте сохраняются остановка на правой границе и возврат в меню с левой. Esc/«Назад», сохранение исходной карточки каталога, выбор перевода/сезона и отмена устаревших запросов продолжают действовать по ADR-0027. После смены сезона действия остаются видимыми, даже если новое описание длиннее.

Действия просмотра остаются заглушками. Модель будущего продолжения просмотра с серией и временем сохраняется; вход, воспроизведение и запись отметок этим решением не добавляются.

## Альтернативы и последствия

Фиксировать все блоки на первом экране пришлось бы за счёт сокращения описания и состава. Дополнительное окно метаданных требует лишнего действия. Единая прокручиваемая страница сохраняет порядок сайта и показывает полные тексты, но увеличивает расстояние до просмотра на длинных карточках; прямой переход вправо позволяет его пропустить.

Проверки парсера используют очищенную фикстуру рейтингов и полного списка 220 эпизодов. Фокус, доступ к «Все серии» из середины ленты и восстановление позиции проверяются в эмуляторе. Размеры и цвета остаются в общей теме по ADR-0008.

## Проверка

В эмуляторе Android TV API 34 проверены рейтинги «Наруто», полные режиссёры/актёры, прокрутка всей страницы и переход вправо к компактному действию просмотра. Из 37-й серии списка 220 эпизодов вниз за одно нажатие выбирает «Все серии»; сетка открывается на 37-й, после выбора 46-й возврат в ленту восстанавливает её. Смена сезона «Игры престолов» оставляет действия видимыми, закрытие возвращает на исходный сезон каталога. `make check`: 77 JVM-тестов, 13 тестов Python, Lint; `make build-profile` также прошёл.
