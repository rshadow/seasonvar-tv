# ADR-0062: Исправленные криптографические зависимости инструментария

Дата: 2026-11-04

Статус: Принято

## Контекст

При переходе на AGP 9.5.0 обязательный Dependency review в PR №3 нашёл `bcprov-jdk18on:1.80.2` в транзитивных зависимостях сборки. Версия уязвима к CVE-2026-8763 (critical) и CVE-2026-13506 (high). Оба исправления доступны начиная с Bouncy Castle 1.85; текущий стабильный выпуск — 1.86. Успешная компиляция и тесты приложения не проверяют отсутствие известных уязвимостей библиотек.

## Решение

В classpath корневого `build.gradle.kts` задать ограничения версии не ниже `1.86` для `bcprov-jdk18on`, `bcpkix-jdk18on` и `bcutil-jdk18on`. Согласованный набор относится к инструментам сборки; эти ограничения не добавляют Bouncy Castle в зависимости Android-приложения. Артефакты предварительной загрузки закрепить с URL и контрольными суммами в `toolchain.lock.json`.

Команда `make build-environment` показывает реально разрешённые зависимости сборки и используется для проверки применённых ограничений. После изменения выполнить тесты, Lint, компиляцию для CodeQL и оптимизированную сборку; перед слиянием дождаться Dependency review для нового коммита с подтверждённым графом зависимостей.

Порог Dependency review остаётся `high`. Предупреждения не исключаются из проверки и не получают разрешающий список ради слияния PR.

## Альтернативы

- Понизить порог серьёзности, исключить инструменты сборки или разрешить конкретные уязвимости. Не устраняет уязвимую библиотеку.
- Откатить AGP и отложить все обновления. Не требуется при наличии совместимого исправленного выпуска зависимости.
- Обновить только `bcprov`. Согласованный выпуск трёх используемых компонентов проще проверить с инструментарием AGP.

## Последствия

Проверяется и работа сборки, и отсутствие новых известных серьёзных уязвимостей по графу GitHub. При следующих обновлениях AGP ограничения можно удалить после подтверждения, что его собственные зависимости выбирают исправленные версии.
