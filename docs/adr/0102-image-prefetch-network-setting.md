# ADR-0102: Предзагрузка обложек в настройках сети

Дата: 2026-11-07. Статус: принято.

Уточняет расположение настройки из [ADR-0098](0098-catalog-image-prefetch.md).

Расширение действия этого же параметра на предварительную подготовку карточек принято и реализовано в [ADR-0127](0127-shared-list-preparation-window.md); место и сохранённое значение настройки сохраняются. Текущее название — «Подготавливать списки заранее».

## Контекст

Пользователь попросил перенести предзагрузку изображений в группу «Сеть»: она управляет дополнительными запросами и расходом трафика.

## Решение

Показывать «Загружать обложки заранее» первым пунктом «Настройки → Сеть», перед обходом блокировок и DNS. Сохранить галочку справа, пояснение и управление всей строкой по ADR-0015. Переходы фокуса проходят через границу групп без дополнительных остановок.

Параметр `image_prefetch` остаётся в прежнем хранилище `interface`: сохранённый выбор и значение по умолчанию не меняются. Сетевой транспорт и алгоритм предзагрузки не меняются.

## Альтернативы и последствия

Сохранение прежнего места в группе «Приложение» не соответствует выбранному расположению. Перенос данных в сетевое хранилище потребовал бы миграции без изменения поведения. Выбрано изменение только расположения строки.

Проверка: `make check` и визуальный проход по настройкам в profile-сборке эмулятора; галочка предзагрузки находится под заголовком «Сеть», переходы вверх и вниз работают с D-pad.

Проверено в profile-сборке: предзагрузка стоит первой в «Сети», сохранённое включённое значение осталось прежним. Переходы с автоперехода сезона к предзагрузке, затем к обходу блокировок и обратно работают пультом.
