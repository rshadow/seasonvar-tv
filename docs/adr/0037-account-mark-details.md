# ADR-0037: Отметки аккаунта в подробной карточке

Дата: 2026-11-03. Статус: формат строк пересмотрен в [ADR-0038](0038-compact-account-marks.md); остальные решения приняты. Уточняет отображение данных личных списков из [ADR-0036](0036-personal-lists.md).

## Контекст

Текст отметки и сообщение сайта ранее объединялись в подпись миниатюры. В короткой строке они обрезаются, а без подписей назначение полей неясно. Пользователь попросил оставить эти данные только в самой карточке сериала.

## Решение

- Личные отметки хранить отдельно в `SeriesEntry.accountMark`, не смешивать с `update` публичных подборок.
- На миниатюрах личных списков показывать название и сезон при наличии. Отметку и сообщение на них не выводить.
- В большой карточке выбранного сериала над лентой и в открытой подробной карточке выводить отдельные строки без обрезания: «Отметка просмотра: …» для `.pgs-marks-current` и «Статус на сайте: …» для `.pgs-marks-mess`. Текст значений сохранять как на сайте; пустые поля не показывать.
- Эти сведения не получают фокус. Использовать общую тему и прокрутку карточки.
- Отметка относится к исходному сезону из личного списка. При выборе другого сезона очищать её, чтобы не приписывать ему чужой прогресс.

## Альтернативы

Оставить объединённую подпись под постером — не решает обрезание. Удалить данные полностью — теряется полезная информация из аккаунта. Пересчитать отметку по локальному прогрессу — смешивает два пока не синхронизированных источника.

## Последствия

Миниатюры остаются компактными; значения аккаунта читаются с пояснением в большой карточке. Локальное продолжение и запись отметок на сайт этим решением не меняются.
