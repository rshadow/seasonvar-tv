# ADR-0093: Автопереход между сезонами

Дата: 2026-11-06

Статус: Принято

Дополняет [ADR-0080](0080-direct-episode-autoplay.md), изменяя ограничение очереди одним сезоном, и [ADR-0046](0046-player-episode-navigation.md).

## Контекст

После последней серии плеер останавливался даже при наличии следующего сезона. В TODO предусмотрены его загрузка и подбор озвучки. Пользователь попросил отдельную настройку, похожую на автоматическое включение следующей серии.

## Решение

- Рядом с «Следующая серия автоматически» добавить «Следующий сезон автоматически». Пояснение: «После последней серии запускаем следующий сезон, если он доступен». Галочка справа, одна точка фокуса на строку по ADR-0015; значение сохраняется на устройстве и по умолчанию включено.
- Настройки независимы: первая управляет переходами внутри сезона, вторая — после его последней серии. Выключение первой не запрещает переход после последней серии при включённой второй.
- Переход начинается только после фактического `STATE_ENDED`, без таймера, промежуточного подтверждения и обрыва видео.
- Свежая страница текущего сезона подтверждает, что закончился последний эпизод выбранной озвучки. Следующий сезон берётся из списка сезонов этого сериала, по номеру с сохранением порядка при неизвестном номере. ID не вычисляется; используется точная ссылка сайта. Страницы загружаются в фоне.
- Загружаем только ближайший следующий сезон и проверяем общий `serialId`. Не перескакиваем через недоступный сезон к более позднему.
- Озвучка выбирается по названию текущей, затем по упорядоченным предпочтениям пользователя, затем стандартная по ADR-0042/0076. Одинаковость ID озвучки между сезонами не предполагается. Трейлеры исключаются.
- Запускаем первый эпизод очереди выбранного перевода с начала, с полным списком серий нового сезона. Старое локальное время и серверная отметка нового сезона не подменяют этот переход. Дальнейшие переходы между сериями продолжают работать по обычным правилам.
- Если следующего сезона или доступных эпизодов нет, показываем существующую финальную панель. Ошибка сети, HTTP или разметки показывает ошибку плеера; «Повторить» повторяет поиск следующего сезона, а не перезапускает старую серию.
- При загрузке сезона видна обычная загрузка плеера, управление старым завершённым видео отключено. Назад/Esc закрывает плеер. Ручная смена серии, уход в фон, закрытие или выключение соответствующей настройки отменяют запрос; запоздалый ответ не запускает видео.
- Сохраняем завершение старой серии и последующий прогресс нового сезона существующим механизмом. Старую отметку не удаляем. При возврате карточка выбирает фактически проигрываемые сезон, озвучку и серию.
- Ручные кнопки предыдущей/следующей серии сохраняют границы текущего сезона. Скрытого ручного перехода между сезонами не добавляем.

## Альтернативы

- Общая галочка для всех переходов: пользователь попросил отдельную настройку для сезона.
- Переход по ID или совпадению номера озвучки: эти идентификаторы не задают порядок сезонов и соответствие названий.
- Пропускать недоступные сезоны: можно незаметно пропустить часть сюжета.

## Последствия и проверка

На границе сезона нужны два свежих запроса страниц, поэтому возможна пауза загрузки. Интерфейс остаётся отзывчивым. Обычная навигация внутри сезона и оригинальные списки сайта не меняются.

`make check` проверяет выбор сезона, озвучки, первой серии, недоступность, ошибки и возврат в карточку. `make player-probe DEVICE=emulator-5554` проверяет действительное видео до и после перехода, выключенный автопереход, паузу, перемотку и возврат с восстановлением настроек и локального прогресса. Кадры обязательно просматривать. Затем вернуть обычную тестовую сборку через `make run-profile DEVICE=emulator-5554` и проверить новый пункт настроек пультом.
