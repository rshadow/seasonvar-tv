# ADR-0200: Ручная отметка просмотра серии

Дата: 2026-11-21

Статус: Принято. Дополняет [ADR-0090](0090-shared-series-actions-menu.md) и [ADR-0169](0169-local-shared-card-marks.md).

## Контекст

Статус «Смотрю» сохраняет прежнюю отметку, если у сезона уже есть прогресс. Для серии, просмотренной вне приложения, нужно явно поставить отметку на выбранный эпизод.

## Решение

В карточке сезона фокус на серии в горизонтальном ряду определяет серию для меню `⋮`. После входа в аккаунт меню содержит действие «Отметить серию … как просмотренную», если выбрана обычная серия и известна озвучка. Действие доступно в карточке из главного экрана и из фильмографии актёра. Пункты меню миниатюры остаются прежними.

Запись использует `PlaybackMark` с ID открытого сезона, номером выбранной серии, ID озвучки и временем `00:00`. После ответа `msg=success` общая запись сезона обновляет прогресс и личные списки. Ручная отметка не создаёт запись истории воспроизведения. Отложенная автоотметка этого сезона сбрасывается после принятия ручной.

Если выбранная серия раньше текущей, порядок серий невозможно определить по их номерам или установлен статус «Посмотрел» либо «Не буду смотреть», приложение показывает текущую и новую отметки. В диалоге первый фокус получает «Отмена». При подтверждении ещё раз читаем состояние сайта. Если заменяемая отметка изменилась и по-прежнему требует согласия, подтверждение обновляется. Ошибка оставляет прежний прогресс.

## Альтернативы и последствия

Переиспользование пункта «Смотрю» поменяло бы смысл статуса в личных списках. Отдельная кнопка в ряду управления заняла бы место на карточке. Новый пункт использует существующее меню и добавляет одно действие на выбранной серии.

Сайт хранит одну отметку сезона. Если для продолжения доступна следующая серия той же озвучки, существующий механизм продолжения выбирает её. Независимая отметка каждой серии потребовала бы отдельного хранилища.
