# ADR-0164: компактное изображение запасного фона

Статус: принято. Дата: 2026-11-15. Уточняет [ADR-0162](0162-theme-fallback-background.md).

## Контекст и решение

Иконка запасного фона занимала весь экран. Пользователь хочет аккуратное изображение по центру примерно втрое меньше прежнего.

Атрибут темы `seasonvarPosterFallbackScalePercent` задаёт линейный масштаб запасного изображения относительно заполнения экрана. В «Стекле» значение равно 33%; базовое значение 100% также задаётся XML-ресурсом темы. Изображение сохраняет пропорции и центрируется по обеим осям; остальную область занимает основной цвет страницы. Размытие и затемнение сохраняются. Масштаб постеров не меняется.

## Альтернативы и последствия

Общий масштаб уменьшал бы также постеры. Отдельный масштаб запасного источника сохраняет настройки в XML темы и прежнее поведение остальных фонов. Он входит в ключ общего кеша, подготовка остаётся фоновой и ограниченной по размеру. Проверяем размеры и центр изображения, края экрана, повторное использование кеша и переходы между источниками.
