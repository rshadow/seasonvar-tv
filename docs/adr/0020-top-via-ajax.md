# ADR-0020: Раздел «Топ» через AJAX с общими механиками каталога

Дата: 2026-11-02

Статус: Принято

## Контекст

Пользователь выбрал раздел «Топ» через AJAX и те же механики, что в «Обновлениях». Проверенный публичный запрос `mode=pop` возвращает карточки той же разметки, без предварительного GET главной.

## Решение

- Добавить пункт «Топ» после «Обновлений». Получать `POST /ajax.php?mode=pop` с формой `ganre=&country=&block=0&main=1`, `Referer` главной и `X-Requested-With: XMLHttpRequest`.
- Считать ответ AJAX источником состава и порядка выдачи. Не пересортировывать по собственному рейтингу и не подгонять под встроенный HTML главной.
- Использовать общий `sidebar`-транспорт и парсер HTML-фрагментов для `new` и `pop`, общий `CatalogViewModel` и экран ленты. Галочка обхода и выбранный DNS применяются к новому запросу тем же клиентом.
- Хранить состояние списка, выбор карточки, позицию прокрутки и фокус отдельно для каждого раздела. Композицию ленты привязать к разделу, чтобы внутреннее состояние поиска фокуса не переносилось между выдачами. Загружать «Топ» при первом открытии, обновлять кнопкой, при смене сети и дня, как «Обновления».
- Хранить корректный ответ до 24 часов в `top-ajax.html`, отдельно от других лент. Сначала показывать кэш с фоновым обновлением. При ошибке сохранять хороший кэш и показывать предупреждение.
- Использовать общие постеры и их кэш, описания с кэшем 24 часа, бейдж «новинка» по метке сайта и фиксированный размер карточек с предпочитаемым русским названием. Правила — ADR-0018 и ADR-0019.
- Сохранять навигацию ADR-0013 и ADR-0014: раздел появляется по фокусу меню, OK/вправо входят в ленту, последняя карточка останавливает переход вправо, вверх ведёт на «Обновить», Esc/Back из описания возвращают на выбранную карточку.
- Ручную проверку запроса выполнять через `make site-top`; автономную — на сохранённом [ответе](../../app/src/test/resources/top-ajax.html), включая полный порядок всех позиций.

## Альтернативы

- Загрузка главной противоречит выбранному отдельному AJAX-источнику.
- Копирование экрана и парсера создаёт разные правила карточек и навигации для одинакового формата данных.
- Общий файл кэша или общая позиция списка смешивают состояние независимых подборок.

## Последствия и ограничения

В проверке 2026-11-02 сайт вернул HTTP 200, 28 729 байт HTML и 49 позиций. Количество не фиксируем в приложении. Алгоритм ранжирования и пагинация сайта не установлены. Раздел «Лучшие сериалы» остаётся отдельным пунктом плана, до проверки его источника.
