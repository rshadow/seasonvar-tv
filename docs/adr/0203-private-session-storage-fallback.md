# ADR-0203. Сохранение входа при сбое Android Keystore

Дата: 2026-11-22. Статус: принято. Дополняет [ADR-0033](0033-account-and-resume.md) и [ADR-0099](0099-preserve-session-on-storage-failure.md).

## Контекст

На приставке сайт подтверждает вход, а Android Keystore возвращает ошибку при создании ключа `K03-UNKNOWN`. Пользователю нужно сохранить вход между запусками.

## Решение

Приложение сначала пытается зашифровать сессию через Android Keystore. При ошибке шифрования после подтверждённого входа оно предлагает сохранить cookies в приватных настройках приложения без дополнительного шифрования. Согласие действует для этой сессии, включая обновление cookies. По умолчанию в диалоге выделен «Войти без сохранения». Эта кнопка и «Назад» оставляют новую сессию в памяти. Пароль на диск не записывается. Диагностика показывает способ сохранения и код исходной ошибки.

При восстановлении приложение предпочитает зашифрованную сессию. Если сохранены только cookies, приложение проверяет их на сайте и снова пробует шифрование. Запись зашифрованной сессии и удаление незашифрованной выполняются одной операцией. При выходе очищаются оба представления. Файл сессии исключён из резервного копирования и переноса между устройствами. [Правила резервного копирования Android](https://developer.android.com/identity/data/autobackup).

## Альтернативы и последствия

Хранение только в памяти требует нового входа после завершения процесса. Шифрование отдельной парольной фразой требует ввода с пульта при каждом восстановлении. Приватные настройки сохраняют вход без повторного ввода. Доступ к их файлу позволяет прочитать cookies. Подтверждение владельца на сайте предшествует показу его приватного кэша при восстановлении из незашифрованной сессии.
