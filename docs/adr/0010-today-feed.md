# ADR-0010: Раздел «Сегодня» из публичной главной сайта

Дата: 2026-11-01

Статус: Принято

## Контекст

Первый раздел каталога должен повторять сегодняшние обновления оригинального сайта и выбранную в [ADR-0006](0006-tv-navigation-and-content-layout.md) схему интерфейса.

## Решение

- Получать публичный HTML главной через OkHttp, разбирать Jsoup в отдельном слое данных. Старое API с ключом не использовать.
- Выбирать блоки `div.news` с сегодняшней датой в часовом поясе устройства. Сохранять порядок сайта и точные ссылки; одинаковую пару «страница + обновление» показывать один раз.
- Показывать описание выбранного сериала над горизонтальной ленивой лентой. По OK открывать полное описание с прокруткой; видео на этом этапе не запускать.
- Загружать описание страницы после короткой задержки выбора, отменять предыдущий запрос при смене карточки. Хранить описание до 24 часов.
- Показывать сохранённую главную только за текущий день, затем обновлять в фоне. Не выдавать вчерашний список за сегодняшний и не затирать хороший кэш невалидным ответом.
- Различать загрузку, пустой день, сетевую/HTTP-ошибку и изменение разметки. Отсутствие `div.news` считать ошибкой контракта.
- Использовать ViewModel, StateFlow и lifecycle-aware сбор состояния; сетевую подготовку, парсинг и файлы выполнять вне UI-потока. Постеры загружать Coil с кэшем и размером отображаемого компонента.
- Сохранять выбор, позицию ленты и фокус при возврате из описания и других разделов. У ленивых карточек использовать стабильные ключи и тип содержимого.

## Альтернативы

- Вчерашние обновления вместо пустого дня и зацикленная лента дублировали бы данные и меняли смысл раздела.
- Готовый сторонний каталог не сохраняет выдачу оригинального сайта.
- WebView затрудняет предсказуемую навигацию с пульта.

## Последствия и ограничения

Разметка сайта становится частью контракта, поэтому парсер проверяется автономными тестами; поля и селекторы описаны в [web-api.md](../api/web-api.md). Номер сезона необязателен: при отсутствии подписи его не придумываем.

На 2026-11-01 эмулятор Android TV API 34 получил 83 обновления, постеры и описание через транспорт из [ADR-0011](0011-network-bypass-setting.md). Вход и воспроизведение ещё не реализованы.
