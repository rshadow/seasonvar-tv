# ADR-0001: Хранить принятые решения в docs/adr

Дата: 2026-11-01

Статус: Принято

## Контекст

При разработке клиента Seasonvar для Android TV нужно сохранять принятые решения и основания их выбора в доступном участникам проекта месте.

## Решение

Все принятые решения о проекте записывать отдельными ADR в `docs/adr`. Вести реестр в [README.md](README.md). Для каждого решения описывать контекст, выбор, альтернативы и последствия.

## Альтернативы

- Хранить решения только в переписке: их сложнее найти при продолжении работы.
- Записывать всё в корневой README: история решений будет смешана с текущим описанием проекта.

## Последствия

Новые принятые решения сопровождаются ADR и обновлением реестра. Пересмотр оформляется новой записью со ссылкой на заменённую; история сохраняется.

Основание: указание владельца проекта от 2026-11-01 — «В docs/adr будем записывать все принятые решения».
