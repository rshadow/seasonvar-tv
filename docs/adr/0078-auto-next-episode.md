# ADR-0078: Автоматический переход к следующей серии

Дата: 2026-11-05

Статус: Заменено [ADR-0080](0080-direct-episode-autoplay.md).

Дополняет [ADR-0046](0046-player-episode-navigation.md).

## Контекст

Пользователь хочет смотреть серии подряд без пульта. На первом этапе переход ограничен текущим сезоном; переход между сезонами остаётся отдельной задачей.

## Решение

- В настройках добавить «Следующая серия автоматически», включённую по умолчанию. Название и пояснение слева, галочка справа; вся строка получает один фокус по ADR-0015. Выбор сохраняется на устройстве.
- После фактического завершения серии показывать справа внизу небольшую панель: «Следующая серия через 10 с», название следующей серии и кнопку «Отменить переход». Фокус сразу находится на отмене. Видео заранее не обрывать, порог просмотренности аккаунта не использовать как сигнал завершения.
- По истечении отсчёта запускать следующую запись очереди текущего сезона и озвучки с начала. Использовать порядок и идентификаторы сайта, не вычислять номер прибавлением единицы. Для последней серии или неполной очереди без известного соседа ничего не запускать и не зацикливать сезон.
- OK отменяет переход; стрелки и действия управления видео также отменяют отсчёт и сохраняют обычное назначение. «Назад»/Esc выходит из плеера. Отмена не запускает новый отсчёт на том же завершении; повторное воспроизведение серии позволяет запустить его заново.
- При уходе в фон, выходе, ошибке, ручном переходе или отключении настройки отменять ожидающий переход. В фоне автозапуск запрещён. Отключённая настройка не меняет ручные кнопки следующей/предыдущей серии.
- Сохранение локальной позиции, серверной отметки и выбранной серии при возврате использует прежние механизмы. Автопереход не создаёт отдельного вида отметок и не обходит ошибки загрузки.
- Длительность и ширина панели хранятся в ресурсах темы; текст — в строковых ресурсах. Протокол Seasonvar не меняется.

## Альтернативы

Мгновенный запуск не даёт отменить переход. Запуск до конца видео может обрезать содержимое. Переход между сезонами требует загрузки следующего сезона и повторного выбора озвучки; его реализуем отдельно.

## Последствия

Просмотр продолжается внутри выбранного сезона без дополнительных нажатий. Отсчёт проверяется модульными тестами; реальное видео, смена кадров после перехода, отмена, отключённая настройка, последняя серия, пауза, перемотка и возврат проверяются в эмуляторе. Состояния декодера не заменяют визуальную проверку изображения.
