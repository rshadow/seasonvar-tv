# ADR-0015: Единый формат пункта настроек

Дата: 2026-11-02

Статус: Принято

## Контекст

В настройках галочка находилась слева, а выбранный DNS — справа. Пользователь выбрал единое расположение элементов управления справа и попросил закрепить формат названия, пояснения и выбора опций.

## Решение

- Каждый пункт — строка на всю ширину содержимого. Слева располагается блок текста: короткое название сверху, пояснение назначения и эффекта настройки под ним.
- Названия и пояснения всех пунктов начинаются на одной вертикали. Название использует `titleLarge` и основной цвет текста, пояснение — `bodyLarge` и вторичный цвет.
- Справа располагается элемент управления: галочка для логического параметра или текущее значение для выбора из списка. Его правая граница выровнена по общему внутреннему отступу, по вертикали — по центру строки.
- Текстовый блок занимает оставшееся место; между ним и элементом управления есть общий интервал. Пояснение переносится по словам, высота строки определяется содержимым.
- Цвета, внутренние отступы, расстояния и рамка фокуса берутся из общей темы по [ADR-0008](0008-centralized-ui-theme.md).

Схема:

~~~text
┌───────────────────────────────────────────────────┐
│ Название                                [контроль]│
│ Пояснение назначения настройки                    │
└───────────────────────────────────────────────────┘
~~~

### Фокус и выбор

- Вся строка — одна точка фокуса с заметной рамкой. Название, пояснение и декоративная галочка внутри неё не создают дополнительных остановок.
- Вверх/вниз перемещают фокус между пунктами, пропуская подзаголовки групп. Стрелка влево возвращает фокус в меню.
- Для логического параметра OK или клик по любой части строки сразу переключает значение.
- Для параметра с набором опций OK или клик открывает диалог с радиокнопками. В этом списке названия опций выровнены слева, радиокнопки — справа. Первоначальный фокус стоит на текущем значении.
- Стрелки в диалоге перемещают фокус без изменения настройки. OK или клик выбирает ровно одну опцию, сохраняет значение, закрывает диалог и возвращает фокус на исходную строку.
- Esc/«Назад» закрывает диалог без изменения настройки и возвращает фокус в меню текущего раздела по [ADR-0013](0013-navigation-without-back-buttons.md). Выбор параметра и отмена остаются разными действиями.
- Список опций может расширяться; текущий выбор всегда виден в строке настройки.

## Альтернативы и последствия

Разное расположение галочки и выбранного значения нарушало единое выравнивание. Отдельная кнопка изменения требовала бы дополнительной остановки фокуса. Выбранный формат позволяет читать названия по одной вертикали и менять значение одним нажатием на пункт.

Формат применяется к обходу блокировок и DNS. Способ хранения и независимость этих параметров остаются описаны в ADR-0011 и ADR-0012.
