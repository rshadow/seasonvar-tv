# ADR-0167: заданные размеры кнопки не требуют естественных измерений

Статус: принято. Дата: 2026-11-15. Уточняет реализацию [ADR-0125](0125-button-content-alignment.md).

## Контекст

Общая кнопка вычисляла максимальную естественную ширину и минимальную высоту даже при уже заданных ширине и высоте. Профиль переключения разделов подтвердил затраты на эти запросы и измерение текста; подключённая Compose 1.11.4 не пропускает их для фиксированных ограничений.

## Решение

Один узел `Modifier.Node` рассчитывает размеры содержимого общей текстовой кнопки. Фиксированная сторона берётся из входных ограничений без запроса естественного размера. Для свободной ширины запрашивается максимальная естественная ширина полной подписи; для свободной высоты — минимальная высота при уже выбранной ширине. Ограничения родителя сохраняются.

Естественные запросы родителей также сохраняют этот контракт. Отдельные размеры, резервирование ширины и локальные отступы для экранов не вводятся. Центрирование и левый столбец строк с галочками остаются общими по ADR-0125.

## Альтернативы и последствия

Удаление расчёта естественных размеров целиком растягивает компактные кнопки; расчёт по самому короткому слову обрезает длинные подписи. Сохраняем прежние правила и пропускаем только вычисления, результат которых уже задан родителем.

Тесты проверяют отсутствие запросов для фиксированных сторон, свободные стороны и пределы родителя. Геометрия, длинные подписи, управление, загрузка и блокировка дополнительно проверяются в эмуляторе для обеих тем.
