# Принятые решения

Все принятые решения о проекте записываем здесь в виде ADR (Architecture Decision Record).

Одна запись — одно решение. Имя файла: `NNNN-short-title.md`, номера последовательные и не переиспользуются.

В записи указывать:

- дату и статус;
- контекст;
- принятое решение;
- рассмотренные альтернативы;
- последствия и ограничения.

Предложение не считать принятым решением. При пересмотре создавать новую запись, связывать её с прежней и отмечать прежнюю как заменённую, сохраняя историю.
