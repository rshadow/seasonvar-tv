# ADR-0162: запасной фон темы для экранов без постера

Статус: принято. Дата: 2026-11-14. Уточняет отсутствие источника в [ADR-0158](0158-selected-list-poster-background.md), расширяет конфигурацию [ADR-0161](0161-resource-defined-interface-themes.md).

## Контекст

На экранах настроек и информации о приложении нет выбранного сериала. Пользователь хочет сохранять стеклянное оформление с размытым фоном и использовать для него предопределённое изображение.

## Решение

Атрибут темы `seasonvarPosterFallbackImage` задаёт локальный drawable. В «Стекле» используется иконка приложения, в классической теме фоновые изображения выключены. Запасной источник показывается при отсутствии выбранного постера, включая загрузку, ошибку изображения и пустые списки. Появление постера переключает фон на него. Экран рецензий и подготовка просмотра используют тот же запасной фон; видеоплеер остаётся без декоративного изображения.

Локальный ресурс растеризуется до ограниченного размера и обрабатывается вне главного потока. Размытие, затемнение, переходы и LRU-кеш общие с постерами. Ключ учитывает ресурс и параметры подготовки. Сетевых запросов и отдельного кеша нет, разметка и фокус не меняются.

## Альтернативы и последствия

Однотонная заливка нарушает выбранное оформление. Сохранение последнего постера связывает фон настроек с предыдущим экраном и может показывать чужой сериал. Локальный ресурс даёт постоянный фон без загрузки; тема может заменить его другим drawable без изменения Kotlin. Проверяем отсутствие постера, возврат к выбранному сериалу, выключение темы, повторное использование кеша и читаемость настроек.
