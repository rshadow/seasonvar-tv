# ADR-0007: Исследование сайта через локальный HTTPS-загрузчик с DPI-стратегией

Дата: 2026-11-01

Статус: Принято

## Контекст

Прямой HTTPS-доступ к Seasonvar из среды разработки сбрасывается или возвращает неподходящий сертификат; HTTP приводит на страницу блокировки оператора. Одного разрешения имени через Quad9 оказалось недостаточно.

В прежнем обсуждении пользователь подтвердил работу стратегии ByeByeDPI `-o1 -a1 -r-5+se`. Сохранился Python-скрипт `dpitest.py`, реализующий её TCP/TLS-приёмы. Пользователь поручил сделать проектный скрипт для получения страниц сайта.

## Решение

- Добавить целевой загрузчик публичных HTTPS-страниц Seasonvar на Python со стандартной библиотекой.
- Использовать разделение TLS-записи за пять байт до конца SNI и отправку TCP OOB-байта по найденной стратегии. UDP-параметр `-a1` для HTTPS не применяется.
- Сохранять штатную проверку сертификата и имени сайта. TLS-данные обрабатывает OpenSSL; скрипт меняет границы записей и способ отправки начального ClientHello.
- Получать адреса через Quad9 DoH с проверкой TLS. Для HTTP/2 у DoH использовать curl, уже входящий в базовый инструментарий проекта.
- Поддерживать анонимные GET-запросы и редиректы в пределах HTTPS-доменов оригинального сайта. Результат сохранять в локальный файл; для главной проверять наличие блоков обновлений.
- Предоставить `make site-fetch` и `make site-test` согласно [ADR-0005](0005-reproducible-local-development.md). Автономные проверки включить в общие цели тестирования.
- Инструкцию, ограничения и результаты живой проверки вести в [docs/api/access.md](../api/access.md).

## Альтернативы

- **Прямой HTTPS с Quad9.** Не обеспечил доступ в проверенной сети.
- **Отключение проверки сертификата.** Не позволяет подтвердить ответ оригинального сайта.
- **Глобальный прокси или VPN.** Меняет маршрутизацию других программ и требует отдельной настройки. Для текущего исследования достаточно целевого загрузчика.

## Последствия и ограничения

Появился проверенный способ получать главную страницу и поисковый JSON для исследования контракта сайта. Дополнительные Python-зависимости и постоянный локальный сервер не нужны.

Метод зависит от сети и поведения сервера. Скрипт не реализует весь ByeDPI и не предназначен для авторизации, передачи cookie или воспроизведения видео. Применение DPI-стратегии в Android-клиенте потребует отдельного решения.

Основание: пользователь попросил восстановить прежнюю рабочую стратегию и сделать скрипт для доступа к интерфейсам Seasonvar.
