# ADR-0017: Загружать «Обновления» отдельным AJAX-запросом

Дата: 2026-11-02

Статус: Принято

Пересматривает источник списка в [ADR-0016](0016-updates-feed.md). Правила отображения, порядка, навигации и срока кэша сохраняются.

## Контекст

Пользователь выбрал независимую загрузку «Обновлений», без получения главной страницы. Публичный AJAX-запрос вкладки подтверждён в официальном JavaScript и проверен без cookie и предварительного GET главной.

При сравнении ответы различались: AJAX содержал 11 позиций перед первой записью встроенной подборки, следующие 39 ссылок совпадали с началом списка главной. Пользователь подтвердил, что сохраняем AJAX несмотря на это различие. Внутренняя причина различия на стороне сайта не установлена.

## Решение

- Отправлять `POST https://seasonvar.ru/ajax.php?mode=new` с формой `ganre=&country=&block=0&main=1`, заголовками `X-Requested-With: XMLHttpRequest` и `Referer: https://seasonvar.ru/`.
- Разбирать ответ как HTML-фрагмент с карточками `a.pst.rside-p[href]` без оболочки главной. Не выполнять JavaScript и не загружать главную как запасной источник при ошибке AJAX.
- Считать AJAX-ответ источником состава и порядка «Обновлений». Совпадение с начальной подборкой в HTML главной не требуется; подгонять выдачу под неё не нужно.
- Сохранять весь порядок ответа, включая разные обновления/озвучки одного сезона. Номера серий передавать как текст сайта, включая встреченную «0 серия».
- Использовать существующий сетевой клиент с выбранными DNS и обходом, проверкой TLS, отменой запросов и ограничением размера ответа. Не следовать редиректам POST, чтобы не подменять ошибку ответом другой страницы.
- Хранить фрагмент в отдельном файле `updates-ajax.html` до 24 часов. Старый кэш главной `updates.html` не читать. Описания и постеры продолжают использовать свой кэш.
- Проверять парсер на сохранённом анонимном [ответе AJAX](../../app/src/test/resources/updates-ajax.html), формат POST — автономным тестом. Ручную проверку запроса выполнять через `make site-updates`.

## Альтернативы

- HTML главной — предыдущая реализация, зависящая от загрузки всей страницы.
- Запрос JSON заголовком `Accept` не переключил сервер: проверка вернула тот же HTML. Отправка JSON-тела вместо формы также вернула HTML. JSON-контракт не установлен.

## Последствия и ограничения

Список больше не зависит от разметки главной. Зависимость от HTML карточек остаётся: AJAX возвращает HTML, а не JSON. В проверке 2026-11-02 получены HTTP 200, 30 828 байт, 50 позиций на 49 страниц сезонов. Пагинация не добавляется без подтверждения протокола. «Сегодня» продолжает получать главную своим запросом; это не предварительный шаг для «Обновлений».
