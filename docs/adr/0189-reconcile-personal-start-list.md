# ADR-0189. Сверка личного стартового списка

Статус: принято. Дата: 2026-11-18. Уточняет [ADR-0188](0188-cached-personal-start.md).

## Контекст

Переход с кеша на обычную загрузку меняет источник списка и сбрасывает подготовку карточек при подтверждении сеанса. Это заметно даже при одинаковом ответе сайта.

## Решение

Пока сайт проверяет аккаунт и обновляет данные, видимый список сохраняет данные кеша. При подтверждении того же аккаунта с теми же фильтрами подготовленные карточки остаются в памяти. Запросы описаний и действия с аккаунтом включаются после подтверждения.

Свежие карточки сверяются с видимыми в фоне. Совпадение данных и порядка сохраняет экземпляр списка. При отличиях индекс по ключу позволяет переиспользовать неизменившиеся карточки и применить новый порядок одним обновлением. Если перемещение увело бы выбранную карточку за пределы экрана, прокрутка удерживает её в видимой области.

Порция свежих карточек образует начало списка. Записи, судьба которых ещё неизвестна, сохраняются в хвосте до полной выдачи. Явное локальное исключение сезона применяется сразу. Смена владельца, фильтров или раздела сбрасывает данные сверки.

## Альтернативы и последствия

Замена всего списка упрощает передачу состояния, но создаёт переход и для одинаковых данных. Публикация вставок и удалений по одному добавляет промежуточные состояния с собственной прокруткой. Сверка по ключу берёт порядок с сайта и занимает в среднем линейное время от числа старых и свежих записей. Для отличающегося ответа требуется индекс старых карточек.
