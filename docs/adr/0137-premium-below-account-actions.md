# ADR-0137: Премиум под действиями аккаунта

Дата: 2026-11-10

Статус: Принято; уточняет размещение из [ADR-0135](0135-account-premium-expiration.md).

## Контекст

Пользователь попросил отделить сведения о премиуме от действия выхода пустой строкой.

## Решение

Слева показывать имя, пояснение о входе и кнопку «Выйти из аккаунта», справа — аватар по ADR-0136. Под этой областью размещать срок премиума и подсказку о HD. Между кнопкой и блоком премиума оставлять интервал не меньше строки текста, используя размеры общей темы.

Сохранять зарезервированную строку подсказки при отсутствии активного премиума. Обновление сведений не перемещает кнопку выхода и аватар; тексты премиума не получают фокус.

## Альтернативы и последствия

Размещение премиума перед кнопкой смешивает справочные сведения и действие. Отдельный блок занимает больше высоты, но сохраняет порядок действий при загрузке. Источник даты и условия показа HD из ADR-0135 не меняются. Проверка разметки подтверждает порядок, разделительный интервал и стабильность действия выхода.
