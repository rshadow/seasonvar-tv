# ADR-0206. Системный выбор распознавателя для комментариев

Дата 2026-11-25. Статус принят. Заменяет [ADR-0205](0205-comment-voice-ugoos.md) и уточняет [ADR-0204](0204-write-season-comments.md).

## Контекст

Пользователь выбирает распознаватель в настройках Android. Пустой результат USearch на X5M привёл к временному выбору Google TV в редакторе. Владелец приложения подтвердил, что редактор должен уважать системную настройку.

## Решение

Кнопка «Голосом» отправляет стандартный неявный запрос `ACTION_RECOGNIZE_SPEECH`. Android выбирает обработчик по настройкам устройства. В черновик вставляется первый непустой вариант результата. При отмене черновик сохраняется. Пустой результат и ошибки обработки показываются пользователю.

## Альтернативы и последствия

Временный выбор Google TV менял обработчик, выбранный пользователем. Системный выбор даёт одинаковый порядок запуска в поиске и в комментариях. Если выбранный распознаватель возвращает пустой результат, причина выясняется в его настройках и работе на устройстве.
