# ADR-0199: Расположение действий в каталоге

Дата: 2026-11-21

Статус: Принято. Уточняет [ADR-0132](0132-compact-catalog-page.md).

## Контекст

«Применить» и «Сбросить» стояли на противоположных концах строки. Обе кнопки действуют на весь набор условий каталога.

## Решение

Во второй строке после сортировки расположены текстовая кнопка «Применить» и кнопка сброса с иконкой воронки и крестика. При фокусе на сбросе видна подсказка «Сбросить фильтры и сортировку». Она не сдвигает описание и постеры. Обновление выдачи доступно по отдельной иконке в заголовке.

Стрелки влево и вправо перемещают фокус по строке. При переходе между строками фокус следует по столбцам. Над кнопкой сброса фокус переходит на «Рейтинг». Стрелка вниз со второй строки фокусирует выбранный постер. Стрелка вверх с постера возвращает к кнопке, с которой пользователь вошёл в выдачу. До первого такого перехода используется «Применить».

## Альтернативы и последствия

Рассмотрели иконки для обоих действий. Текст «Применить» показывает, что выбранные условия вступают в силу после нажатия. Компактная кнопка сброса оставляет место под длинные значения сортировки в пределах двух строк.
