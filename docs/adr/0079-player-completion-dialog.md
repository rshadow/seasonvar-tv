# ADR-0079: Основное действие после окончания серии

Дата: 2026-11-05

Статус: Заменено [ADR-0080](0080-direct-episode-autoplay.md).

Частично пересматривает [ADR-0078](0078-auto-next-episode.md): длительность отсчёта, компоновку, начальный фокус и отмену. Ограничение текущим сезоном, сохранение озвучки и включение по умолчанию сохраняются.

## Контекст

После окончания серии основной путь — продолжить просмотр. Пользователь выбрал явную первую кнопку перехода, отсчёт 5 секунд и возврат из плеера вместо остановки на завершённом видео. Название «К сериалу» обозначает результат возврата.

## Решение

При включённом автопереходе и завершении видео показывать компактную панель справа внизу:

~~~text
┌───────────────────────────────┐
│ Следующая серия 7             │
│                               │
│               5               │
│                               │
│  [ Перейти ]   [ К сериалу ]   │
└───────────────────────────────┘
~~~

- Название следующей серии находится сверху. Под ним по центру — только цифра обратного отсчёта, вдвое крупнее текста заголовка, обычным цветом текста. Размер задаётся множителем в themes.xml.
- Отсчёт длится 5 секунд после фактического завершения видео. По истечении запускать следующую серию с начала, в текущем сезоне и озвучке.
- «Перейти» слева — первая кнопка и начальный фокус, сразу запускает следующую серию. «К сериалу» справа закрывает плеер, отменяет ожидающий переход и возвращает в карточку с сохранением выбранной серии.
- Стрелки влево/вправо переключают две кнопки; на краях, сверху и снизу фокус остаётся в панели. OK/Enter выполняет выбранное действие. «Назад»/Esc возвращает в карточку, как и в остальном плеере.
- Для последней известной серии показывать «Следующей серии нет», без цифры, отсчёта и кнопки перехода. Единственная кнопка «К сериалу» сразу получает фокус. Новый сезон автоматически не загружать.
- При выключенном автопереходе сохранять прежнюю ручную панель плеера, без этого предложения. Ошибка, выход и уход в фон отменяют ожидающий запуск. Ручные кнопки переключения серий продолжают работать.

## Альтернативы

Фокус на отмене требует лишнего движения для основного действия. «Отмена» с остановкой на последнем кадре не завершает просмотр, а её название не объясняет возврат. Крупный текст всего сообщения отвлекает от кнопок; крупной остаётся только цифра.

## Последствия

Следующую серию можно запустить одним нажатием, а отказ возвращает в карточку. Проверять первичный фокус, немедленный запуск, автоматический переход через 5 секунд, возврат второй кнопкой, последнюю серию, паузу, перемотку и реальные сменяющиеся кадры после переходов.
