# ADR-0077: Подсказка о внешних сетевых инструментах

Дата: 2026-11-05

Статус: Принято

Дополняет настройки сети из [ADR-0011](0011-network-bypass-setting.md) и [ADR-0012](0012-dns-provider-setting.md). Оформление следует [ADR-0008](0008-centralized-ui-theme.md) и [ADR-0015](0015-settings-item-format.md).

## Контекст

Встроенные настройки помогают не во всех сетях. Пользователь выбрал краткое пояснение с рекомендацией отключить неработающие настройки и попробовать внешние инструменты.

## Решение

- Под существующим пояснением о применении сетевых настроек показывать текст: «Если настройки не помогают, отключите их и попробуйте внешние инструменты для решения сетевых проблем.»
- Оформить его как статичный справочный текст: bodyLarge, вторичный цвет текста и малый интервал из общей темы. Переносить текст по ширине содержимого.
- Фокус пульта остаётся на строках настроек; подсказка входит в прокручиваемое содержимое экрана.

## Альтернативы

- Пояснение рядом с заголовком группы: отдаляет совет от самих настроек.
- Отдельный диалог: требует дополнительного действия для чтения справки.

## Последствия

Подсказка доступна на экране настроек сети и напоминает о следующем шаге при проблемах с доступом. Настройки изменяются пользователем вручную. Читаемость и переходы фокуса проверяются в локальном эмуляторе Android TV.
