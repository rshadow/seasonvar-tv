# ADR-0005: Воспроизводимый локальный цикл разработки через Makefile

Дата: 2026-11-01

Статус: Принято

## Контекст

Первый прототип содержит меню с пунктом «О программе». Нужно собирать и отлаживать его локально и повторять настройку на компьютере другого разработчика.

## Решение

Все штатные команды подготовки инструментов, загрузки зависимостей, сборки, проверок, запуска и отладки определять в корневом `Makefile`. Вспомогательные скрипты обслуживают эти цели; отдельный дублирующий интерфейс команд не поддерживается.

- Gradle запускается через сохранённый в проекте Wrapper с закреплённой версией и контрольной суммой.
- Версии Android Gradle Plugin, Kotlin и Compose-зависимостей указаны в Gradle-файлах.
- `toolchain.lock.json` закрепляет JDK, Android SDK, командные инструменты, эмулятор и образ Android TV с официальными URL и контрольными суммами.
- `make bootstrap` устанавливает инструменты в игнорируемую `.tools` внутри проекта. Архивы проверяются перед распаковкой.
- `make deps` загружает зависимости. Для крупных артефактов с медленной загрузкой через Java предусмотрена проверяемая предварительная загрузка через curl.
- `make avd` настраивает клавиатуру и сенсорный ввод локального эмулятора для работы с клавиатурой компьютера и мышью. Параметры закреплены в `toolchain.lock.json`; для уже запущенного эмулятора есть `make emulator-restart`.
- Основной способ интерактивной отладки — локальный Android TV-эмулятор; установка на физическую приставку выполняется явным выбором устройства.
- README и [docs/development.md](../development.md) описывают проверенные команды и необходимые предварительные условия.

Базовые утилиты — Python 3.12+, make и curl. Подготовлены варианты инструментария для macOS ARM64, macOS Intel и Linux x86_64; фактическую проверку каждого варианта фиксируем отдельно.

## Альтернативы

- **Команды только в переписке или README.** Сложнее воспроизводить и поддерживать в соответствии с реальными аргументами.
- **Неявная зависимость от глобальных установок SDK/JDK.** Компьютеры разработчиков могут использовать разные версии.
- **Отладка только на приставке.** Требует доступного физического устройства даже для простой проверки меню.

## Последствия и ограничения

Первая настройка требует интернета, свободного места для SDK/образа и аппаратной виртуализации для эмулятора. Повторные сборки используют локальные инструменты и кэши.

Изменение команд сопровождать изменением Makefile и документации, обновление версий — lock-файлами. SDK-лицензии принимаются разработчиком; ранее принятые на том же компьютере лицензии могут быть переиспользованы.

Воспроизводимость означает закреплённые инструменты, зависимости и повторяемый процесс. Побайтовое совпадение debug APK на разных компьютерах не заявляется: отладочная подпись создаётся локально.

Основание: пользователь попросил локальную отладку и потребовал фиксировать команды в Makefile для воспроизводимости на другом компьютере.
