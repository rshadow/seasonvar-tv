# ADR-0202: Комментарии под описанием сезона

Дата: 2026-11-21

Статус: Принято.

## Контекст

На Seasonvar у сезона есть короткие комментарии с ответами и отдельные рецензии. В карточке сезона нужен доступ к обсуждению с пульта.

## Решение

В полной карточке комментарии идут сразу после описания. Первой строкой записи показываем автора и дату. Ответы раскрыты при открытии и идут следом за родительским комментарием с отступом, как на сайте. Стрелки перемещают фокус по ленте; переход вверх с первой записи возвращает к управлению карточкой.

За прокрутку отвечает одна ленивая вертикальная лента. Первая порция берётся со страницы сезона. Следующая запрашивается автоматически при приближении к концу, номер берётся из пагинации сайта. Загруженные записи сохраняют ключи, повторяющиеся ID пропускаются. Ошибка подгрузки оставляет прочитанные записи и даёт повторить запрос.

Спойлер внутри сообщения и скрытое целиком сообщение отображаются кнопкой «Показать спойлер». OK раскрывает текст на месте. При сворачивании закрытый текст снова исчезает из интерфейса и дерева доступности.

Переключатель «Комментарии зрителей» в настройках приложения включён по умолчанию. В выключенном состоянии лента скрыта и страницы обсуждения не загружаются. На миниатюрах списков обсуждение не отображается.

## Альтернативы и последствия

Отдельный экран добавляет переход при чтении обсуждения сезона. Полная загрузка всех страниц увеличивает объём запросов и задержку входа. Встроенная лента загружает порции по мере чтения и использует [нативный разбор разметки Seasonvar](../api/web-api.md#чтение-комментариев-сезона).
