# ADR-0182: Разделение главного контейнера

Статус: принято. Дата: 2026-11-17. Дополняет [ADR-0025](0025-responsive-section-switching.md) и [ADR-0175](0175-stable-menu-entry-handlers.md).

## Контекст

`SeasonvarContent` объединял выбор источника данных, позиции всех списков, объекты фокуса, эффекты авторизации и запуска, боковое меню и разметку содержимого. Изменения навигации требовали читать всю функцию.

## Решение

Главный контейнер сохраняет выбор раздела и карточки, существующие подписки на данные, открытие карточки и обработку возврата. `MainMenu` выводит прежнее меню; `MainCatalogContent` подключает общий `CatalogPane`, поиск, историю запросов и фильтры каталога. Компоненты не добавляют контейнеров разметки, моделей данных или механизмов загрузки.

Один запомненный `MainFocus` владеет объектами фокуса и таблицей видимых карточек. `MainCatalogPositions` хранит запомненные пары позиций ленты и плитки для всех источников. Смена фильтров пересоздаёт только позицию каталога; смена версии аккаунта сбрасывает личные позиции и «Продолжить», сохраняя публичные.

Активация источников, запуск приложения, переходы при смене аккаунта и завершение поиска выделены по назначению. Ключи эффектов и порядок очистки сохраняются. Вход в содержимое ждёт прежние два кадра, при необходимости прокручивает список, ждёт ещё два и повторно проверяет экран, раскладку, выбранную карточку и закрытое состояние подробностей. Данные для перехода читаются после ожидания кадров. Обработчик входа из меню сохраняет обёртку `rememberUpdatedState` по ADR-0175.

## Альтернативы и последствия

Перенос всей функции в другой файл сохраняет связанность. Общий изменяемый объект со всеми данными и обработчиками скрыл бы зависимости компонентов. Используются небольшие владельцы состояния фокуса и прокрутки, а данные и действия передаются явно.

Разделение не меняет общий движок списков, кеши и границы подписок на данные; ускорение интерфейса не предполагается. Проверяются старт, смена аккаунта, все разделы меню, лента и плитка, возвраты, поиск, фильтры и фон в обеих темах. Baseline Profile генерируется и проверяется по ADR-0174.
