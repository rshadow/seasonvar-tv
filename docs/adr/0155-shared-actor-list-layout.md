# ADR-0155: общий сохраняемый вид списков актёров

Статус: принято. Дата: 2026-11-14. Дополняет [ADR-0083](0083-catalog-layout-selection.md) и [ADR-0153](0153-actor-series-list.md).

## Контекст

Вид обычных списков сохраняется по разделу. Экран сериалов актёра держал выбор только во время своей жизни, поэтому повторный переход возвращал ленту. Пользователь выбрал отдельную общую настройку для всех списков актёров.

## Решение

Все списки сериалов актёров используют один постоянный выбор «Лента с описанием» или «Сетка» с ключом `catalog_layout.actor`. Переключатель в заголовке сразу сохраняет значение через общие `CatalogLayoutPreferences` и `InterfaceSettings`. Открытые экраны получают актуальный выбор из общего состояния; повторный переход к любому актёру и перезапуск приложения восстанавливают его. При отсутствии или неизвестном значении открывается лента.

Виды остальных разделов сохраняются независимо. Ключ не зависит от актёра или аккаунта; пункт настроек для него не добавляется. Выбранный сериал, фокус и прокрутка каждого открытого экрана остаются локальными и восстанавливаются существующим механизмом возврата.

## Альтернативы и последствия

Хранение по каждому актёру создало бы множество предпочтений вместо единого ожидаемого вида. Общая настройка со всеми разделами нарушила бы их независимость. Один отдельный ключ сохраняет привычное управление и постоянный объём настроек.
