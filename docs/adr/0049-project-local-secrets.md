# ADR-0049: Секреты Seasonvar в корне проекта

Дата: 2026-11-03

Статус: Принято

Пересматривает место хранения из [ADR-0048](0048-release-apk-signing.md).

## Контекст

Файл подписи содержит только ключ и параметры Seasonvar. Пользователь попросил перенести его в проект и назвать `secrets.env`, исключив из Git.

## Решение

- Секреты Seasonvar хранить в `secrets.env` в корне проекта. Для этого файла действует явное исключение `/secrets.env` в `.gitignore`, права доступа — `0600`.
- Подпись APK читает четыре параметра `SEASONVAR_SIGNING_*` только из этого файла. Старый `~/android.env` перенесён; домашний `~/secrets.env` остаётся источником других секретов локальных инструментов.
- `make release` выполняется из корня проекта. Загрузка ключа в память, схемы подписи и проверки остаются прежними по ADR-0048.
- Значения не выводить в логи и чат, не добавлять в индекс, фикстуры или документацию. Перед коммитом проверять, что `secrets.env` игнорируется и не отслеживается Git.

## Альтернативы

- **Отдельный `~/android.env`.** Пользователь предпочёл хранение рядом с проектом.
- **Название `android.env` в проекте.** Заменено на `secrets.env` по просьбе пользователя.

## Последствия и ограничения

Клонирование репозитория не переносит секреты. Для release-сборки на другом компьютере файл передаётся отдельно безопасным способом. Резервную копию постоянного ключа хранить отдельно от каталога проекта.
