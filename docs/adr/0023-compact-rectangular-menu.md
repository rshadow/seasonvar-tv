# ADR-0023: Прямоугольные кнопки и компактное меню

Дата: 2026-11-02

Статус: Принято

## Контекст

Пользователь выбрал прямоугольные кнопки с небольшим скруглением по образцу Seasonvar и более компактное левое меню. Число разделов растёт; все пункты должны оставаться доступны с пульта.

## Решение

- Общие кнопки приложения оформлять прямоугольниками со скруглением 5dp. Не увеличивать кнопку при получении фокуса; фокус выделять существующим золотым цветом.
- «Обновить» в заголовке каталога — квадратная кнопка 44×44dp с иконкой перезагрузки 24dp. Без фокуса фон прозрачный, видна только иконка; при фокусе появляется полная золотая кнопка. Доступное название — «Обновить»; размеры задаются `seasonvar_header_button_size` и `seasonvar_header_button_icon_size`.
- Маленькие кнопки с иконками (обновление, поиск, микрофон) реализовывать через `IconButton` с квадратным размером из темы и центрированием по всей площади. Применять те же скругление, цвета фокуса и масштаб, что у текстовых кнопок. Вектор иконки также должен быть центрирован в своём viewport; отступы текстового `Button` для него не использовать.
- Высота пункта меню — 40dp, интервал между пунктами — 4dp, отступ от названия приложения — 24dp. Размер текста сохранять для чтения с телевизора.
- Название приложения оставлять над меню. Список разделов ограничивать высотой окна и прокручивать вертикально; при переходе фокуса скрытый пункт должен появляться в видимой области.
- Сохранять навигацию по ADR-0013: показ раздела по фокусу, вход вправо/OK, возврат в текущий пункт меню. Прокрутка не добавляет отдельных кнопок или подтверждений.
- Настройки оформления хранить в `themes.xml`: `seasonvar_button_corner_radius`, `seasonvar_menu_item_height`, `seasonvar_menu_item_spacing`, `seasonvar_menu_header_spacing`; доступ из Compose — через `SeasonvarTheme.dimensions` по ADR-0008.

## Альтернативы

- Кнопки-капсулы не повторяют выбранное оформление сайта.
- Уменьшение шрифта ухудшает чтение с дивана.
- Только уменьшение интервалов не гарантирует доступность меню при дальнейшем добавлении разделов.

## Последствия

Семь текущих пунктов занимают меньше места, новые доступны прокруткой. Размер карточек сериалов и расположение сетевых настроек сохраняются. Все общие кнопки, включая «Обновить» и повторную попытку, используют одно скругление.
