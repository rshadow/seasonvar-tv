# ADR-0054: GPLv3 для собственного кода проекта

Дата: 2026-11-03

Статус: Принято

## Контекст

Репозиторий публичный, но собственной лицензии проекта пока не было. Пользователь попросил порекомендовать лицензию и добавить её на GitHub, затем явно выбрал GPLv3.

## Решение

- Собственный код Seasonvar TV распространять по GNU General Public License, версия 3. SPDX-идентификатор — `GPL-3.0-only`: будущие версии GPL автоматически не разрешаются.
- Стандартный полный английский текст хранить в корневом `LICENSE`, сохраняя уведомление Free Software Foundation о правах на текст лицензии. Уведомление об авторстве собственного кода — `Copyright (c) 2026 rshadow` — указать отдельно в README.
- В README дать ссылку на LICENSE. Опубликовать решение обычным коммитом в `main`, чтобы GitHub распознал GPLv3.
- Сторонние материалы и зависимости сохраняют исходные лицензии. Включённые официальные Android-скиллы остаются под Apache 2.0; их тексты лицензий и уведомления не удалять и не заменять.

## Альтернативы

- **MIT.** Рассматривалась как короткая разрешительная лицензия; допускает закрытые производные версии. Пользователь выбрал GPLv3.
- **Apache 2.0.** Разрешительная лицензия с явным патентным предоставлением; не требует лицензировать производные версии под той же лицензией.

## Последствия

При распространении производных версий необходимо соблюдать GPLv3, сохранять требуемые уведомления и предоставлять соответствующий исходный код на условиях лицензии. Коммерческое распространение GPLv3 не запрещает. Лицензия содержит отказ от гарантий и ограничение ответственности.

Лицензия собственного кода не меняет права на сторонние материалы и содержимое сайта Seasonvar.
