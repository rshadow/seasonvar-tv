# ADR-0008: Общая тема интерфейса и палитра Seasonvar

Дата: 2026-11-01

Статус: Принято

## Контекст

Цвета и размеры были заданы прямо в `MainActivity.kt`, а фон запуска и значки дублировали часть палитры. Настройки интерфейса должны находиться в одном понятном месте.

Пользователь поручил вынести эти значения в тему и использовать фирменные цвета оригинального сайта. Текущие CSS получены с CDN, указанного в HTML главной Seasonvar.

## Решение

### Где менять настройки

| Файл | Что в нём настраивается |
| --- | --- |
| [app/src/main/res/values/themes.xml](../../app/src/main/res/values/themes.xml) | Палитра `seasonvar_*`, отступы, интервалы и размеры кнопок, тема Android для окна запуска |
| [SeasonvarTheme.kt](../../app/src/main/java/ru/seasonvar/tv/ui/theme/SeasonvarTheme.kt) | Соответствие ресурсов ролям Compose MaterialTheme, набор стилей текста `SeasonvarTypography` и доступ к размерам через `SeasonvarTheme.dimensions` |
| [app/src/main/res/drawable](../../app/src/main/res/drawable) | Геометрия значка и ТВ-баннера; их цвета берутся из общей палитры |

Основное место изменения цветов и размеров — `themes.xml`. Экранные компоненты используют `MaterialTheme.colorScheme`, `MaterialTheme.typography` и `SeasonvarTheme.dimensions`. Общие числовые значения оформления в экранах не дублируются.

Тема подключается в корне приложения и используется также в Compose Preview. Android-окно запуска, значок и баннер ссылаются на те же цветовые ресурсы.

### Палитра

| Ресурс | Значение | Назначение в приложении |
| --- | --- | --- |
| `seasonvar_background` | `#2B2521` | Тёмно-коричневый фон |
| `seasonvar_surface` | `#980C3D` | Бордовый фон обычной кнопки |
| `seasonvar_accent` | `#F5B50C` | Золотое выделение фокуса и акценты |
| `seasonvar_on_accent` | `#2B2521` | Тёмный текст на золотом фоне |
| `seasonvar_text` | `#F3F3F3` | Основной светлый текст |
| `seasonvar_secondary_text` | `#D5D9D9` | Второстепенный текст |

Все значения взяты из CSS сайта. Их роли адаптированы для тёмного ТВ-интерфейса: на сайте блоки обновлений белые, а приложение использует тёмный фон и заметное золотое выделение фокуса.

Текущие отступы и размеры компонентов сохраняются. Типографика использует стандартный набор Compose for TV; точка её настройки — `SeasonvarTypography` в `SeasonvarTheme.kt`.

### Источники и обновление

Проверено 2026-11-01, версия ресурсов `25.4.1`:

- [main.css](https://cdn.svstat.net/asset/css/main.css?25.4.1): фон `body` — `#2b2521`, бордовые акценты — `#980c3d`, золотые акценты — `#f5b50c`; также содержит `#f3f3f3` и `#d5d9d9`.
- [pg.index.css](https://cdn.svstat.net/asset/css/pg.index.css?25.4.1): заголовок даты `.news-head` — `#f5b50c`, ссылки при наведении и значки обновлений — `#980c3d`.

Для повторной сверки `make site-styles` скачивает оба CSS в игнорируемую `build/site`. Изменение цветов на сайте само по себе не меняет тему приложения: обновление ресурсов выполняется явно.

## Альтернативы

- **Константы в каждом экране.** Значения дублируются и расходятся при изменениях.
- **Палитра только в Kotlin.** Окно запуска и XML drawable требуют отдельного хранения цветов.
- **Полная копия веб-оформления.** Мелкий текст, плотность и поведение фокуса требуют адаптации для телевизора.

## Последствия

Цвета и размеры меняются через общие ресурсы с последующей пересборкой приложения. Смена темы пользователем во время работы пока не предусмотрена.

Новые экраны следуют той же теме. При добавлении общего параметра оформления его значение помещается в `themes.xml`, а Compose-доступ при необходимости добавляется в `SeasonvarTheme.kt`.

Основание: пользователь поручил централизовать настройки интерфейса, описать их расположение в ADR и использовать фирменные цвета Seasonvar.
