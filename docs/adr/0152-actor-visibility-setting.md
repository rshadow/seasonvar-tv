# ADR-0152: настройка показа актёров

Статус: принято. Дата: 2026-11-13. Дополняет [ADR-0151](0151-actor-row-below-poster-preview.md).

## Контекст

Ряд актёров занимает место между сведениями о сериале и кнопками. Пользователь хочет включать и выключать его отображение.

## Решение

В группе «Настройки → Приложение» доступна строка «Показывать актёров» с пояснением слева и галочкой справа по [ADR-0015](0015-settings-item-format.md). По умолчанию она включена. Выбор сохраняется локально для приложения и действует после перезапуска независимо от аккаунта.

При выключении скрывается весь ряд, включая заголовок и занимаемое им место. Его фотографии не создают запросов от интерфейса. Уже загруженные данные карточек и общий кеш изображений сохраняются. Вверх из строки действий использует прежнюю прокрутку и не переводит фокус к скрытым актёрам. При включении действует навигация из ADR-0151.

## Альтернативы и последствия

Отдельная настройка изображений оставила бы текстовый список и не позволила бы освободить место. Общий переключатель скрывает фотографии и имена вместе; выбранный пользователем режим определяет разметку при открытии карточки.
