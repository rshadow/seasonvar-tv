# ADR-0214 — Фокус при открытии экрана аккаунта

Статус — принято. Дата — 2026-11-28. Дополняет [ADR-0114](0114-stable-async-layout.md).

## Контекст

При открытии экрана аккаунта приложение проверяет текущую сессию. Когда проверка заканчивается, экран запрашивал фокус для кнопки «Выйти из аккаунта». Выделение менялось без нажатия на пульте.

## Решение

Если пользователь вошёл в аккаунт, открытие экрана оставляет фокус на кнопке аккаунта в боковом меню. Стрелка вправо переводит его на кнопку «Выйти из аккаунта», стрелка влево возвращает в меню. Проверка действующей сессии обновляет данные экрана и сохраняет текущий фокус. Если требуется вход, начальный фокус получает поле логина.

## Альтернативы и последствия

Рассматривали немедленный перевод фокуса на выход при открытии экрана. Он экономит одно нажатие для выхода, но делает выход первым доступным действием при просмотре данных аккаунта. С принятым решением для выхода требуется явный переход вправо. Переходы в остальных разделах бокового меню используют прежние правила.
