# ADR-0019: Одно название и фиксированный размер карточек ленты

Дата: 2026-11-02

Статус: Принято

## Контекст

Сочетание русского и оригинального названий занимало большую часть миниатюры. Карточки с коротким названием были ниже соседних, а подписи серий располагались на разных уровнях.

## Решение

- В карточке ленты показывать русское название. Если оно отсутствует или пустое, использовать оригинальное название из того же ответа сайта.
- Получать названия раздельно из HTML, без разделения готовой строки по символу `/`: он может быть частью самого названия.
- В модели `title` хранит предпочитаемое название, `originalTitle` — дополнительное. `fullTitle` сохраняет их сочетание для панели выбранного сериала и полного описания; при отсутствии русского названия оригинальное не дублируется.
- Использовать одинаковую ширину и высоту всех карточек. Значения находятся в `themes.xml`: `seasonvar_card_width` — 120dp, `seasonvar_card_height` — 212dp, подключение — через `SeasonvarTheme.dimensions`.
- Заголовок резервирует ровно две строки (`minLines = maxLines = 2`), длинный текст сокращается многоточием. Подпись серий/озвучки занимает одну строку. Бейдж остаётся поверх постера и не меняет высоту карточки.
- Порядок выдачи, ключи карточек и навигация сохраняются. Правило применяется к общей ленте «Сегодня» и «Обновления».

Это уточняет вид миниатюр из [ADR-0006](0006-tv-navigation-and-content-layout.md) и использует тему по [ADR-0008](0008-centralized-ui-theme.md).

## Альтернативы

- Только ограничение `maxLines` оставляет короткие карточки ниже остальных.
- Разделение готового названия по `/` может обрезать русское название или номер вроде «Ранма 1/2».
- Удаление оригинального названия из данных лишает его панель описания и запасного отображения при отсутствии русского.

## Последствия

Размеры карточек и положение подписи серий одинаковы при коротких и длинных названиях. При изменении типографики следует согласованно настраивать размеры карточки и ленты в общей теме. Выбор названия проверяется автономными тестами парсеров; геометрия и навигация — в эмуляторе.
