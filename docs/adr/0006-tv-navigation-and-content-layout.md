# ADR-0006: Меню слева, информация о сериале и горизонтальная лента справа

Дата: 2026-11-01

Статус: Принято

## Контекст

Клиент сохраняет разделы и смысл подачи данных оригинального Seasonvar, адаптируя навигацию для телевизора и пульта. Главный раздел должен показывать сегодняшние обновления серий с главной страницы сайта.

Нужна единая компоновка, в которой удобно выбирать раздел, просматривать сериалы и читать сведения о выбранном элементе. Пользователь выбрал классический ТВ-интерфейс с меню слева и горизонтальной лентой миниатюр под описанием справа.

## Решение

- Слева располагается вертикальное меню разделов.
- Справа сверху показываются название, сезон, добавленные серии, доступные сведения об озвучке, описание и постер выбранного сериала.
- Справа снизу располагается горизонтальная лента миниатюр с заметным выделением элемента в фокусе.
- При перемещении фокуса по ленте верхняя область показывает сведения о выбранном сериале.
- Основной раздел «Сегодня» показывает сегодняшние обновления в порядке сайта. Остальные разделы добавляются по мере реализации соответствующих функций; названия и назначение сверяются с оригинальным сайтом. Сохраняется пункт «О программе».

### Схема

~~~text
┌──────────────────┬────────────────────────────────────────────────┐
│ Seasonvar        │ Название выбранного сериала                    │
│                  │ Сезон · добавленные серии · озвучка             │
│ → Сегодня        │                                                │
│   …              │ Описание                            Постер     │
│   О программе    │                                                │
│                  ├────────────────────────────────────────────────┤
│                  │ Сегодня · дата                                 │
│                  │ [миниатюра] [ВЫБРАНА] [миниатюра] [мини… →     │
└──────────────────┴────────────────────────────────────────────────┘
~~~

Схема задаёт расположение областей. Многоточие в меню обозначает будущие разделы; размеры, отступы и оформление уточняются при реализации.

### Управление

- В меню стрелки вверх и вниз перемещают фокус по разделам; OK открывает выбранный раздел, стрелка вправо переводит фокус в его содержимое.
- В ленте стрелки влево и вправо перемещают фокус по миниатюрам. Выбранный элемент остаётся видимым при прокрутке.
- Стрелка влево из первой карточки или «Назад» из ленты возвращает фокус в меню.
- OK на миниатюре открывает страницу сериала. Перемещение фокуса обновляет информационную область без запуска воспроизведения.
- После возврата со страницы сериала восстанавливаются позиция ленты и выбранная карточка. Переключение между меню и содержимым также сохраняет выбор.
- Клавиатура и мышь дополняют управление пультом: Enter соответствует OK, клик выбирает элемент.

### Данные и отзывчивость

Следуем [ADR-0003](0003-performance-principles.md): показываем доступные данные из кэша, обновляем их в фоне, используем ленивую ленту со стабильными ключами. Название и сведения об обновлении появляются сразу после получения списка; описание и изображения догружаются отдельно, сохраняя отзывчивость навигации.

Прокрутка непрерывная и без циклического повторения карточек. Подгрузка продолжается, пока источник предоставляет данные. В разделе «Сегодня» список ограничен сегодняшними обновлениями; переход к предыдущим дням требует отдельного решения.

Загрузка, отсутствие обновлений и ошибка получения данных имеют разные состояния интерфейса. Недоступность сайта или изменение разметки не выдаются за отсутствие новых серий.

### Границы текущего этапа и возможное развитие

Сейчас выбран один вид правой части: информационная область сверху и горизонтальная лента снизу. Этот ADR фиксирует концепцию; реализация интерфейса выполняется отдельной задачей.

В будущем рассматривается возможность выбирать вид правой части между этой компоновкой и плиткой сериалов. Это направление развития, а не принятое обязательство реализовать второй вид. Переключатель, настройки, второй вариант отображения и специальные механизмы расширения откладываются до отдельного решения.

## Альтернативы

- **Плитка сериалов справа от меню.** Показывает больше элементов одновременно, оставляет меньше места для описания. Рассматривается как возможный будущий вариант.
- **Вертикальная лента обновлений по датам.** Позволяет плотнее показывать названия и добавленные серии, но отводит меньше места крупному изображению и описанию выбранного сериала.

## Последствия и ограничения

Видно меньше сериалов одновременно, чем в сетке. Взамен выбранный сериал получает крупную информационную область, а навигация разделяется между меню и одной горизонтальной лентой.

Описание и постер могут требовать отдельных запросов. Их загрузка учитывает смену выбора: устаревший ответ не заменяет сведения о текущем элементе. Для проверки нужны доступные ответы оригинального сайта и испытание фокуса и прокрутки в эмуляторе и на Ugoos.

Основание: пользователь выбрал предложенную классическую компоновку и поручил записать ADR со схемой, отложив реализацию и возможность смены вида правой части.
