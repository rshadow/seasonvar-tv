# ADR-0188. Личный стартовый раздел из кеша

Статус: принято. Дата: 2026-11-18. Уточняет [ADR-0173](0173-load-selected-start-page.md).

## Контекст

Восстановление сессии через `/resume` задерживает вход в выбранный личный список. В эмуляторе сетевой ответ и разбор занимали около полусекунды, хотя выдача была сохранена на устройстве.

## Решение

Сохранённый аккаунт определяется по зашифрованной привязке ID последнего подтверждённого владельца к записи cookie. Привязка хранит отпечаток зашифрованной записи, обе части сохраняются одной операцией. Формат cookie остаётся совместимым с прежними APK. Для раннего чтения нужен действующий локальный `svid1`. Замена этой cookie сбрасывает привязку до подтверждения сайта. Сессии без привязки получат её при следующем успешном восстановлении.

Выбранный личный раздел читает только кеш этого владельца. Для личных списков проверяются владелец HTML и сохранённые фильтры. «Продолжить» читает готовый список с ключом аккаунта. При отсутствии подходящих данных сохраняется обычное ожидание проверки сессии.

Ранний экран позволяет выбрать карточку пультом. Открытие карточки, изменение отметок, очистка истории и фильтры доступны после подтверждения. При подтверждении того же аккаунта текущие позиция и фокус сохраняются. Истечение сессии, смена владельца и ручной вход или выход сразу прекращают показ предварительных данных. Временная сетевая ошибка допускает просмотр кеша и повторную проверку сессии.

## Альтернативы и последствия

Ожидание `/resume` сохраняет прежнюю последовательность, но добавляет сеть на путь до управления. Установка подтверждённого `AccountSession` из локального кеша открыла бы запросы с неподтверждённой сессией. Отдельное состояние предпросмотра оставляет авторизацию серверу и использует существующий кеш без новых копий списка на диске.
