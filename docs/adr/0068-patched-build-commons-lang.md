# ADR-0068: Исправленный Commons Lang в инструментарии сборки

Дата: 2026-11-04

Статус: Принято

## Контекст

Dependabot №58 обнаружил org.apache.commons:commons-lang3:3.16.0 в AGP 9.5.0 и lint-gradle 32.5.0. CVE-2025-48924: ClassUtils.getClass(...) при чрезмерно длинном вводе может вызвать StackOverflowError из-за неконтролируемой рекурсии. Первая исправленная версия — 3.18.0.

Полный граф подтверждает 3.16.0 и в корневом classpath, и в отдельном androidLintTool. В конфигурациях APK библиотека не обнаружена. Частичное исправление только AGP не устраняет уязвимость Lint.

## Решение

Задать buildCommonsLangVersion=3.18.0 в gradle.properties, ограничение в корневом buildscript и правило разрешения этой же версии в androidLintTool. Закрепить POM/JAR Maven Central и контрольные суммы в toolchain.lock.json. Использовать совместимый исправленный выпуск 3.x без смены инструментов сборки.

Расширить make check-resolved-dependencies проверкой Commons Lang во всех конфигурациях. Регрессионный тест отклоняет 3.16.0 в корне и в Lint при исправленной версии другого classpath. Подтвердить отказ на реальном графе до исправления и успех нового графа.

Изменение оформляется отдельным PR после PR для HttpClient (ADR-0067). Локально оба исправления проверяются вместе через make check, make ci-lint, make codeql-build и make build BUILD_TYPE=release. GitHub проверяет каждый PR перед слиянием; после слияния проверяется публикация полного графа main.

## Альтернативы

- Исправить только buildscript: оставляет старую версию в Android Lint.
- Менять обработку пользовательского ввода приложения: не исправляет сторонние вызовы внутри инструментов.
- Обновить весь AGP: расширяет область изменения при наличии совместимой исправленной библиотеки.
- Закрыть предупреждение вручную: оставляет уязвимость.

## Последствия

Сборка и Android Lint используют одну исправленную версию. Приложение не получает новую библиотеку в APK. Проверка полного графа предотвращает незаметный возврат старого classpath при обновлении AGP. Успех проверок сам по себе не подтверждает закрытие оповещения GitHub.
