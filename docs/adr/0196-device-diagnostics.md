# ADR-0196. Самодиагностика устройства

Дата: 2026-11-21. Статус: принято.

## Контекст

На отдельных приставках сайт подтверждает вход, а приложение не может сохранить сессию. Действующая проверка подключения подтверждает доступность сайта и медиаресурсов. Для разбора локального сбоя нужно отдельно проверить запись, шифрование и чтение существующей сессии.

## Решение

Последняя группа настроек «Диагностика устройства» запускает проверки в фоне при входе на экран и по кнопке повтора. Она показывает свободное место, результат записи тестового значения в отдельное хранилище настроек, чтения и записи файла в кэше, а также шифрования и расшифровки тестовых данных отдельным ключом Android Keystore. Существующая сессия проверяется чтением и расшифровкой. Отсутствие сохранённой сессии имеет собственный статус.

При отсутствии разрешения на установку обновлений кнопка открывает системный экран для Seasonvar TV. После возврата проверка обновляется, фокус остаётся доступен в группе.

## Альтернативы и последствия

Флаги разрешений не подтверждают фактическую запись и работу шифрования. Пробы выполняют операции на тестовых данных и удаляют их после проверки. Проверка сессии локальная. Доступность сервера проверяется в группе «Подключение» по [ADR-0142](0142-connection-availability-checks.md).
