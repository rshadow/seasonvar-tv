# ADR-0204. Публикация комментариев сезона с пульта

Дата 2026-11-25. Статус принят. Дополняет [ADR-0202](0202-season-comments.md).

## Контекст

Зритель хочет начать обсуждение или ответить в существующей ветке. Чтение должно оставаться доступным вертикальными стрелками. Длинный комментарий может включать несколько спойлеров и несколько фрагментов голосового ввода.

## Решение

«Написать» находится в заголовке обсуждения, в том числе при пустой ленте. Стрелка вверх с первого комментария переводит фокус на эту кнопку. У текущего комментария справа появляется иконка со стрелкой ответа в отведённом месте. Для экранного диктора она подписана «Ответить». Вправо переводит туда фокус с текста или со спойлера. Влево возвращает к месту чтения. Вертикальная навигация пропускает кнопки ответов. Кнопки без рамок, фокус показывает заливка темы. Для отправки нужен подтверждённый вход. Гостю кнопка показывает подсказку о входе.

Общий диалог содержит прокручиваемый многострочный редактор и действия «Голосом», «+ Спойлер» и «Отправить». Спойлер вставляется в месте выделения или курсора и редактируется отдельным блоком. Когда выбрано его поле, на той же кнопке доступно действие «Убрать спойлер». Оно объединяет блок с соседним обычным текстом и возвращает фокус к месту редактирования. При закрытой клавиатуре «Вправо» переводит фокус из текущего поля на «Голосом». Системное распознавание вставляет один фрагмент в выбранное поле. Повторный запуск добавляет следующий фрагмент. Назад сначала закрывает клавиатуру, затем возвращает фокус к исходному действию. Черновики хранятся в памяти, пока открыта карточка и действует тот же вход. У каждого ответа свой черновик. При ошибке отправки текст сохраняется. [Системный выбор распознавателя](0206-system-comment-voice-input.md)

Отправка выполняется один раз на подтверждение с текущей проверенной сессией. Сайт подтверждает публикацию полем `status`. После ответа обновляются страница родителя или загруженные страницы обсуждения, с сохранением ключей элементов. Ошибка обновления после успешной отправки показывает отдельное сообщение. [Форма сайта](../api/web-api.md#публикация-комментариев-сезона)

## Альтернативы и последствия

Размещение «Ответить» между строками добавляет остановку на каждом сообщении. Ручная разметка спойлеров требует ввода тегов с пульта. Отдельный блок передаёт сайту тот же формат и позволяет редактировать обычный и скрытый текст независимо. Возможность голосового ввода зависит от установленного системного распознавателя.
