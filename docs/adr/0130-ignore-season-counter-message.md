# ADR-0130: Игнорировать сообщение сайта «Сезон N из M»

Дата: 2026-11-10

Статус: Принято, реализовано

Уточняет обработку сообщения сайта из [ADR-0038](0038-compact-account-marks.md) и [ADR-0043](0043-account-progress-in-controls.md), сохраняя строку пользовательского прогресса по [ADR-0111](0111-season-progress-below-controls.md).

## Контекст

Авторизованная выдача `/resume` содержит сообщение `.pgs-marks-mess` вида «Сезон 6 из 7». Проверка показала такие подписи и у записей «Хочу посмотреть» без отметки воспроизведения. Подпись не доказывает пользовательский прогресс, приходит не для всех открываемых сезонов и может повторять числа из строки «Прогресс». Пользователь выбрал её безусловное игнорирование.

## Решение

- При разборе обычных и отфильтрованных личных списков отбрасывать сообщение, целиком соответствующее «Сезон N из M», без учёта регистра и с нормализацией пробелов HTML.
- Не переносить подпись в `AccountMark`, не выводить в списках и открытой карточке, не использовать как источник прогресса, отметки, выбора сезона или продолжения просмотра. Условие не зависит от наличия и значений пользовательского прогресса.
- Сохранить остальные сообщения сайта, записи списков, пользовательские отметки, прогресс серий и сезонов и историю. Сама подпись не создаёт пустую отметку. Номер выбранного сезона не становится прогрессом просмотра.
- Исходный HTML остаётся в дисковом кэше по ADR-0129; при его чтении применяется тот же парсер. Дополнительная фильтрация и пустая строка в интерфейсе не нужны.

## Альтернативы и последствия

Условное скрытие при совпадении с прогрессом оставляет подпись в других состояниях и требует специальной разметки. Перенос подписи в строку прогресса смешивает сведения о сериале с данными просмотра. Фильтрация в общем парсере исключает оба случая во всех списках; дополнительная подсказка о более поздних сезонах не показывается.

## Проверка

Автономные тесты проверяют обычные и отфильтрованные личные вкладки, подпись без отметки и с прогрессом, несовпадающие числа и сохранность контекста записи. `make details-progress-probe` проверяет отсутствие подписи при загрузке, ошибке и разных значениях прогресса, сохранение обычного сообщения, геометрии и фокуса. Результаты ручной проверки — в [инструкции разработки](../development.md#проверка-стабильной-строки-прогресса).
