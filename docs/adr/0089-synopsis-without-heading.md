# ADR-0089: Описание сериала без отдельного заголовка

Дата: 2026-11-06

Статус: Принято

Уточняет [ADR-0029](0029-series-controls-before-description.md).

## Контекст

Заголовок «Описание» над текстом сериала добавляет визуальный шум. Пользователь попросил убрать его.

## Решение

Выводить полный текст описания сразу под блоком управления сериями, на всю ширину содержимого, без отдельного заголовка.

## Альтернативы

Сохранить заголовок для обозначения раздела. Для этой карточки пользователь предпочёл более спокойную компоновку.

## Последствия

Текст начинается выше на высоту заголовка и промежутка. Общая прокрутка карточки, сообщения загрузки и ошибки, а также фокус только на действиях сохраняются.
