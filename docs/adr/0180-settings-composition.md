# ADR-0180: Разделение страницы настроек

Статус: принято. Дата: 2026-11-17. Дополняет [ADR-0015](0015-settings-item-format.md) и [ADR-0141](0141-network-and-connection-settings.md).

## Контекст

Одна функция страницы содержала четыре категории, повторяющуюся разметку строк, состояния диалогов и переходы фокуса. Изменение отдельного пункта требовало учитывать весь экран.

## Решение

`SettingsPane` сохраняет общую прокрутку, порядок категорий и уведомление о видимости страницы. Категории выводятся отдельными компонентами без дополнительных контейнеров разметки. `SettingsFocus`, созданный через `remember`, связывает соседние пункты, включая границы категорий; изменение значения не создаёт новые объекты фокуса.

Строки с галочкой используют общий `SettingsToggle`, строки выбора — `SettingsChoice`. Общая разметка сохраняет формат ADR-0015, роли доступности и одну точку фокуса. Состояние выделения принадлежит строке, состояние открытого диалога — пункту выбора. Диалог использует существующий `SettingsChoiceDialog`: выбор возвращает фокус на исходную строку после двух кадров, отмена сохраняет прежние обработчики возврата.

Модели данных и сохранение настроек остаются вне компонентов. Цвета, размеры, тексты, порядок пунктов и момент запуска проверки подключения сохраняются.

## Альтернативы и последствия

Перенос всей функции в другой файл не разделяет обязанности. Универсальное описание всех настроек через схему потребовало бы обобщать уже работающие специализированные компоненты озвучек, каналов и прокси; они сохраняются.

Проверка проходит все строки пультом в обе стороны, меняет и восстанавливает пять галочек, проверяет диалоги и сравнивает снимки. Генерация и проверка Baseline Profile выполняются по ADR-0174. Разделение упрощает сопровождение; ускорение интерфейса само по себе не предполагается.
