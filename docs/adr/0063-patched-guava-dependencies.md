# ADR-0063: Исправленная Guava для сборки и Android

Дата: 2026-11-04

Статус: Принято

## Контекст

Dependency review при обновлении AGP обнаружил Guava 33.4.0-jre с CVE-2026-102554. Полный граф также содержит Guava 33.3.1-android через Media3. Уязвимость выделения памяти при десериализации затрагивает обе разновидности; исправлена в 33.7.2. Наличие библиотеки не доказывает доступность уязвимого пути в приложении.

## Решение

Хранить общий номер `guavaVersion=33.7.2` в `gradle.properties`. Для корневого classpath и независимого `:app/androidLintTool` выбирать `-jre`, для транзитивной зависимости приложения — `-android` через ограничение implementation. Не добавлять JRE-вариант в APK. Артефакты обеих разновидностей закрепить в `toolchain.lock.json` с контрольными суммами.

`make check-resolved-dependencies` строит полный граф официальным плагином Gradle и проверяет Bouncy Castle и Guava во всех найденных конфигурациях. Команда входит в `make check`; прежняя `make check-build-crypto` остаётся совместимым псевдонимом. Регрессионные тесты должны отклонять старую Guava в инструментарии даже при исправленном Android-варианте и старую Android-версию при исправленном JRE-варианте. Пустой или неполный граф и неизвестные версии не считаются успехом.

После изменения выполнить `make check`, `make ci-lint`, `make codeql-build` и `make build BUILD_TYPE=release`. Поскольку меняется транзитивная зависимость Media3, перед слиянием дополнительно проверить настоящее видео в эмуляторе: видимые меняющиеся кадры, паузу, перемотку и возврат. В CI дождаться Dependency review по новому графу без исключения уязвимости.

## Альтернативы

- Исправить только JRE-вариант. Оставляет уязвимую Android-зависимость.
- Исключить Guava из Media3. Может нарушить работу плеера.
- Разрешить предупреждение в Dependency review. Не исправляет зависимость.

## Последствия

Версии сборки и приложения проверяются отдельно. При будущих обновлениях ограничения можно удалить после подтверждения исправленных транзитивных версий. Локальная проверка известных минимальных версий дополняет обновляемую базу уязвимостей GitHub и не заменяет её.
