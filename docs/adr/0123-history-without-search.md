# ADR-0123: История просмотров без поиска

Дата: 2026-11-09

Статус: Принято

Дополняет [ADR-0039](0039-account-viewing-history.md).

## Контекст

При исследовании страницы истории после входа найдены поиск по названию, кнопка очистки и пагинация. Отдельных условий жанра, страны и периода не обнаружено. Работа серверного поиска подтверждена, но пользователь явно решил не добавлять его в приложение.

## Решение

- История приложения остаётся хронологическим списком с существующей подгрузкой страниц и сохранением порядка и повторов.
- Поиск по истории в приложение не добавлять и отдельную задачу на его реализацию не вести. Исследование фильтров истории отметить завершённым в TODO.
- Подтверждённый контракт сайта сохранить в документации API как результат исследования. Возврат к реализации поиска потребует нового решения.
- Общую панель жанра, страны и периода к истории не подключать: таких фильтров в проверенном интерфейсе сайта нет.

## Альтернативы и последствия

Сайт поддерживает серверный поиск, а локальный поиск потребовал бы определить охват загруженных страниц. Оба варианта исключены из текущего продукта по решению пользователя. Очистка истории при исследовании не выполнялась; её реализация и проверка остаются вне этого решения.
