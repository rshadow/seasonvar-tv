# ADR-0042: Стандартная озвучка при несовпадении или удалении перевода

Дата: 2026-11-03. Статус: принято. Пересматривает обработку отсутствующей озвучки из [ADR-0040](0040-details-entry-context.md).

## Контекст

Название озвучки в списке может отличаться от названия в карточке или отсутствовать в доступных вариантах. Это особенность данных сайта; озвучку также могут удалить. Пользователь выбрал автоматический откат к стандартной, после которого можно вручную переключить перевод.

## Решение

Если указанные ID или название озвучки однозначно сопоставились с доступным переводом, выбираем его. Если сопоставления нет или оно неоднозначно, автоматически выбираем стандартную озвучку. Модальное предупреждение и дополнительное подтверждение не нужны.

Стандартную определяем по доступным данным сезона: сначала перевод с ID `0`, затем вариант с явным названием «Стандартная»/«Стандартный»/«По умолчанию», затем перевод сайта по умолчанию, затем первый доступный. Отсутствующие варианты не создаём.

Известные сезон и серия сохраняют приоритет. В выбранной стандартной озвучке выбираем именно известную серию. Если её там нет, показываем проблему выбора серии и оставляем ручной выбор серии или другой озвучки. Автоматически другую серию не подставляем. Для полностью отсутствующей озвучки в исходной записи продолжают действовать правила заполнения неизвестных параметров из ADR-0040.

Локальная отметка другой озвучки не отменяет откат к стандартной. Продолжение с локального времени разрешено только для совпадающих сезона, озвучки и серии. Исходное название озвучки остаётся в неизменяемом `SeriesEntry`; фактический выбор хранится отдельно в состоянии открытой карточки по [ADR-0041](0041-shared-catalog-entry.md).

## Альтернативы и последствия

Ошибка и обязательный ручной выбор при каждом несовпадении требуют лишних нажатий и мешают просмотру из-за различий в данных. Подмена серией из локальной отметки меняет выбранный пользователем эпизод.

После отката карточка сразу готова к просмотру известной серии в стандартной озвучке, если она доступна. Пользователь может переключить озвучку обычным селектором. Проверки охватывают отсутствующее название/ID, неоднозначное название, приоритет стандартного ID над иным переводом по умолчанию и отсутствие нужной серии в стандартной озвучке.
