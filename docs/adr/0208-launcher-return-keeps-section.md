# ADR-0208. Сохранение раздела при возврате через ярлык

Дата 2026-11-26. Статус принят. Уточняет [ADR-0045](0045-start-page-setting.md).

## Контекст

После Home лаунчер открывает Seasonvar через `ACTION_MAIN` и категорию `LEANBACK_LAUNCHER`. Если исходный запуск произошёл через другой Intent, Android может добавить вторую `MainActivity` в ту же задачу. Новая Activity применяет настройку «При запуске», хотя прежнее окно с выбранным разделом ещё существует.

## Решение

Главная Activity использует режим `singleTop`. Если она уже наверху задачи, Android повторно использует её и сохраняет текущий раздел, фокус и список. При новом запуске действует настройка «При запуске». Изолированный генератор профиля проверяет выбор другого пункта, Home и возврат с Intent ярлыка Android TV.

## Альтернативы и последствия

`singleTask` может закрывать окна поверх главной Activity. `singleTop` сохраняет существующий порядок окон Android и устраняет повторное создание главного окна в проверенном сценарии. После завершения задачи пользователь получает выбранный стартовый раздел. [Документация Android о режимах запуска](https://developer.android.com/guide/components/activities/tasks-and-back-stack)
