# ADR-0032: Явная недоступность просмотра и обновление данных карточки

Дата: 2026-11-02

Статус: Принято. Уточняет состояния карточки и запуск из [ADR-0031](0031-native-playback.md).

## Контекст

При проверке на Ugoos первый сезон «Экстрасенсы. Реванш» открыл описание, но не имел переводов и серий. Оригинальный сайт вернул `.pgs-player-block` с сообщением о блокировке сезона для страны по просьбе правообладателя. В приложении оставалась кнопка «Смотреть», нажатие которой ничего не делало.

Наличие описания и HTTP 200 не подтверждает доступность просмотра. Отсутствие серий без объяснения также не доказывает ограничение правообладателя.

## Решение

- Сохранять необязательный текст `.pgs-player-block:not(.error)` в `SeriesDetails.playbackUnavailableReason`, очищая HTML. Показывать его на месте списка серий. Не подменять сведения о сериале общей ошибкой загрузки.
- Предлагать «Смотреть» / «Продолжить» только при наличии выбранной серии и отсутствии явного ограничения сайта. При недоступном просмотре действие называется «Обновить данные» и повторно загружает страницу. Пустое или отсутствующее `arEpisodes` без сообщения сайта сохраняет отдельное состояние списка серий.
- Явное ограничение запрещает запуск даже при наличии оставшихся метаданных серий. Выбор другого сезона остаётся доступным; интерфейс и фокус на кнопках сохраняются.
- Любой явный повтор загрузки карточки обходит кэш метаданных; обычное открытие продолжает использовать кэш по ADR-0003. Повтор не меняет сетевые настройки.
- Для отладки использовать debug-теги `SeasonvarDetails` и `SeasonvarPlayback`: ID сезона/перевода/серии, этап запроса, классы причин, HTTP-статус, место в коде и код Media3. Сообщения исключений и объекты Throwable в лог не передавать: они могут содержать временные ссылки. Длину цепочки причин ограничивать.

## Альтернативы и последствия

Скрытая либо выключенная кнопка просмотра не даёт действия для повторной проверки и усложняет восстановление начального фокуса. Кнопка «Обновить данные» остаётся полезной точкой входа и позволяет проверить изменившуюся доступность. Подставлять другой сезон или поток при ограничении нельзя: это меняет выбранный контент без ведома пользователя.

Приложение не устраняет ограничение сайта. Сообщение сайта и ошибка сети остаются разными состояниями. Свежие запросы при ручном обновлении добавляют сетевую работу, но не меняют обычное открытие из кэша.

## Проверка

Регрессионные тесты проверяют сообщение из очищенной фикстуры ограниченного сезона, сохранение описания/выбора сезона, запрет запуска, ручную загрузку поверх кэша и отсутствие URL/сообщений исключений в диагностике. Реальная сеть и пульт проверяются отдельно на приставке.

На Ugoos подтверждены сообщение первого сезона «Экстрасенсы. Реванш», повторная загрузка, выбор третьего сезона и запуск его видео с возвратом на исходную карточку каталога. Для «Боруто» прежний HTTP 404 воспроизведён на устройстве; после исправления имени файла проверены изображение, пауза, перемотка и продолжение в debug- и profile-сборках. Проверка управления выполнена через ADB-имитацию пульта. Прошли `make check` (109 JVM-тестов, 17 Python-тестов, Lint) и `make build-profile` с R8.
