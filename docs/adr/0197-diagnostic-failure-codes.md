# ADR-0197. Этапы и коды ошибок самодиагностики

Дата: 2026-11-21. Статус: принято. Дополняет [ADR-0196](0196-device-diagnostics.md).

## Контекст

По общему статусу «Проверка не прошла» нельзя определить причину сбоя. Отдельный тестовый ключ может работать даже при повреждении рабочего ключа сессии.

## Решение

Строка диагностики при сбое показывает первый неудачный этап и короткий код причины. Независимые проверки продолжаются. Код состоит из идентификатора операции и категории причины, например `S04-COMMIT` для неподтверждённой записи сессии. Если Android сообщает числовой код Keystore или файловой системы, включаем его в код.

«Аккаунт» показывает код ошибки реального входа или восстановления. Диагностика показывает последний сбой каждой операции в течение 24 часов. Локальная запись содержит вид операции, время, этап и код причины. Если хранилище недоступно, код доступен в памяти до перезапуска или истечения срока.

## Альтернативы и последствия

Текст исключения может содержать значения из входных данных. Фиксированные коды позволяют передать результат в одном обращении без содержимого сессии и полного журнала.
