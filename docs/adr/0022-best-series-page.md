# ADR-0022: Раздел «Лучшие сериалы» из отдельной страницы сайта

Дата: 2026-11-02

Статус: Принято

## Контекст

Ссылка «Лучшие сериалы» ведёт на `/?mode=top`. В проверенном ответе 100 позиций с другими ссылками и порядком, чем у боковой AJAX-подборки «Топ». Страница содержит названия, краткие описания и необязательное количество сезонов.

## Решение

- Добавить пункт «Лучшие сериалы» после «Новинок». Получать отдельную страницу `GET https://seasonvar.ru/?mode=top`, без начального запроса главной и без подмены AJAX-«Топом».
- Разбирать только строки `.pgs-search-wrap` внутри основного `#search-res`; сохранять порядок и точные ссылки сайта. Фильтры периода и жанра пока не добавлять: показывать результат страницы по умолчанию.
- Количество сезонов хранить отдельно от номера сезона. При отсутствии подписи не подставлять один сезон. Серии и бейджи, которых нет в этой разметке, не придумывать.
- Использовать краткое описание из списка при ожидании или недоступности полного описания. Полное описание продолжать получать со страницы по точной ссылке; диалог сохраняет загрузку, ошибки и повторную попытку.
- Использовать общую ленту, постеры, фиксированные карточки, названия и навигацию. Выбор, прокрутку и состояние фокуса хранить отдельно для раздела.
- Кэшировать страницу в `best.html` до 24 часов, не заменять хороший кэш невалидным ответом. Сетевые настройки и кэш описаний/постеров общие с остальными разделами.
- Проверять загрузку через `make site-best`. Автономные тесты используют [очищенную разметку](../../app/src/test/resources/best.html): порядок и поля 100 позиций сохранены, описания сокращены или заменены тестовыми.

## Альтернативы

- Объединение с «Топом» меняет список и ссылки на сезоны.
- Разбор всей страницы без ограничения основным блоком добавляет посторонние ссылки боковых панелей.
- Использование числа сезонов как номера сезона вводит пользователя в заблуждение.

## Последствия и ограничения

В проверке 2026-11-02 получены HTTP 200, 256 522 байта HTML и 100 позиций. Количество в приложении не фиксируется. Алгоритм ранжирования, AJAX фильтров и пагинация не проверены. Краткое описание из списка может быть обрезано сайтом.
