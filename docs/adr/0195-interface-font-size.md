# ADR-0195. Размер шрифта в интерфейсе

Дата: 2026-11-20. Статус: принято.

## Контекст

При системном шрифте 125% длинные названия разделов обрезаются в боковом меню. Проба с увеличенной плотностью показала подписи целиком, но лента заняла область описания сериала.

## Решение

В «Настройки → Приложение → Размер шрифта» доступны «Обычный» и «Крупный». По умолчанию выбран «Обычный», который следует системной настройке Android. Крупный режим задаёт для текста Compose минимум 125% системного базового размера. Выбор применяется сразу и сохраняется на устройстве. В крупном режиме расширяются боковое меню и кнопка «Рецензии». Карточки пересчитывают текстовые области по текущему масштабу. Текст нативных элементов Media3 следует настройке Android.

## Альтернативы и последствия

Изменение плотности увеличивает изображения, отступы и размеры элементов, включая ленту. Настройка типографики с расширением отдельных областей сохраняет размеры иконок и плотность большинства экранов. При проверке нужны длинные названия и переходы фокуса вокруг настройки.
