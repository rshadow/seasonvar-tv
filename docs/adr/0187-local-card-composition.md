# ADR-0187. Обновление отдельных карточек списка

Статус: принято. Дата: 2026-11-18. Дополняет [ADR-0127](0127-shared-list-preparation-window.md).

## Контекст

При смене фокуса внутри видимой строки плитки выполнялись неизменившиеся карточки. Блок элементов списка захватывал выбранный ключ и обработчики текущего экрана. Миниатюры наблюдали общую карту подготовленных данных, поэтому сдвиг окна предзагрузки затрагивал даже карточки с прежним содержимым.

## Решение

Список передаёт карточкам стабильные ссылки на состояние. Выбранный ключ читается в карточке только для публикации её фонового постера. Изменение ключа затрагивает подписки карточек, для которых меняется признак выбора. Навигация и планирование предзагрузки используют прежний ключ.

Миниатюра наблюдает результат подготовки своей записи. Исходная карта остаётся в общем движке, а результат для карточки считается изменившимся при смене экземпляра подготовленных данных. Фокус, открытие и долгое нажатие читают актуальные обработчики в момент вызова. Состояния обработчиков принадлежат ключу каталога, чтобы уходящая карточка не получила действие нового раздела.

## Альтернативы и последствия

Отдельное хранилище на каждую запись усложнило бы вытеснение и очистку. Производное состояние ограничено скомпонованными карточками ленты и плитки и использует существующее хранилище. Сценарий пульта, границы карточек и подготовка окна сохраняются. Снижение числа выполнений и выделений проверяется отдельно от времени кадра.
