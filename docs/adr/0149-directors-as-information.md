# ADR-0149: режиссёры в информации о сериале без поиска

Статус: принято. Дата: 2026-11-13.

## Контекст

Приложение выводит режиссёров в информации о сериале. При [исследовании поиска сайта](../api/web-api.md#актёры-и-режиссёры--проверка-2026-11-13) отдельный серверный поиск по режиссёрам не подтверждён. Локальная фильтрация исключена пользователем.

## Решение

Сохраняем существующее отображение режиссёров обычным текстом. Поиск по ним и переходы из их имён не добавляем.

## Альтернативы и последствия

Локальная фильтрация потребовала бы собирать данные карточек и не соответствовала бы выбранному серверному поиску. Текущее отображение сохраняет сведения о режиссёрах без изменения интерфейса. Решение о поиске по актёрам принимается отдельно.
