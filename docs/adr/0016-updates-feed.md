# ADR-0016: «Обновления» из боковой подборки сайта

Дата: 2026-11-02

Статус: Принято

## Контекст

Нужен пункт «Обновления», повторяющий одноимённую подборку Seasonvar. Она отличается от [«Сегодня»](0010-today-feed.md): содержит последние обновления без фильтра по дате устройства.

## Решение

- Читать встроенный в публичную главную `GET /` блок `li[data-tabr=rside-new][data-tabgr=rightside]`. Селекторы и результаты проверки хранить в [web-api.md](../api/web-api.md).
- Сохранять порядок сайта, названия, подписи серий/озвучек и точные ссылки. Не сортировать и не объединять записи одного сезона с разными обновлениями или озвучками. В проверенном ответе 50 позиций на 48 страниц сезонов.
- Использовать существующую ленту с описанием и постерами по [ADR-0006](0006-tv-navigation-and-content-layout.md). Пункт показывается сразу при получении фокуса в меню; OK/вправо переводят в список.
- Использовать общие модели, парсер и репозиторий каталога, отдельный экземпляр ViewModel для каждой выдачи. Выбор карточки и позицию прокрутки хранить отдельно для «Сегодня» и «Обновления». Esc/Back из описания возвращают на выбранную карточку.
- Загружать «Обновления» при первом открытии, обновлять кнопкой «Обновить» и после изменения сети. При повторном переключении меню сохранять загруженный список.
- Хранить последнюю корректную главную для этой подборки отдельно, до 24 часов. При запуске показывать кэш с фоновым обновлением; при ошибке отмечать сохранённые данные. Невалидный ответ не заменяет хороший кэш. Правило текущего дня для «Сегодня» остаётся прежним.
- Различать загрузку, пустой результат и ошибки сети, HTTP и разметки. Отсутствие блока подборки считать ошибкой разметки.

## Альтернативы

- Объединение с «Сегодня» меняет состав выдачи.
- Дополнительный AJAX-запрос не требуется для начального списка: все 50 позиций уже есть в главной.

## Последствия и ограничения

Состав списка задаёт сайт. Сортировку, фильтрацию и пагинацию от себя не добавляем. Подтверждён только встроенный список; способ получения следующих страниц не установлен. Авторизация не требуется, видео на этом этапе не воспроизводится. При изменении разметки понадобится обновить парсер.
