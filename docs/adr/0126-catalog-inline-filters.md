# ADR-0126: Отдельный каталог с фильтрами на странице

Дата: 2026-11-09

Статус: Принято; компоновка и начало реализации уточнены в [ADR-0132](0132-compact-catalog-page.md)

Пересматривает [ADR-0118](0118-shared-list-filter-panel.md) и [ADR-0120](0120-filter-icon-button.md) только для будущего экрана «Каталог». Для остальных списков общая модальная панель сохраняется. Правила общей темы, стабильной разметки и немедленного сброса из [ADR-0008](0008-centralized-ui-theme.md), [ADR-0114](0114-stable-async-layout.md) и [ADR-0119](0119-filter-reset-and-action-buttons.md) продолжают действовать.

Получение большого списка, кэш и общее окно подготовки карточек и обложек определены в [ADR-0127](0127-shared-list-preparation-window.md).

## Контекст

Пользователь выбрал отдельный вход в каталог рядом с поиском и постоянно видимые фильтры. Полная вертикальная форма заняла бы место описания выделенного сериала. Требуется собственная компоновка экрана с компактными фильтрами, описанием и результатами. Точные размеры и состав видимых полей ещё обсуждаются.

В проверенном обработчике каталога нет поля названия: фильтрация через `POST /index.php` и поиск через `/autocomplete.php` — разные запросы. Локальный поиск по названиям технически возможен, но пользователь выбрал каталог только с фильтрами. Контракт и результаты сетевой проверки — в [документации API](../api/catalog-filters.md#проверка-выдачи-каталога-и-рейтингов--09112026).

## Решение

- Открывать «Каталог» отдельной кнопкой рядом с поиском. Отдельный пункт бокового меню, вкладки общего экрана поиска и перенос поискового запроса в каталог не входят в это решение.
- В каталоге нет строки поиска по названию. Подбор выполняется фильтрами и сортировкой; существующий поиск остаётся отдельным сценарием.
- Оценки IMDb/КиноПоиска на экране каталога не показывать: их нет в основной выдаче. Не выполнять дополнительные запросы только ради оценок. Это не исключает серверный фильтр и сортировку по рейтингу и не меняет рейтинги в существующей полной карточке сериала.
- Основные области экрана идут сверху вниз: фильтры, описание выделенного сериала, список найденных сериалов. При перемещении по списку описание относится к текущему выделению.
- Фильтры видны непосредственно в верхней части страницы. Вся форма не открывается отдельной модальной панелью. Компоновку каталога разрабатывать отдельно, используя общие стили и компоненты выбора значений.
- Группу «Прочее» не добавлять. Предлагавшиеся в ней доступность в стране, «Скоро на сайте» и переключение оригинальных названий исключены из объёма каталога; не переносить их в другие группы. Наличие этих параметров на сайте сохраняется в документации протокола и не означает план их реализации.
- Сохранять применённые фильтры и сортировку локально, восстанавливать при возвращении в каталог и после перезапуска. Если условия зависят от аккаунта, соблюдать разделение владельцев из ADR-0118. Сохранение условий не означает вечного кэширования выдачи: данные обновляются для восстановленного набора условий.
- Сортировка по умолчанию — «По добавлению», самые недавно добавленные сериалы первыми. Использовать её при первом открытии без сохранённого выбора и после сброса. Если пользователь выбрал другую сортировку, восстанавливать её вместе с условиями. В исходнике сайта этому варианту соответствует `sortTo[]=newest`; свежий анонимный ответ проверен в документации API. Не заменять этот порядок сортировкой по году выхода.
- Кнопка «Сбросить» снимает ограничения и возвращает сортировку «По добавлению» без дополнительного подтверждения применения по ADR-0119.
- Изменённые условия запрашивать по кнопке «Применить», когда пользователь закончил их выбирать. Сброс остаётся немедленным действием. Расположение кнопок на собственной странице ещё требует согласования.
- Фильтры занимают ограниченную область, оставляя место описанию и нижнему списку. Загрузка данных не меняет расположение этих областей и не сдвигает фокус.
- Этот ADR фиксирует направление экрана, а не разрешение начинать реализацию. Пункты TODO остаются незавершёнными.

## Что ещё решить

- Высота области фильтров, количество строк и набор полей, видимых сразу; способ доступа к редким условиям и выбора значений.
- Размещение кнопок «Применить» и «Сбросить» на странице.
- Размеры описания и нижнего списка, переходы фокуса между областями.

## Альтернативы и последствия

Общая выдвижная панель скрывает фильтры и не соответствует выбранной компоновке каталога. Единый поиск с фильтрами требует отдельной семантики совмещения двух источников. Отдельный пункт меню и вкладки поиска рассматривались, но выбран прямой вход кнопкой рядом с поиском.

Собственный экран требует проверки плотности на телевизоре: каталог должен одновременно сохранять доступ к фильтрам, описанию и результатам. Повторно использовать общие оформление и поведение выбора, а не копировать стили. До согласования компактной компоновки реализацию не начинать.
