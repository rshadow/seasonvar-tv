# ADR-0057: Удаление отметки сезона из личных списков

Дата: 2026-11-04

Статус: Принято

Дополняет [ADR-0034](0034-resume-current-markup.md), [ADR-0041](0041-shared-catalog-entry.md) и [ADR-0056](0056-automatic-account-playback-marks.md).

## Контекст

На сайте крестик личной карточки снимает постоянную отметку сезона. На телевизоре дополнительная кнопка поверх каждой миниатюры усложняет листание. Пользователь выбрал два доступа к одной операции: удержание OK в личном списке и явную кнопку в открытой карточке сериала.

## Решение

- Короткое OK по миниатюре открывает сериал. Удержание OK/Enter в течение системного порога открывает меню «Открыть сериал» / «Удалить из списка». Долгое нажатие мышью или касанием открывает то же меню. Отпускание кнопки после удержания не открывает сериал и не активирует пункт появившегося меню.
- Дополнительные точки фокуса в ленту не добавляются. Для личных подборок показывается краткая подсказка об удержании OK. У обычных каталогов и записей истории это меню удаления отсутствует.
- В открытой карточке есть «Удалить из списка» в строке управления, после сезона/озвучки и перед прогрессом. Она доступна для отмеченного сезона и при открытии из поиска или публичной подборки: наличие отметки проверяется в аккаунте. При смене сезона проверяется новый сезон.
- Оба способа открывают одно подтверждение с названием сериала и номером сезона, кнопками «Отмена» и «Удалить». Первый фокус — на отмене. Текст объясняет удаление отметки из аккаунта и связанных подборок. История просмотров и локальное продолжение сохраняются.
- Назад/Esc и закрытие диалога возвращают фокус к исходной миниатюре или кнопке карточки. Подтверждённая операция не отменяется при закрытии её окна во время сетевого запроса. Если ошибка пришла после закрытия, показать краткое сообщение; открытое подтверждение показывает ошибку и повтор.
- Удалять из интерфейса только после подтверждения сервером и повторным чтением. При сбое сохранять карточку и позволять повторить операцию. Повторное подтверждение во время запроса не создаёт ещё один запрос.
- После удаления в ленте выбирать следующий элемент на прежней позиции, а для последнего — предыдущий. Не сбрасывать прокрутку в начало; для пустого списка фокус возвращается к его управлению. Открытая полная карточка остаётся на том же сезоне, кнопка удаления исчезает, фокус переходит к «Смотреть»/«Продолжить».
- Снимать отметку только выбранного сезона. Не удалять автоматически отметки других сезонов, даже если ответ сайта предлагает это. Сезон может исчезнуть сразу из «На чём остановились» и «Есть обновления»/«Нет новых серий». Не представлять действие как удаление всех сезонов сериала или очистку истории.
- Типизированная цель `AccountListMark` хранится в общей `SeriesEntry`. Парсер проверяет ID элемента удаления, когда он есть в ответе. Интерфейс не извлекает ID из подписи или ключа карточки.
- Использовать авторизованный POST `jsonMark.php` с единственным параметром `delId=<ID сезона>`. Проверять `msg=success`, затем отсутствие отметки на свежей странице того же сезона под той же учётной записью. Если отметки уже нет, считать удаление идемпотентно успешным без лишнего POST. Не показывать успех при пустой гостевой странице или неожиданной разметке.
- Удаление сериализуется с автоматической записью прогресса. Дождаться уже отправляемой записи, убрать ожидающие записи того же сезона/аккаунта и отсеять отложенные события, созданные до удаления. Другое устройство без версионного протокола сайта всё ещё может создать отметку заново. Новый просмотр в приложении также может создать её по ADR-0056.
- Запоздалые ответы и подтверждение прежней сессии не должны менять данные другого аккаунта. После подтверждённого удаления обновлять связанные личные списки и прогресс без смены версии сессии и переключения раздела.

### Схема

```text
Лента:  [карточка] ── короткое OK ──> полный экран сериала
                  └─ удержание OK ─> Действия с сериалом
                                     Открыть сериал
                                     Удалить из списка ─┐
                                                       v
Полная карточка: [Смотреть] [Сезон ▾] [Озвучка ▾] [Удалить из списка]
                                                       |
                                                       v
                         Удалить из списка?
                         Название · сезон N
                         [Отмена]  [Удалить]
```

## Альтернативы

- Крестик на постере отклонён пользователем: усложняет переходы фокуса в ленте.
- Только удержание OK экономит место, но его трудно обнаружить. Явная кнопка в полной карточке делает действие доступным без знания жеста.
- Только кнопка в полной карточке требует открывать сериал для каждой операции.
- Мгновенное удаление без подтверждения повышает риск случайно снять отметку прогресса аккаунта.

## Последствия

Удаляется постоянная серверная отметка, а не произвольное членство в одной вкладке. Подборки сайта частично пересекаются. Очередь автоматических сохранений и ручное удаление должны использовать общий порядок операций; один вызов HTTP без согласования с очередью недостаточен.

Источники: [публичный скрипт отметок Seasonvar](https://cdn.svstat.net/asset/js/pg.marks.min.js?25.4.1), [контракт проекта](../api/web-api.md#6-запись-отметок). JavaScript повторно проверен 2026-11-04. Обратимый `make mark-probe MARK_PROBE_MODE=delete-roundtrip` подтвердил удаление, отсутствие во всех личных подборках и восстановление исходной отметки. В эмуляторе проверены удержание и короткое OK, оба входа в подтверждение, отмена через Назад/Esc и возврат фокуса. Выбор соседа после удаления и конфликты с автосохранением проверяются автономными тестами.
