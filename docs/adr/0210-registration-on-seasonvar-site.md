# ADR-0210: регистрация на сайте Seasonvar

Статус: принято. Дата: 2026-11-27. Дополняет [ADR-0033](0033-account-and-resume.md).

## Контекст

Создание аккаунта требует доступа к почте. После отправки веб-формы Seasonvar предлагает продолжить по ссылке из письма. [Проверенный контракт сайта](../api/web-api.md#регистрация-по-e-mail)

## Решение

На экране «Аккаунт» слева расположена форма входа, справа — шаги регистрации под заголовком «Нет аккаунта?» и кнопка «Открыть seasonvar.ru». Кнопка открывает веб-форму регистрации в браузере. Пользователь указывает почту и пароль, открывает ссылку из письма и возвращается в приложение для входа. Стрелка вправо от «Войти» переводит фокус к кнопке открытия сайта, стрелка влево возвращает к форме. Если браузер недоступен, подсказка предлагает открыть seasonvar.ru на телефоне или компьютере.

## Альтернативы и последствия

Встроенная форма потребовала бы поддерживать ошибки регистрации и переход между телевизором и почтой. Сайт ведёт пользователя через эти шаги, а приложение использует существующий вход, когда аккаунт готов.
