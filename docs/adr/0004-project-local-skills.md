# ADR-0004: Подключать скиллы локально для проекта

Дата: 2026-11-01

Статус: Принято

## Контекст

Специализированные инструкции нужны в контексте определённого проекта. Пользователь не хочет подключать их глобально и применять в несвязанных задачах.

## Решение

Любые скиллы, которые подключаем для этого проекта, хранить локально в `.agents/skills` внутри Seasonvar независимо от их источника и назначения. Глобальная установка проектных скиллов не используется.

Правила применения записывать в `AGENTS.md`. Текущий список используемых скиллов, их источники и закреплённые версии вести в [README каталога скиллов](../../.agents/skills/README.md). Конкретный набор может меняться без изменения этого ADR, пока сохраняется локальная область подключения.

Хранить необходимые ресурсы вместе со скиллом и сохранять его лицензию.

## Альтернативы

- **Глобальная установка.** Делает специализированные инструкции доступными в несвязанных проектах.
- **Только ссылки на удалённые инструкции.** Не обеспечивает локальное обнаружение скиллов и сохранение выбранной версии с проектом.

## Последствия

Подключённые для проекта скиллы хранятся с его исходниками и доступны агентам при работе в каталоге проекта. При обновлении нужно проверять изменение инструкций и фиксировать исходную версию.

Решение касается скиллов, которые добавляем для Seasonvar; оно не требует удаления встроенных скиллов или уже существующего пользовательского инструментария.

Основание: пользователь уточнил, что все скиллы проекта подключаются локально, а Android-скиллы должны быть перечислены как текущие используемые.
