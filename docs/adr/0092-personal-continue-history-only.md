# ADR-0092: «Для меня» и продолжение только по серверной истории

Дата: 2026-11-06

Статус: Принято

Уточняет [ADR-0091](0091-smart-continue-account-marks.md) в части названия группы и отбора карточек.

## Контекст

В группе со временем появятся другие персональные подборки. Название «Умные списки» излишне громкое. Для «Продолжить» нужен определённый порядок недавних просмотров; локальная активность не подходит, поскольку пользователь смотрит и на сайте, и в приложении.

## Решение

- Группа меню называется «Для меня», пункт — «Продолжить».
- Сохраняем расчёт целевой серии и времени по отметкам аккаунта из ADR-0091.
- Включаем только сериалы, найденные в серверной истории просмотра. Достаточно записи о любом сезоне этого сериала.
- Сортируем по первому появлению сериала в истории, от новых просмотров к старым. Повторы и старые сезоны не сдвигают найденную позицию.
- Отметка без записи в истории не создаёт карточку. Если таких записей нет, показываем обычное пустое состояние.
- Прежний кэш без фильтра по истории не используется. Новый кэш содержит только прошедшие этот отбор карточки; сессия и настройки сохраняются.
- Остальные списки сайта сохраняют прежний состав и порядок. Просмотр локальными датами не дополняем.

## Альтернативы

- Оставлять записи без истории в конце: пользователь выбрал только записи с известным порядком.
- Дополнять порядок локальными датами: не учитывает просмотр на сайте и других устройствах.

## Последствия и проверка

Список может быть короче списка отметок. Пока приложение не пишет в серверную историю, часть просмотров из приложения не попадёт сюда; синхронизация истории остаётся отдельным TODO.

Проверяем отбор и сортировку, пустую историю и отбрасывание старого кэша в `make check`; название группы и список — в тестовой сборке эмулятора.
