# ADR-0138: Cloudflare в выборе DNS

Дата: 2026-11-10

Статус: Принято

## Контекст

Одного внешнего DNS-провайдера недостаточно для сетей, в которых он недоступен. Пользователь выбрал Cloudflare как дополнительный вариант внутри приложения.

## Решение

В существующем диалоге «Сеть → DNS-сервер» показывать «Системный», «Quad9 DoH» и «Cloudflare DoH». Сохранять выбранного провайдера; прежние значения и начальный выбор Quad9 сохраняются. Выбор DNS независим от переключателя DPI-обхода.

Cloudflare использует `https://cloudflare-dns.com/dns-query` и bootstrap-адрес `1.1.1.1`. Общий сетевой клиент применяет выбранный DNS к сайту, постерам, плейлистам и видео. Системные настройки устройства не меняются, автоматического переключения на другой провайдер нет.

Сохранять системную проверку TLS и имени сервера. Для Cloudflare закреплять ключи SSL.com Root Certification Authority ECC и резервного RSA в общей конфигурации по ADR-0133; публичные сертификаты служат только тестовыми данными.

## Альтернативы и последствия

Автоматический перебор DNS добавляет неявное поведение и в этот этап не входит. Один явный выбор позволяет пользователю проверить другой провайдер. DoH помогает при проблемах DNS, но не заменяет обход блокировки IP или TLS. Проверять выбор пультом, все сочетания DNS/DPI, настоящие запросы и отказ при неправильном TLS pin.
