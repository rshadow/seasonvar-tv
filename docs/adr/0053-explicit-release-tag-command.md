# ADR-0053: Релизный тег только по явной команде пользователя

Дата: 2026-11-03

Статус: Принято

Уточняет запуск выпуска из [ADR-0050](0050-github-actions-builds-and-releases.md).

## Контекст

Отправка тега `v<versionName>` автоматически публикует GitHub Release. Пользователь хочет самостоятельно определять момент выпуска и явно запретил добавлять релизные теги без своей команды.

## Решение

- Агент создаёт и отправляет релизный тег только по явной команде пользователя.
- Разрешение на коммит, push, настройку или проверку автосборки не является разрешением на тег или выпуск новой версии.
- Проверять автосборку запуском по ветке. Успешные проверки и готовый APK не служат основанием для самостоятельного добавления тега.
- После явно запрошенной отправки тега GitHub Actions автоматически выполняет проверки, подпись и публикацию, как определено ADR-0050.

## Альтернативы

- **Самостоятельно добавлять тег для проверки всей цепочки выпуска.** Не соответствует требованию пользователя.

## Последствия

Завершение разработки и выпуск становятся отдельными действиями. Рабочие APK по-прежнему доступны в артефактах сборки ветки без нового релиза.
