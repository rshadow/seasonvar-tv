# ADR-0115: TODO как краткий чеклист

Дата: 2026-11-08

Статус: Принято

## Контекст

В TODO накопились описание API фильтров, таблицы параметров и результаты исследования. Пользователь попросил перенести их в документацию, оставить чеклист и закрепить правила в инструкциях агенту.

## Решение

В `TODO.md` оставлять заголовки групп и пункты `- [ ]` / `- [x]`. В пункте кратко описывать ожидаемый результат и давать ссылки на подробности. Статус отражает работающую реализацию с необходимыми проверками; принятие решения или исследование API не закрывает задачу реализации.

Контракты, параметры, источники и ограничения проверки хранить в `docs/api`, решения — в `docs/adr`, инструкции проверки — в `docs/development.md`. При переносе сохранять задачи, их статусы, источники и даты. Открытые задачи не удалять при сокращении текста.

Сведения о фильтрах вынесены в [документацию API](../api/catalog-filters.md). Правила ведения чеклиста добавлены в [AGENTS.md](../../AGENTS.md#ведение-todo).

## Альтернативы и последствия

Хранение всех сведений в TODO затрудняет просмотр оставшихся задач. Удаление подробностей теряет результаты исследования. Отдельная документация сохраняет сведения, а ссылки из чеклиста дают доступ к ним без дублирования.
