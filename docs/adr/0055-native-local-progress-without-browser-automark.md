# ADR-0055: Использовать существующее локальное продолжение просмотра

Дата: 2026-11-03

Статус: Принято

## Контекст

Публичный скрипт оригинального сайта хранит временную автометку только в localStorage конкретного браузера. В нативном клиенте уже есть локальный ResumePoint с сезоном, озвучкой, серией и временем по ADR-0031. После уточнения пользователь отказался от добавления отдельного механизма браузерной автометки.

## Решение

- Использовать существующее локальное продолжение просмотра и кнопку «Продолжить» для сохранённой выбранной серии.
- Отдельно воспроизводить markAuto или переносить браузерный localStorage в приложение не требуется. HTTP API для временной браузерной отметки в исследованном скрипте отсутствует.
- Сохранить существующий приоритет известных параметров перехода из списков по ADR-0040.
- Постоянные отметки аккаунта через jsonMark.php — отдельный серверный механизм. Отказ от браузерной автометки не определяет будущую синхронизацию постоянного прогресса.

## Альтернативы

- **Добавить ещё одну временную отметку.** Дублирует существующее локальное сохранение.
- **Использовать серверную постоянную отметку как временную.** Меняет данные аккаунта и требует отдельного решения о поведении синхронизации.

## Последствия

Код плеера в рамках этого решения не меняется. В API-документации сохранён исследованный контракт и отличие временной браузерной отметки от постоянной серверной.
