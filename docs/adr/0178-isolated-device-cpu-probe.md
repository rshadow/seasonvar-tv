# ADR-0178: изолированный замер фоновых вычислений на устройстве

Статус: принято. Дата: 2026-11-17. Дополняет [ADR-0177](0177-device-aware-background-cpu.md) и [ADR-0174](0174-isolated-baseline-profiles.md).

## Контекст

Результаты эмулятора неоднородны; пользователь запросил проверку общего CPU-бюджета на Ugoos. Установка обычной profile-сборки конфликтует с релизной подписью рабочего приложения. Сравнение разных APK и живых сетевых выдач смешивает стоимость вычислений, состояние ART и ожидание сайта.

## Решение

`make build-cpu-probe` собирает оптимизированный profile-вариант с тестовой подписью и отдельным идентификатором `ru.seasonvar.tv.cpucheck`. Свойство сборки `isolatedCpuProbe=true` действует только на profile. Обычный release и генератор Baseline Profile не меняются.

Для физического устройства требуются явный выбор serial и `--physical-device`. Этот режим скрипта всегда адресует изолированный пакет; произвольный идентификатор и рабочее приложение выбрать нельзя. Activity также разрешает физическое устройство только для изолированного пакета с явным флагом. Штатная проба без флага сохраняет ограничение эмулятором.

Стенд запускает настоящий общий интерфейс на фиксированных данных, локальных изображениях и собственном кеше. Он работает в отдельном процессе без запуска сетевых служб Application, не использует аккаунт и не воспроизводит видео. Внутри одного APK сравниваются обычный I/O и общий вычислительный предел; требуются подтверждённые ProfileInstaller и ART `speed-profile`. Компиляция затрагивает только диагностический пакет. Во время измерения меняется фокус экрана устройства; запуск разрешён только по запросу пользователя.

## Альтернативы и последствия

Обновление рабочего приложения тестовой подписью требует удаления данных и неприемлемо. Переподпись профилировочного APK релизным ключом сохраняет данные, но заменяет пользовательскую установку ради стенда. Изолированный пакет позволяет избежать обоих действий.

Измерение отражает вычисления и отрисовку на реальном устройстве, но не сетевые задержки, весь личный кеш и поведение видеодекодера. Диагностические переключатели отсутствуют в обычном release. Команды, данные и ограничения проверки находятся в [документации разработки](../development.md#фоновая-подготовка-и-отзывчивость).
