# ADR-0029: Управление перед описанием и фокус только на действиях

Дата: 2026-11-02

Статус: Видимость «Все серии» и навигация коротких списков уточнены в [ADR-0030](0030-all-episodes-threshold.md). Остальное принято. Пересматривает компоновку и фокус из [ADR-0028](0028-site-like-series-details.md).

## Контекст

Длинное описание справа от постера оставляло бесполезную пустую колонку слева. Пользователь согласовал перенос сведений вверх, управления под ними и описания в конец на всю ширину правой части. Дополнительно потребовал убрать большие рамки и оставить фокус только на кнопках и элементах управления сериями.

## Решение

```text
┌────────────────┬──────────────────────────────────────────────────┐
│ Главное меню   │ ┌──────────┐  Название                            │
│                │ │  Постер  │  Оригинальное название               │
│ Сегодня        │ │          │  Жанры · возраст · страна · год       │
│ Обновления     │ │          │  IMDb · КиноПоиск при наличии         │
│ Топ            │ └──────────┘  Режиссёры и полный состав             │
│                │               Остальные сведения                 │
│                │                                                  │
│                │ [▶ Смотреть]  [Сезон ▾]  [Перевод ▾]              │
│                │ Серии                                            │
│                │ … [37] [38] [39] [40] [41] [42] …                 │
│                │ [Все серии]                                      │
│                │                                                  │
│                │ Описание                                         │
│                │ Полный текст на всю ширину правой части.          │
│                │ Слева под постером пустая колонка не сохраняется. │
└────────────────┴──────────────────────────────────────────────────┘
```

- Вся правая часть прокручивается одной страницей. Меню остаётся слева.
- Все метаданные, включая режиссёров, актёров, год, жанры и рейтинги, располагаются в верхней колонке справа от постера. Списки переносятся и не обрезаются.
- Компактное управление просмотром, сезоном и переводом, лента и «Все серии» используют всю ширину под верхним блоком. Размер «Смотреть» определяется подписью.
- Полное описание расположено последним блоком и использует всю ширину содержимого. У него нет отдельной прокрутки и собственной точки фокуса.
- Внутри карточки фокус получают только кнопки просмотра/повтора, селекторы сезона/перевода, серии и «Все серии». Постер, заголовки, текст и контейнеры не фокусируются. Большие рамки вокруг информационных блоков удалены; видимое состояние фокуса остаётся у интерактивных элементов по общей теме.

## Управление пультом

Начальный фокус — «Смотреть» (или «Повторить» при ошибке). Автоматическая прокрутка в карточке лишь показывает скрывшийся элемент; полностью видимую кнопку не переносит к стандартной ТВ-позиции, чтобы не сдвигать заголовок без необходимости. Влево/вправо в строке действий выбирают соседнюю кнопку, вниз — выбранную серию. Вверх из строки действий прокручивает страницу к верхним сведениям, сохраняя фокус на кнопке. Нефокусируемый текст не создаёт промежуточных остановок.

Из любой серии вниз выбирает «Все серии». Следующие нажатия вниз с этой кнопки прокручивают страницу к описанию, сохраняя фокус на кнопке. При чтении вверх сначала прокручивает обратно к исходной позиции кнопки; следующее нажатие вверх возвращает фокус на выбранный эпизод. После закрытия сетки «Все серии» видна и снова получает фокус. Page Up/Page Down и колесо мыши прокручивают общую страницу без фокуса на тексте.

Смена сезона сохраняет видимость управления. Esc/«Назад», восстановление исходной карточки каталога, отсутствие реального воспроизведения и будущая модель продолжения сохраняются по ADR-0027/0028.

## Альтернативы и последствия

Сохранение описания рядом с постером расходует ширину на длинных текстах. Фокус на блоке чтения добавляет большую рамку и лишнюю остановку. Единая страница с управлением перед описанием предоставляет всю ширину тексту и оставляет навигацию на действиях. При чтении за пределами экрана фокус остаётся на последней кнопке; отдельного фокуса у описания нет.

Парсеры и сетевой контракт не меняются. Проверка в эмуляторе должна подтвердить ширину описания, отсутствие фокуса у текста, чтение пультом и возврат к выбранной серии. Размеры и цвета остаются в общей теме по ADR-0008.

## Проверка

В эмуляторе Android TV API 34 на «Наруто» подтверждены видимость заголовка при начальном фокусе на «Смотреть», отсутствие фокуса у текста и описание от левого края содержимого. С 37-й серии вниз выбирает «Все серии»; следующие нажатия вниз читают описание, вверх возвращает к кнопке и затем к 37-й серии. Esc восстанавливает исходный результат поиска. Прошли `make check` (77 JVM-тестов, 13 тестов Python, Lint) и `make build-profile`.
