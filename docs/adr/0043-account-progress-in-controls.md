# ADR-0043: Прогресс сезонов и серий в строке управления

Дата: 2026-11-03. Статус: принято и реализовано.

Уточняет формат [ADR-0038](0038-compact-account-marks.md) и размещение сведений в карточке по [ADR-0029](0029-series-controls-before-description.md).

## Контекст

Пользователь попросил перенести прогресс в конец строки кнопок «Смотреть», сезона и озвучки, сократить подпись до одного слова и одновременно показывать положение отметки по сезонам и прогресс серий внутри сезона. После обсуждения уточнил: нужен сезон отметки из общего числа сезонов, как прежде.

## Решение

Подпись — «Прогресс». Формат при наличии обоих значений:

```text
[Смотреть] [Сезон 3 ▾] [Перевод ▾]  Прогресс: сезоны 2 из 5 · серии 3 из 10
```

Числа — пример оформления. «Сезоны 2 из 5» означает, что отметка аккаунта относится ко второму сезону сериала с пятью сезонами. «Серии 3 из 10» — значение отметки эпизодов в этом сезоне. Это отображение позиции просмотра; число полностью просмотренных сезонов отдельно не подсчитывается.

- Прогресс — последний элемент после кнопок просмотра, выбора сезона и озвучки в общей строке управления. Это справочный текст без рамки, действия и точки фокуса, выровненный по высоте с кнопками.
- При нехватке ширины допускается естественный перенос; значения не обрезаются многоточием.
- При переключении сезона прежняя отметка убирается. После загрузки показываются данные аккаунта для выбранного сезона. Ручное переключение серии или озвучки не меняет серверную отметку.
- В информационном блоке открытой карточки прогресс не дублируется. Сообщение сайта и дата истории остаются в сведениях.
- В большой карточке над лентой применяется тот же формат для известных значений. На миниатюрах списков прогресса нет.

## Данные и неполная информация

Общая модель [ADR-0041](0041-shared-catalog-entry.md) содержит `AccountProgress`: отдельные необязательные значения `seasons` и `episodes`. Эпизоды связаны с точным ID сезона через `SeasonEpisodeProgress`. Интерфейс только форматирует готовые данные.

Сезон отметки берётся из записи авторизованного `/resume`, общее число сезонов — из списка сезонов открытой страницы, с устранением повторов ID. Номер в селекторе сам по себе не подтверждает отметку аккаунта. Спецвыпуски и нестандартная нумерация сохраняются в том виде, который отдаёт сайт; номер не заменяется порядковым индексом ссылки.

Пара эпизодов берётся из `.pgs-marks-current` вида «N из M». Для явно просмотренного сезона без этой пары допустима полная отметка по известному числу эпизодов стандартного плейлиста. Если успешное авторизованное чтение подтвердило отсутствие отметки, допустимо показать ноль из известного количества эпизодов. Заблокированная страница, неизвестное количество, неразобранная или противоречивая отметка не превращаются в ноль.

Если известно одно значение, показываем только его с единицей. Неизвестный сезон или общее количество не выдумываем. Сырые отметки сохраняются отдельно и неизменными. Полная карточка уточняет прогресс в фоне, не задерживая показ сведений и доступность кнопок. Ошибка чтения прогресса не блокирует просмотр.

## Альтернативы и последствия

Один счётчик без единицы неоднозначен. Подсчёт полностью просмотренных сезонов меняет смысл привычного указания позиции отметки. Отдельные строки занимают лишнее место, а фокус на справочном тексте добавляет нажатия.

Чтение прогресса не записывает отметки на сайт и не заменяет серверные данные локальной позицией плеера. Цвета и размеры берём из общей темы. Проверяем неполные данные, смену сезона, поздние ответы и отсутствие повторного вывода в сведениях.
