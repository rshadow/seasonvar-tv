# ADR-0186: Скорость воспроизведения

Дата: 2026-11-18. Статус: принято.

Уточняет вертикальную навигацию плеера из [ADR-0046](0046-player-episode-navigation.md).

Видимость центральных кнопок и навигацию при их скрытии определяет [ADR-0194](0194-player-controls-visibility.md).

## Контекст

Зрителю нужен выбор скорости с пульта, сохранение выбора между сериями и естественная высота голоса. В предварительном просмотре использовалось меню Media3 с шестерёнкой; его список не сохраняет настройку сериала.

## Решение

Центральные кнопки остаются на месте. Нижняя строка дополнительных действий начинается с кнопки текущей скорости. Навигация доступна при воспроизведении и на паузе:

```text
          [предыдущая] [−10] [▶/Ⅱ] [+10] [следующая]
                              ↓ ↑
          ─────────────── перемотка ───────────────
                              ↓ ↑
                                       [скорость 1×]
                                              OK
                              ┌ Скорость воспроизведения ┐
                              │ Как в настройках · 1×  ● │
                              │ 0,5×                   ○ │
                              │ 0,75×                  ○ │
                              │ 1×                     ○ │
                              │ 1,25×                  ○ │
                              │ 1,5×                   ○ │
                              │ 1,75×                  ○ │
                              │ 2×                     ○ │
                              └──────────────────────────┘
```

Кнопка скорости вне фокуса отображается без рамки. Фокус обозначается заливкой темы.

Из видео «Вверх» открывает центральные кнопки, «Вниз» переводит на перемотку. Следующее «Вниз» открывает фокус нижней строки. В списке начальный фокус стоит на выбранном пункте; стрелки только перемещают его, OK применяет значение, «Назад» отменяет выбор. После закрытия фокус возвращается на скорость. Меню не меняет состояние паузы и не издаёт звуков навигации.

В настройках приложения, в группе «Плеер», находится «Скорость по умолчанию» с начальным значением 1×. Выбор в плеере сохраняется отдельно для всего сериала по `SeriesDetails.serialId`, включая сезоны и озвучки. Точное значение 1× является отдельным выбором; «Как в настройках» удаляет переопределение. Изменение общей скорости влияет только на сериалы без переопределения. Данные хранятся локально и переживают перезапуск приложения, с сайтом и другими устройствами не синхронизируются. При отсутствии идентификатора применяется общая скорость, сохранение отдельного выбора недоступно.

Media3 получает `PlaybackParameters(speed, 1f)` до запуска каждого эпизода и при выборе скорости без перезапуска видео. Высота голоса всегда сохраняется; отдельной настройки нет. Это обработка длительности аудио с сохранением частоты тона, а не простое ускоренное чтение аудиосэмплов. Субтитры и дополнительные настройки плеера в это решение не входят.

## Альтернативы и последствия

Одна общая скорость не позволяет слушать разные сериалы в разном темпе. Сохранение по сезону потребовало бы повторного выбора при переходе между сезонами. Штатный список Media3 подходит для временного выбора, но не выражает наследование и не сохраняет предпочтения приложения. Потребуется проверять навигацию и восстановление настроек вместе с реальным воспроизведением; качество обработки звука зависит от материала и устройства.

## Источники

[Media3 PlaybackParameters](https://developer.android.com/reference/androidx/media3/common/PlaybackParameters) разделяет скорость и высоту тона. На сайте Seasonvar в загруженном 2026-11-18 скрипте PlayerJS 9.97.2 (`cdn.svstat.net/js/playerjs77.js`) есть обработчик скорости, но пункт `settings5action: "speed"` выключен значением `settings5: 0`; визуальное наличие пункта в браузере не проверялось. Это не контракт хранения скорости аккаунта сайта.
