# ADR-0122: Дополнительные переключатели «Лучших сериалов»

Дата: 2026-11-08

Статус: Принято

Дополняет [ADR-0121](0121-best-list-genre-and-period.md), уточняя транспорт фильтров и сохранение условий аккаунта. Сохраняет общую панель, немедленный сброс и кнопку из ADR-0118–0120.

## Контекст

Пользователь выбрал следующий пункт TODO: дополнительные переключатели «Лучших сериалов». Сайт принимает их как POST `filterTop` и возвращает HTML-фрагмент. Три условия относятся к аккаунту; гостевой сервер их игнорирует. Показ отечественных сериалов имеет обратное значение параметра.

## Решение

- В общей панели после жанра и периода показывать строки с галочками: «В качестве Full HD (1080p)», «В качестве HD», «С субтитрами», «Показывать отечественные», «Доступны в моей стране».
- После входа добавлять «Скрывать смотримые», «Скрывать из истории», «Скрывать чёрный список». У гостя эти строки отсутствуют. «Из истории» относится к запускам на сайте, а не к постоянному статусу «Посмотрел». Доступность определяет сайт для страны запроса, а не фактический запуск видео клиентом.
- По умолчанию отмечен только показ отечественных сериалов. Сброс возвращает это состояние вместе с любым жанром и периодом один день. Снятый показ отечественных считается активным ограничением; в краткой подписи показывать «Без отечественных».
- OK меняет галочку в черновике; запрос выполняется по «Применить». Каждая строка имеет одну точку фокуса, нижние действия остаются на месте. Короткий набор полей прокручивается целиком, все его строки участвуют в явной цепочке фокуса; длинные справочники вариантов остаются ленивыми списками.
- Представлять переключатель отдельным типом поля общей панели. Активные галочки входят в счётчик и краткие подписи существующего заголовка. Радиокнопки личных списков и жанра/периода сохраняют прежнее поведение.
- Перед применением получать свежую полную страницу с выбранными жанром и периодом, проверять выбор и доступные элементы. Для личных ограничений читать эту страницу через репозиторий аккаунта с проверкой владельца; при истёкшей сессии закрывать панель вместе со сменой состояния аккаунта, а не принимать проигнорированные сервером флаги. Если есть дополнительные ограничения, отправлять восемь полей `filterTop[...]` на тот же URL. Включённое ограничение кодируется `yes`, отсутствие — пустой строкой. Для «Показывать отечественные» значение инвертировано: отмечено → `eng` пустой, снято → `eng=yes`.
- Разбирать фрагмент отдельно, сохраняя общую модель карточки. Пустой результат подтверждает специальное сообщение `.pgs-msg`; пустое тело и другие сообщения считать ошибкой. Не выдумывать заголовок страницы или аккаунта для фрагмента.
- Новые условия и выдача принимаются вместе. Ошибка оставляет старые карточки и черновик; отменённый запрос или ответ прежнего аккаунта не применяется. Открытие панели и изменение галочек не отправляют запрос выдачи.
- Общие условия хранить на устройстве. Три личных переключателя — отдельно для хешированного владельца аккаунта; при выходе их не переносить в гостевой набор или следующую учётку. Смена сессии закрывает панель и отменяет запросы. Постоянные отметки и история не записываются.
- Ключ гостевого кэша включает жанр, период и набор ограничений. Для POST сохранять отдельный JSON с проверенными параметрами, полной страницей справочников и фрагментом; при чтении проверять их соответствие. Авторизованные ответы по существующей политике не сохранять в публичный дисковый кэш. Полное чтение без переключателей сохраняет прежний формат кэша.

## Альтернативы и последствия

Локальная фильтрация первой сотни не воспроизводит серверный рейтинг. Передача дополнительных флагов через GET не соответствует проверенному обработчику. Одна запись кэша смешивала бы разные выдачи; общие настройки личных условий переносили бы выбор между аккаунтами. Параметры POST и правила пустой выдачи требуют отдельных проверок. Положительный пример исключения конкретного чёрного сериала в доступном аккаунте не установлен; это ограничение живой проверки, а не подтверждение изменения постоянного чёрного списка.

## Проверка

08.11.2026: `make check` — 562 JVM-теста, 39 Python-тестов, Android Lint и зависимости; `make run-profile DEVICE=emulator-5554` — успешный запуск итоговой сборки. Живой `make best-filters-probe` подтвердил восемь запросов у гостя и в аккаунте, специальную пустую выдачу и неизменность отметок и обычных GET. В эмуляторе визуально проверены все строки и галочки, прокрутка до последней строки, применение сочетания шести ограничений, короткие подписи и счётчик, отмена черновика, восстановление после перезапуска, пустой результат, немедленный сброс и показ отечественных по умолчанию. Панель проверена в сетке и ленте; итоговый личный фильтр применён с проверкой владельца сессии. Ошибки, истёкшая/сменившаяся сессия, раздельные кэши и настройки аккаунтов проверены автономно.
