# ADR-0052: Ссылка на GitHub в «О программе»

Дата: 2026-11-03

Статус: Принято

Уточняет поведение информационного раздела из [ADR-0013](0013-navigation-without-back-buttons.md).

## Контекст

Пользователь попросил добавить в «О программе» ссылку на публичный репозиторий приложения. Раньше экран не имел действий, поэтому фокус оставался на пункте меню.

## Решение

- Под сведениями о программе показывать кнопку «Проект на GitHub» и полный адрес `https://github.com/rshadow/seasonvar-tv`.
- Перемещение по меню по-прежнему только показывает раздел. OK или стрелка вправо из «О программе» переводят фокус на кнопку ссылки. Стрелка влево, Esc и «Назад» возвращают фокус на пункт меню. Сохраняется общий принцип двойного нажатия «Назад» для выхода.
- Нажатие кнопки передаёт HTTPS-адрес системному обработчику через `ACTION_VIEW`. Встроенный браузер и новые зависимости не добавляются.
- Если обработчика нет или открытие запрещено, оставаться в приложении и показать сообщение с предложением открыть видимый адрес на другом устройстве. Ошибка не должна приводить к падению.
- Кнопка использует общие размеры, цвета и скругления темы. Адрес и остальной текст не получают отдельный фокус.

## Альтернативы

- **Только текстовый адрес.** Не позволяет открыть проект с пульта при наличии браузера.
- **Встроенный WebView.** Добавляет отдельный экран и управление браузером ради одной ссылки.

## Последствия

«О программе» становится разделом с одним действием. Для открытия сайта требуется установленное приложение, обрабатывающее HTTPS-ссылки; адрес доступен для чтения и без него.

Источник: [Android — открытие URL при ограниченной видимости пакетов](https://developer.android.com/training/package-visibility/use-cases).

Проверка 2026-11-03: `make check` прошёл (227 JVM-тестов, 22 Python-теста и Lint). В эмуляторе Android TV API 34 проверены видимый адрес, вход в кнопку через вправо/OK и возврат через влево/Esc. Вместо полноценного браузера эмулятор использует системный `BrowserStub`, поэтому загрузка страницы в настоящем браузере не проверялась.
