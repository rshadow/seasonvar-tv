## Статус сведений

**По исходникам** означает, что запрос или парсер найден в указанной версии клиента. Это не подтверждение текущего ответа сервера. **Проверено в сети** означает результат нашего обращения без аккаунта с указанной датой. **Подтверждено пользователем** означает ответ, открытый в его браузере и переданный в чат. **Не установлено** означает, что контракта недостаточно для реализации без дополнительной проверки.

Приложению с учёткой сайта нужен протокол cookie-сессии. Старый API-ключ нельзя считать заменой логина и пароля: соответствие этих способов доступа не подтверждено.

## Быстрая проба в браузере

[Поиск «Игра престолов»](https://seasonvar.ru/autocomplete.php?query=%D0%98%D0%B3%D1%80%D0%B0%20%D0%BF%D1%80%D0%B5%D1%81%D1%82%D0%BE%D0%BB%D0%BE%D0%B2)

~~~bash
curl --get 'https://seasonvar.ru/autocomplete.php' \
  --data-urlencode 'query=Игра престолов' \
  --user-agent 'Mozilla/5.0' \
  --header 'Accept: application/json'
~~~

Пользователь открыл этот запрос в браузере и прислал реальный ответ с 14 результатами. См. [пример JSON](examples/autocomplete-game-of-thrones.json). Позднее агент также получил валидный JSON с 14 результатами через [локальный загрузчик](access.md).

## Применимость к нашему приложению

Для Ugoos нужен интерфейс с управлением пультом и адаптер оригинального сайта. Анонимное воспроизведение, вход, личные списки, локальное продолжение и автоматическая запись постоянной отметки реализованы. POST отметки подтверждён повторным чтением в авторизованном эмуляторе 2026-11-04; видео и управление проверяются отдельно после изменений плеера.

Найден открытый [SeasonvarTV](https://github.com/Zhmot666/SeasonvarTV), специально рассчитанный на Android TV. Он полезен как пример адаптера сайта. В исследованной версии видео открывается через WebView с внешним плеером, а работоспособность сборки нами не проверялась.
