# PAC и «АнтиЗапрет»

Проверено 2026-11-11 в Android TV API 34 ARM64. Источники: [FAQ](https://antizapret.prostovpn.org/faq.html), [техническое описание](https://antizapret.prostovpn.org/tech.html), скачанный пользователем оригинальный PAC и живая проверка приложения. Это внешний прокси-сервис, а не API Seasonvar.

Предустановка получает `https://p.thenewone.lol:8443/proxy.pac` отдельным анонимным клиентом. Пользовательский режим принимает HTTPS-адрес. Загрузка идёт напрямую с выбранными DNS и обходом, без текущего PAC, cookie аккаунта и HTTP-кеша. Ответ ограничен 2 МиБ; перенаправления загрузки не выполняются. Для «АнтиЗапрета» любая попытка запускает сохраняемый минутный лимит; у пользовательского PAC паузы между завершёнными запросами нет.

Сервис выбирает разновидность PAC по User-Agent. С собственным кратким заголовком приложение получило HTTP-прокси; с браузерным заголовком совместимости Firefox и идентификатором Seasonvar-TV получило HTTPS-прокси первым вариантом. Заголовок, адрес и лимиты находятся в `PacSettings`.

В исходном файле пользователя доменные правила содержали `seasonvar.ru`; отдельные домены постеров и видео могут определяться IP-правилами. Поэтому вычисляются все используемые домены, а не только домен сайта. `dnsResolve` получает IPv4 через выбранный нативный DNS. Неизвестный домен вычисляется по сохранённому файлу без повторной загрузки. Сеть и доступ JavaScript к файлам внутри WebView запрещены.

Поддерживаемые результаты: `HTTPS host:port; PROXY host:port; DIRECT`. Это упорядоченные резервные способы подключения. HTTPS-прокси использует TLS перед CONNECT, после которого отдельно проверяется TLS конечного сервера и закреплённые сертификаты приложения. HTTP-прокси тоже сохраняет TLS конечного сервера. Числовой адрес прокси не отправляется в DNS. Cookie сайта находятся внутри туннеля и не включаются в CONNECT. Фактические адреса прокси берутся только из неизменённого PAC и не сохраняются как ручная конфигурация.

Живая проверка: подготовлен оригинальный PAC; свежие страница сезона, JPEG-постер, первые 1024 байта MP4 и GitHub API доступны через выбранные правила, включая вариант с HTTPS-прокси первым в списке. Короткая проверка видео один раз достигла таймаута, повторная прошла; это ограничение диагностического бюджета, а не доказательство постоянной доступности сервиса. В эмуляторе воспроизведены «Наруто» и «Любовь, смерть и роботы»: визуально подтверждены меняющиеся кадры, пауза, перемотка и переходы серий/сезонов, без записи отметок аккаунта. Автономно проверены два слоя TLS, отказ недоверенного сертификата, резервирование, IP-правила и завершение процесса WebView.

Ограничения пользовательского PAC описаны в [ADR-0144](../adr/0144-custom-pac-source.md). В частности, скрипт получает HTTPS-origin без пути, DNS только для текущего пакета доменов, а результаты SOCKS и дополнительные браузерные функции не поддерживаются. Ошибка проверки не включает прямое соединение вместо правил. При неудачном обновлении сохраняется последняя проверенная копия; при первом включении сохраняется прежний режим прокси.

Пользователь сообщил об отправке авторам сервиса письма о приложении с аудиторией до тысячи пользователей и возможной будущей VPN-интеграцией. Ответ на дату проверки не сообщён. VPN, системные маршруты и настройки других приложений эта реализация не меняет.

В Android TV API 34 обнаружена неполная цепочка HTTPS-прокси к R46: первоначальный HTTP 200 получался через резервный HTTP-маршрут. Дополнение официальным перекрёстным сертификатом без изменения системных доверенных корней принято в [ADR-0145](../adr/0145-proxy-tls-chain-completion.md); живая проверка отдельно требует успешного соединения именно с первым HTTPS-прокси.

По [ADR-0146](../adr/0146-isolated-antizapret-policy.md) браузерный заголовок и дополнение цепочки относятся только к предустановке «АнтиЗапрет». Пользовательский PAC использует обычный User-Agent приложения и системный TLS; его копия разделена с предустановкой даже при одинаковом URL. Форма и исключение пользовательского PAC из минутного ограничения уточнены в [ADR-0147](../adr/0147-compact-pac-controls.md).
