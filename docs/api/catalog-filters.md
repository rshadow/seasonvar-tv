# Фильтры каталога и списков Seasonvar

Проверено агентом 06.11.2026: получены свежие анонимные HTML главной, `/resume`, `/?mode=top`, `/?mode=soon`, `/?mod=history` и официальные скрипты. Использованы `make site-fetch` и `make site-scripts` с доступом по [описанию доступа](access.md). Сырые страницы и скрипты находятся только в игнорируемом `build/site/`.

Начальная проверка подтверждала наличие элементов и исходников обработчиков. Применение непустых фильтров после входа дополнительно проверено 08.11.2026 для личных списков и реализовано в приложении. Жанр и период «Лучших сериалов» также проверены и реализованы; общий каталог и остальные подборки требуют отдельной проверки.

## Личные списки

Источник: [страница отметок](https://seasonvar.ru/resume) и [pg.marks.min.js](https://cdn.svstat.net/asset/js/pg.marks.min.js?25.4.1).

Под раскрывающейся областью фильтрации находятся два `select[data-change="mark-filter"]`:

| Параметр | Элемент | Значения |
| --- | --- | --- |
| Жанр | `name="marks-genre"` | ID жанра из `option[value]`, `all` снимает ограничение |
| Страна | `name="marks-country"` | Название страны из `option[value]`, `all` снимает ограничение |

Обработчик отправляет `POST /ajax.php`: `marks_filter=true`, `country=<value>`, `genre=<value>`. Ответ вставляется в `[data-result="marksf"]`, общий контейнер четырёх вкладок `marks-new`, `marks-nonew`, `marks-want`, `marks-watched`. Поэтому это общий фильтр личных списков, а не отдельная публичная подборка. В приложении «На чём остановились» составляется из первых двух вкладок.

Разметка присутствует и в гостевом ответе. Это не подтверждение авторизации и не основание считать личные списки пустыми. Авторизованный отбор подтверждён проверкой ниже. Справочники жанров и стран брать из свежих опций сайта, не закреплять их состав в коде. Настройка открытия в новой вкладке рядом с фильтрами относится к браузеру и фильтром не является.

### Проверка и реализация личных фильтров — 08.11.2026

Авторизованный эмулятор подтвердил варианты из свежего `/resume` и три запроса: `all/all`, отдельный жанр, отдельная страна. POST возвращает HTTP 200 и HTML-фрагмент четырёх `data-tabr` без `.headblock-menu` и `.pgs-marks`. Фильтрация сужает соответствующие вкладки; пустая вкладка остаётся в ответе. `all/all` совпал с исходной выдачей. Обычный GET `/resume` после фильтров сохранил все исходные записи, порядок и отметки: проверенные условия не сохранились на сервере. Набор опций в этой проверке: 22 значения жанра и 107 стран, включая варианты `all`; эти количества не являются ограничением протокола.

Приложение перед фильтрацией читает `/resume`, проверяет владельца и получает свежие опции. Неизвестные сохранённые значения заменяются `all`. При ограничениях отправляется POST, а фрагмент принимается только с полным набором четырёх вкладок в той же версии сессии; заголовок аккаунта в нём не выдумывается. При отсутствии ограничений достаточно обычного GET. Нераспознанный или пустой ответ не считается пустым списком; при ошибке структуры повторное авторизованное чтение позволяет отличить истёкшую сессию.

Одна [панель по ADR-0118](../adr/0118-shared-list-filter-panel.md) показывает жанр и страну для «На чём остановились», «Есть обновления», «Нет новых серий», «Хочу посмотреть», «Посмотрел». Черновик применяется по кнопке; «Сбросить» сразу загружает выдачу без ограничений по [ADR-0119](../adr/0119-filter-reset-and-action-buttons.md). Успешные условия сохраняются раздельно для раздела и владельца. Фильтры экрана не передаются в `resume()` для «Продолжить», прогресса или домашних лент. Запросов записи постоянных отметок или истории эта операция не выполняет.

Воспроизведение проверки: `make personal-filters-probe DEVICE=emulator-5554 PERSONAL_FILTERS_PROBE_OUT=<каталог-сессии>/personal-filters`. Требуется существующая сессия эмулятора; на приставке команда не работает. В отчёте только публичные варианты, структура, счётчики и результат сравнения; тела личных ответов и cookie не сохраняются. Автономные тесты используют синтетические фикстуры.

## Лучшие сериалы

Источник: [отдельная страница](https://seasonvar.ru/?mode=top), включая её встроенный JavaScript. Это не боковая AJAX-подборка «Топ» (`mode=pop`).

| Условие | Элементы и параметры из исходника |
| --- | --- |
| Жанр | `.gen`, query `genre=<ID>`; пустое значение без ограничения |
| Период популярности | `.per`, query `period=1`, `7`, `31`: день, неделя, месяц; на проверенной странице выбран день |
| Качество | `fhdTop` → `filterTop[fhd]`, `hdTop` → `filterTop[hd]` |
| Субтитры | `subTop` → `filterTop[sub]` |
| Отечественные сериалы | `engTop` → `filterTop[eng]`; флаг RU включён по умолчанию, параметр инвертирован: при включении пустой, при выключении `yes` |
| Доступность в стране | `blockTop` → `filterTop[block]` |
| Сериалы, которые пользователь смотрит | `markTop` → `filterTop[mark]` |
| Ранее просматривавшиеся сериалы | `historyTop` → `filterTop[history]` |
| Чёрный список | `notwatchedTop` → `filterTop[nw]` |

Жанр и период меняют URL `/?mode=top&genre=…&period=…`. Дополнительные флаги отправляются POST на текущий URL в объекте `filterTop`; значения `yes` либо пустая строка. Применение и ограничения авторизации проверены ниже. `history` не приравнивать без проверки к постоянному статусу «Посмотрел».

### Повторная проверка жанра и периода — 08.11.2026

Анонимные GET `/?mode=top` и `/?mode=top&genre=17&period=7` возвращают полные страницы, а не AJAX-фрагменты. В первой серверный скрипт отмечает `.per[value=1]`, во второй — `.gen option[value=17]` и `.per[value=7]`; HTML-атрибуты `selected` у жанра при этом остаются начальными. Эффективный выбор надо учитывать по инициализации страницы, а не только по HTML-атрибутам. Справочник содержит 21 жанр и пустое значение «Любой жанр»; периоды — 1, 7, 31. Состав справочника не фиксировать в приложении. Дополнительно проверен `genre=18&period=31`: скрипт отмечает аниме и месяц. Приложение проверяет соответствие серверного выбора запросу и разделяет кэш по жанру и периоду; сброс возвращает любой жанр и день, см. [ADR-0121](../adr/0121-best-list-genre-and-period.md).

### Проверка дополнительных переключателей — 08.11.2026

Проверка агентом: POST на `/?mode=top&period=1` с восемью полями `filterTop[fhd|hd|sub|eng|block|mark|history|nw]`, каждое `yes` либо пустая строка. Ответ — только элементы `.pgs-search-wrap`, без `#search-res` и без полей жанра/периода. При пустом результате сервер присылает один `.pgs-msg` с текстом «Сожалеем, по вашему запросу ничего не найдено»; это подтверждено сочетанием `genre=10`, `fhd=yes`, `sub=yes`, `eng=yes`. Пустое тело или произвольное сообщение не считать успешной пустой выдачей. Анонимно отдельные `fhd`, `hd`, `sub`, `eng`, `block` меняют состав выдачи. `eng=yes` исключает отечественные; галочка RU на сайте инвертирована. На публичных страницах «Купертино» и «Айда!» найден `poster.fhd`, у исключённой Full HD-фильтром «Ставки на любовь» такого признака нет. Флаг `block` исключил две позиции из первоначальной сотни; доступность определяет сайт для страны запроса, это не гарантия воспроизведения.

Живой тест эмулятора проверил гостевой клиент и существующую сессию. При применении личных ограничений приложение предварительно читает выбранную страницу через репозиторий аккаунта и проверяет владельца; истёкшая сессия не считается успешным применением проигнорированных флагов. У гостя `mark`, `history`, `nw` оставили исходную выдачу. После входа `mark` и `history` исключали часть совпадений с названиями личного списка (6 → 1 и 6 → 2 соответственно). Названия использовались только в исследовательском сравнении в памяти; приложение фильтрует серверным запросом. Отдельного положительного примера чёрного списка в аккаунте не установлено, поэтому проверена форма `nw` и валидный ответ, а не исключение конкретного чёрного сериала. Обычные GET до и после всех запросов совпали у гостя и после входа; постоянные отметки также остались прежними.

Повторить: `make best-filters-probe DEVICE=emulator-5554 BEST_FILTERS_PROBE_OUT=<каталог-сессии>/best-filters`. В отчёте только агрегированные счётчики и признаки, без тел личных ответов, cookie, названий и ID пользователя.

## Общий фильтр каталога

Источник: [главная](https://seasonvar.ru/) и [main.min.js](https://cdn.svstat.net/asset/js/main.min.js?25.4.1), функции `fChange` и `fShowResult`.

| Группа | Возможности из разметки |
| --- | --- |
| Страна | Выбор страны и исключение выбранной; все, русские или зарубежные сериалы |
| Названия | Оригинальное название для зарубежных сериалов; отключено для остальных групп |
| Жанры | Несколько условий через добавление строки, включение и исключение жанров |
| Год | Равен, больше или меньше выбранного |
| Количество сезонов | Равно, больше или меньше выбранного |
| Рейтинг | КиноПоиск или IMDb; равен, больше или меньше выбранного |
| Перевод | Выбор озвучки из актуального списка сайта |
| Анонсы | Условие для сериалов, ещё ожидаемых на сайте |
| Качество и субтитры | Full HD/1080, HD, наличие субтитров |
| Ограничения показа | Доступность в стране, смотримые сериалы, история просмотра, чёрный список |
| Сортировка | Название, КиноПоиск, IMDb, год, популярность, добавление |

`fChange` собирает объект `filter` и отправляет `POST /index.php` с `countFilter=yes` для счётчика. `fShowResult` отправляет тот же `filter` без `countFilter` для выдачи в `[data-filter="result"]`. Жанры: `quotG`/`notQuotG`; страны: `quotC`/`notQuotC`; год: `quotY`/`moreY`/`underY`; сезоны: `quotS`/`moreS`/`underS`; рейтинг: `quotR`/`moreR`/`underR` и `rait`; перевод: `quotT`; сортировка: `sortTo`. Дополнительные поля: `only`, `engName`, `hd`, `fhd`, `sub`, `block`, `history`, `mark`, `nw`, `exp`. Значения сортировки: `name`, `kinopoisk`, `imdb`, `god`, `view`, `newest`.

Общий фильтр виден также в боковой панели других страниц. Его наличие рядом со списком не означает, что он фильтрует этот список: обработчик отдельно выводит результаты каталога.

## Что пока не подтверждено

- **Боковые «Обновления», «Топ», «Новинки».** В текущем HTML отдельных элементов фильтрации не найдено. `main.min.js` при загрузке вкладки всегда отправляет `ganre=""`, `country=""`, `block="0"`, `main="1"` в `POST /ajax.php?mode=new|pop|newest`. Наличие этих полей не подтверждает ни интерфейс фильтров, ни работу непустых значений. Написание `ganre` сохранять именно для этого запроса; в личных списках и «Лучших сериалах» используется `genre`.
- **«Сегодня» и «Анонсы».** Собственных фильтров в полученной разметке не найдено. Общий каталог в боковой панели не считать фильтром текущей ленты.
- **«История просмотров».** [Гостевой запрос](https://seasonvar.ru/?mod=history) возвращает требование входа вместо содержимого. Отсутствие фильтров в этом ответе ничего не говорит об авторизованной странице; проверить её отдельно.
- **Состояние фильтров на сервере.** У личных фильтров и «Лучших сериалов» обычные GET после фильтрации не изменились; для общего каталога сохранение условий в cookie/сессии и независимость вкладок пока не проверены. Перед реализацией убедиться, что фильтрация не меняет постоянные отметки и другие списки пользователя.

## Требования к клиенту

Жанр и страна личных списков, жанр, период и дополнительные переключатели «Лучших сериалов» реализованы; остальные возможности запланированы. Состав и статус задач — в [TODO](../../TODO.md#фильтры-списков).

- **Личные списки: жанр и страна** — реализованы фильтры страницы `/resume` в «Есть обновления», «Нет новых серий», «Хочу посмотреть» и «Посмотрел». Они применяются и к «На чём остановились», который объединяет первые два списка. Есть варианты без ограничения жанра и страны.
- **«Лучшие сериалы»: жанр и период** — выбирать жанр и популярность за день, неделю или месяц. Не смешивать с боковой подборкой «Топ».
- **«Лучшие сериалы»: дополнительные переключатели** — Full HD/1080, HD, субтитры, отечественные сериалы, доступность в стране, показ/скрытие смотримых сериалов, просмотренных ранее и чёрного списка. Реализованы по [ADR-0122](../adr/0122-best-list-switches.md); личные переключатели доступны после входа.
- **Каталог: основные и расширенные фильтры** — страна с включением/исключением; русские/зарубежные/все сериалы; несколько жанров с включением/исключением; год, число сезонов и рейтинг с условиями «равно», «больше», «меньше»; источник рейтинга КиноПоиск/IMDb; озвучка; анонсированные сериалы; Full HD/HD и субтитры. Добавить переключатели доступности, смотримых сериалов, истории просмотра и чёрного списка. Для зарубежных сериалов предусмотреть вывод оригинальных названий, как на сайте.
- **Каталог: сортировка** — по названию, КиноПоиску, IMDb, году, популярности и времени добавления.
- **Боковые «Обновления», «Топ», «Новинки»: уточнить поддержку** — в запросах есть `ganre`, `country`, `block`, но отдельные элементы фильтрации на текущих страницах не найдены. Проверить непустые параметры и наличие соответствующего интерфейса сайта перед включением в план реализации этих подборок.
- **Остальные списки: уточнить отдельные фильтры** — в «Сегодня» и «Анонсах» не найден собственный набор; общий фильтр боковой панели выдаёт каталог. Страницу «История просмотров» дополнительно проверить после входа: гостевой ответ её содержимое не показывает.
- **Управление фильтрами с пульта** — показывать активные ограничения, дать сброс и сохранять выбор при возврате; состояние каждого списка учитывать отдельно.
