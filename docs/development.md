# Локальная разработка

Приложение содержит «Сегодня», «Настройки → Сеть» и «О программе». Для публичной ленты нужен доступ к Seasonvar; компьютерный сервер, аккаунт и подключение к приставке не требуются.

Все команды запускаются из корня проекта через [Makefile](../Makefile).

## Подготовка другого компьютера

Требуются Python 3.12+, make и curl. Для локального эмулятора также нужна доступная аппаратная виртуализация.

~~~bash
make bootstrap
make licenses
make deps
make avd
~~~

`make bootstrap` скачивает зафиксированные инструменты в `.tools`. Это игнорируемые локальные файлы; системный JDK и SDK не заменяются. Архивы берутся из Google и Eclipse Adoptium и проверяются по размерам и контрольным суммам из [toolchain.lock.json](../toolchain.lock.json).

`make licenses` нужен, если лицензии SDK ещё не приняты. При наличии ранее принятых лицензий в пользовательском SDK bootstrap переиспользует их на этом же компьютере.

Подготовлены наборы для macOS Apple Silicon, macOS Intel и Linux x86_64. На Linux могут дополнительно потребоваться системные библиотеки графики/звука и доступ к KVM; их состав зависит от дистрибутива. Windows-разработка отдельно не настроена.

Загрузка занимает примерно 1,5–2 ГБ; распакованные инструменты и образ требуют дополнительного места. Кэш архивов по умолчанию — `~/.cache/seasonvar/downloads`; его можно указать через `BOOTSTRAP_CACHE`:

~~~bash
make bootstrap BOOTSTRAP_CACHE=/path/to/download-cache
~~~

## Посмотреть приложение

В первом терминале:

~~~bash
make emulator
~~~

Откроется окно Android TV. После загрузки во втором терминале:

~~~bash
make run
~~~

По умолчанию используется `emulator-5554`. Если эмуляторов несколько, выбрать нужный из `make devices`:

~~~bash
make devices
make run DEVICE=emulator-5556
~~~

Управление: щёлкнуть в окно эмулятора, затем использовать Enter/OK для выбора. Кнопки приложения также реагируют на клик мышью. В меню стрелки сразу показывают выбранный раздел; OK или стрелка вправо переводят фокус в его содержимое. В ленте стрелки перемещают фокус, OK открывает описание сериала. В полном описании стрелки вверх/вниз прокручивают текст. Esc и «Назад» пульта закрывают карточку/диалог и возвращают фокус в меню текущего раздела. Два нажатия в пределах 500 мс закрывают приложение; удержание клавиши не считается двойным нажатием. Другая клавиша отменяет ожидание второго нажатия. Стрелка влево из настроек переводит фокус в меню; в «О программе» фокус остаётся в меню.

`make avd` настраивает аппаратную клавиатуру и сенсорный ввод для кликов мышью; `make emulator` применяет эту настройку перед запуском. Значения закреплены в `toolchain.lock.json`. Команда запуска также включает `-use-keycode-forwarding`: эмулятор получает коды физических клавиш напрямую. Раскладку для ввода текста в этом режиме выбирают внутри Android. Если окно уже открыто со старой конфигурацией, перезапустить его:

~~~bash
make emulator-restart
~~~

После загрузки в другом терминале выполнить `make run`. Данные эмулятора при перезапуске сохраняются.

Программная имитация пульта:

~~~bash
make key KEY=DPAD_CENTER
make key KEY=BACK
make key KEY=ESCAPE
make key-double KEY=BACK
make key KEY=BACK KEY_ARGS=--longpress
make tap X=400 Y=670
~~~

## Сборка и проверки

| Команда | Назначение |
| --- | --- |
| `make help` | Доступные команды |
| `make doctor` | Версии JDK, Gradle и ADB |
| `make deps` | Подготовка зависимостей и первая сборка |
| `make build` | Debug APK |
| `make test` | Задача unit-тестов Gradle |
| `make lint` | Android Lint |
| `make check` | Сборка, задача unit-тестов и Lint |
| `make restart` | Перезапуск установленного приложения без сборки |
| `make clean` | Удаление результатов сборки через Gradle |

APK: `app/build/outputs/apk/debug/app-debug.apk`.

В `make test` и `make check` входят 23 JVM-тестов парсера/кэша/TLS-фрагментации/двойного нажатия и 10 автономных Python-тестов загрузчика. Интернет и аккаунт им не нужны. Управление и реальную сеть проверяем отдельно в эмуляторе.

При проверке навигации выбрать «Настройки» в меню: сетевые параметры должны появиться сразу. Стрелка вправо или OK переводит фокус на галочку обхода; вниз — на выбор DNS, вверх — обратно. Подзаголовок «Сеть» не должен получать фокус. Аппаратная кнопка «Назад» и стрелка влево из параметров возвращают фокус на «Настройки» в меню без открытия «Сегодня». Отдельно проверить вход мышью, возврат из диалога DNS и переключение разделов стрелками в меню. Одиночные Esc/Back должны закрывать диалог с возвратом в меню текущего раздела; быстрые двойные нажатия — закрывать приложение даже при переходе из диалога в главное окно.

Для подробного вывода Gradle:

~~~bash
make build GRADLE_ARGS=--info
~~~

## Логи и отладчик

~~~bash
make logs
make logs LOG_ARGS=-d
make debug
make layout
~~~

`make logs` показывает только процесс приложения, `LOG_ARGS=-d` выводит накопленные записи и завершает команду. `make debug` пробрасывает JDWP на локальный порт 8700 и позволяет подключить JDK-отладчик командой `make attach`.

Для удобной пошаговой отладки можно открыть проект в Android Studio: выбрать Gradle JDK `.tools/jdk` и SDK `.tools/android-sdk`, затем использовать Attach debugger to Android process для `ru.seasonvar.tv`. Android Studio для сборки и работы окна эмулятора не обязателен.

Снимок экрана:

~~~bash
make screenshot OUT=/path/to/menu.png
~~~

## Настройка интерфейса

Цвета, отступы и размеры компонентов задаются в [themes.xml](../app/src/main/res/values/themes.xml). Роли цветов Compose, набор стилей текста и типизированные размеры — в [SeasonvarTheme.kt](../app/src/main/java/ru/seasonvar/tv/ui/theme/SeasonvarTheme.kt). После изменения выполнить `make run`. Источники фирменной палитры и правила — [ADR-0008](adr/0008-centralized-ui-theme.md); `make site-styles` загружает CSS для повторной сверки.

## Сеть приложения

На общем экране «Настройки» под текстовым подзаголовком «Сеть» расположены две независимые настройки: галочка «Обход блокировок» (по умолчанию включена) и DNS («Системный» / «Quad9 DoH», по умолчанию Quad9 DoH). Они хранятся в приватных SharedPreferences `network`: ключ `dpi_bypass` и строковый `dns_provider` (`system` / `quad9_doh`). Если ключ DNS ещё отсутствует, используется Quad9 DoH; сохранённая галочка остаётся прежней.

Выбор применяется к новым запросам HTML и Coil, а список «Сегодня» обновляется. При ошибке сети остаётся кэш текущего дня с предупреждением. Сертификаты проверяются во всех сочетаниях; детали — [ADR-0011](adr/0011-network-bypass-setting.md) и [ADR-0012](adr/0012-dns-provider-setting.md). Для добавления провайдера расширить `DnsProvider`, UI-название и соответствующий резолвер в `NetworkClients`.

## Получение страниц сайта

`make site-fetch` сохраняет публичную главную Seasonvar в `build/site/index.html` с использованием проверенной DPI-стратегии и Quad9 DoH. Параметры, поиск и результаты проверки — в [docs/api/access.md](api/access.md). Проверки загрузчика запускаются через `make site-test` и входят в `make test` и `make check`.

## Физическая приставка

Подключить устройство к ADB и найти его серийный идентификатор через `make devices`. Затем использовать `make run DEVICE=SERIAL`, заменив `SERIAL` значением из списка. IP приставки в проекте не закрепляется.

Для этого прототипа физическая приставка — дополнительная проверка. Производительность готового клиента измеряется на Ugoos согласно [ADR-0003](adr/0003-performance-principles.md).

## Проверенное окружение

На 2026-11-01 сборка и запуск через `make run` проверены на macOS ARM64, Apple M4 Pro, в локальном Android TV API 34. Проверены «Сегодня» с 83 обновлениями, постерами и описанием, сетевые настройки, все четыре сочетания DNS/обхода в UI и сохранение обоих параметров после остановки процесса. Передачу клавиш из окна эмулятора проверять отдельно: ADB не заменяет клавиатуру пользователя. `make check` прошёл: 23 JVM-тестов, 10 Python-тестов, сборка и Lint без ошибок. Lint оставляет предупреждения о версиях зависимостей, ТВ-баннере и настройках Android. Остальные подготовленные платформы пока не проверялись.

При проверке `android layout` Play Protect заблокировал вспомогательный Android CLI Instrumentation Server с сообщением о старой версии Android. Для сборки и запуска Seasonvar TV он не требуется. Цель `make layout` использует встроенный UI Automator через ADB.

## Скиллы и принятые решения

Скиллы хранятся только в [.agents/skills](../.agents/skills/README.md). Их назначение и версии перечислены там; правила применения — в [AGENTS.md](../AGENTS.md).

- [ADR-0002](adr/0002-native-kotlin-compose-media3.md): Kotlin, Compose for TV и Media3; плеер будет подключён при реализации воспроизведения.
- [ADR-0004](adr/0004-project-local-skills.md): локальное подключение всех проектных скиллов.
- [ADR-0005](adr/0005-reproducible-local-development.md): Makefile и воспроизводимый локальный цикл.

Физический Esc из окна эмулятора проверять отдельно от `make key KEY=ESCAPE`: ADB обходит обработку клавиатуры macOS и Qt. В debug-сборке тег `SeasonvarInput` выводит только события Esc/Back и результат возврата, без текста остальных клавиш.
