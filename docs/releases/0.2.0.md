- Первый выпуск приложения для Android TV с управлением пультом.
- Добавлены каталоги сериалов, текстовый и голосовой поиск.
- Доступен выбор сезонов, озвучек и серий.

- Добавлены вход в аккаунт, личные списки и история просмотров.
