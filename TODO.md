# TODO: Seasonvar TV

План разделов левого меню и механик приложения. Пункт отмечается готовым, когда работает в приложении и доступен с пульта. Реализованы «Сегодня», «Обновления», «Топ», «Новинки», «Лучшие сериалы», «Анонсы», «Настройки» с группой «Сеть» и «О программе».

Начинаем с раздела «Сегодня» с описанием выбранного сериала сверху и горизонтальной лентой миниатюр снизу, согласно [ADR-0006](docs/adr/0006-tv-navigation-and-content-layout.md).

## Общедоступные разделы — делаем сначала

Эти разделы работают без входа в аккаунт Seasonvar.

### Основные разделы

- [x] **Сегодня** — серии, добавленные сегодня на главную Seasonvar, в порядке сайта.
- [x] **Поиск** — лупа над меню, текстовый и системный голосовой ввод, JSON-результаты по сезонам и открытие описания. Воспроизведение — отдельная задача.
- [ ] **Каталог** — фильтр сериалов по стране, жанру, году и рейтингу, сортировка результатов; сохранять выбранные фильтры при возврате в каталог.

### Подборки сайта

- [x] **Обновления** — одноимённая подборка обновлённых сериалов из боковой панели сайта.
- [x] **Топ** — популярные сериалы из подборки «Топ».
- [x] **Новинки** — одноимённая подборка новых сериалов сайта.
- [x] **Лучшие сериалы** — раздел сайта «Лучшие сериалы».
- [x] **Анонсы** — список «Скоро на нашем сайте»: ожидаемые сериалы и сезоны в порядке страницы `/?mode=soon`, с ориентировочными датами и описаниями. [ADR-0070](docs/adr/0070-announcements-section.md).
- [ ] **Случайный сериал** — выбор случайного сериала средствами сайта, открытие его карточки и кнопка «Другой» для следующего предложения.

«Лучшие сериалы» — отдельная страница `/?mode=top` со своей выдачей и ссылками, отличающаяся от AJAX-«Топа». «Сегодня» фильтруется по дате, «Обновления» повторяет боковую подборку сайта без фильтра по дню.

### Служебные разделы

- [x] **Настройки** — группы «Приложение» и «Сеть» без отдельных переходов; «При запуске» выбирает первый раздел. Сеть: независимые сохранённые настройки обхода блокировок и DNS («Системный» / «Quad9 DoH»); по умолчанию обход включён, DNS — Quad9 DoH. Применяются к страницам и постерам. Другие настройки добавляются вместе с соответствующими функциями.
- [x] **При запуске** — выбор первого раздела в настройках приложения; [ADR-0045](docs/adr/0045-start-page-setting.md).
- [x] **О программе** — название, версия приложения, ссылка GitHub, автоматическая проверка обновлений при входе и установка через Android; [ADR-0074](docs/adr/0074-in-app-github-updates.md).

## Разделы после входа

Реализованы вход, аватар и личные списки и история просмотров. Разметка описана в ADR-0034, разделение списков — в [ADR-0036](docs/adr/0036-personal-lists.md).

### Подготовка

- [x] **Вход в аккаунт** — авторизация на Seasonvar и сохранение сессии.

### Личные списки

Данные берём из аккаунта Seasonvar. Без входа предлагаем авторизоваться; истёкшую сессию показываем отдельно от пустого списка.

- [x] **На чём остановились** — список из аккаунта; карточки и просмотр доступны, чтение/запись точного времени аккаунта — следующий этап.
- [x] **Есть обновления** — новые серии в личном списке пользователя.
- [x] **Нет новых серий** — сериалы личного списка без непросмотренных обновлений.
- [x] **Хочу посмотреть** — список запланированных к просмотру сериалов.
- [x] **Посмотрел** — список просмотренных сериалов.
- [x] **История просмотров** — список сайта `/?mod=history` с сезоном, серией, датой записи и подгрузкой следующих страниц; [ADR-0039](docs/adr/0039-account-viewing-history.md).

### Управление аккаунтом

- [x] **Аккаунт** — сведения о текущем пользователе и выход.

## Общие сценарии переходов

- [x] **Открытие карточки с известными параметрами** — из любого раздела выбирать известные сезон, серию и озвучку; применять совместимое локальное продолжение только к незаданным параметрам. Парсеры заполняют единую частичную модель `SeriesEntry`; общий механизм выбирает серию и озвучку, недоступная серия требует ручного выбора, отсутствующая озвучка заменяется стандартной по [ADR-0042](docs/adr/0042-standard-translation-fallback.md). [ADR-0040](docs/adr/0040-details-entry-context.md).

- [x] **Прогресс сезонов и серий** — в конце строки управления «Прогресс: сезоны N из M · серии K из L»: сезон отметки из общего количества сезонов и отметка серий выбранного сезона; данные хранятся раздельно в общей модели. [ADR-0043](docs/adr/0043-account-progress-in-controls.md).
- [x] **Автоматическая отметка аккаунта** — позиция раз в минуту, при паузе/выходе/смене серии; просмотренная серия на 90%, защита от краткого запуска и повтор при сбое. [ADR-0056](docs/adr/0056-automatic-account-playback-marks.md).
- [x] **Удаление из личных списков** — удержание OK по миниатюре и кнопка в полной карточке, общее подтверждение, удаление отметки выбранного сезона с проверкой результата. История и локальное продолжение сохраняются. [ADR-0057](docs/adr/0057-remove-account-list-marks.md).
- [x] **Добавление в личные списки и смена статуса** — иконка закладки в полной карточке и меню удержания OK во всех подборках после входа; четыре статуса сайта, подтверждение повторным чтением и корзина с подтверждением. [ADR-0081](docs/adr/0081-account-list-status-actions.md).
- [x] **Предпочитаемые озвучки** — упорядоченный список в настройках с добавлением, перестановкой и удалением. Свежий справочник сайта при каждом открытии добавления; сохраняются только предпочтения и их порядок. Выбирается первая доступная студия, иначе стандартная; контекст и продолжение имеют приоритет. [ADR-0076](docs/adr/0076-translation-priority-list.md).


## Уточнения плана

- Названия публичных подборок, поиск и фильтр сверены с главной страницей Seasonvar. Основание для личных разделов — [описание запросов сайта](docs/api/web-api.md); чтение вкладок и автоматическое сохранение позиции/просмотренной серии реализованы; ручное изменение статусов остаётся отдельной задачей.
- Группы в этом списке помогают планировать работу. Вложенность и окончательный порядок пунктов уточняются при реализации меню.

## Поиск

- [x] **История поисковых запросов** — до 20 последних запросов на устройстве, без дублей; повтор одним OK, очистка и сохранение между перезапусками. [ADR-0082](docs/adr/0082-local-search-history.md).

## Плеер

- [x] **Предыдущая и следующая серия** — ручные переходы внутри сезона и озвучки, кнопки стандартной панели и пульта; [ADR-0046](docs/adr/0046-player-episode-navigation.md).
- [x] **Автопереход к следующей серии** — сразу после окончания видео в пределах сезона и озвучки, без промежуточной панели; включён по умолчанию. Финальная панель появляется только без следующей серии. [ADR-0080](docs/adr/0080-direct-episode-autoplay.md).
- [ ] **Автопереход между сезонами** — после последней серии загружать следующий сезон и выбирать подходящую озвучку.


## Общие элементы каталога

- [x] **Метка «Смотрю»** — значок паузы по svico-mwatch сайта на постерах, без отдельного фокуса и с обновлением после изменения серверной отметки. [ADR-0072](docs/adr/0072-site-watching-badge.md).

- [ ] **Выбор представления каталога** — переключение между текущей лентой с описанием и сеткой постеров. Развивает будущий вариант интерфейса из [ADR-0006](docs/adr/0006-tv-navigation-and-content-layout.md).

## Главный экран Android TV

- [ ] **Ленты на главном экране Android TV** — показывать списки Seasonvar на системном главном экране. Дать пользователю выбор списков в настройках и возможность отключать их показ. По умолчанию добавлять «Сегодня», если это допускает платформа; проверить поддержку на целевых устройствах и необходимость подтверждения пользователя.
