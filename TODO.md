# TODO: меню Seasonvar TV

План разделов левого меню. Пункт отмечается готовым, когда работает в приложении и доступен с пульта. Реализованы «Сегодня», «Обновления», «Топ», «Новинки», «Лучшие сериалы», «Настройки» с группой «Сеть» и «О программе».

Начинаем с раздела «Сегодня» с описанием выбранного сериала сверху и горизонтальной лентой миниатюр снизу, согласно [ADR-0006](docs/adr/0006-tv-navigation-and-content-layout.md).

## Общедоступные разделы — делаем сначала

Эти разделы работают без входа в аккаунт Seasonvar.

### Основные разделы

- [x] **Сегодня** — серии, добавленные сегодня на главную Seasonvar, в порядке сайта.
- [x] **Поиск** — лупа над меню, текстовый и системный голосовой ввод, JSON-результаты по сезонам и открытие описания. Воспроизведение — отдельная задача.
- [ ] **Каталог** — фильтр сериалов по стране, жанру, году и рейтингу, сортировка результатов.

### Подборки сайта

- [x] **Обновления** — одноимённая подборка обновлённых сериалов из боковой панели сайта.
- [x] **Топ** — популярные сериалы из подборки «Топ».
- [x] **Новинки** — одноимённая подборка новых сериалов сайта.
- [x] **Лучшие сериалы** — раздел сайта «Лучшие сериалы».
- [ ] **Скоро на нашем сайте** — сериалы, анонсированные на Seasonvar.
- [ ] **Случайный сериал** — выбор случайного сериала средствами сайта.

«Лучшие сериалы» — отдельная страница `/?mode=top` со своей выдачей и ссылками, отличающаяся от AJAX-«Топа». «Сегодня» фильтруется по дате, «Обновления» повторяет боковую подборку сайта без фильтра по дню.

### Служебные разделы

- [x] **Настройки** — группа «Сеть» без отдельного перехода: независимые сохранённые настройки обхода блокировок и DNS («Системный» / «Quad9 DoH»); по умолчанию обход включён, DNS — Quad9 DoH. Применяются к страницам и постерам. Другие настройки добавляются вместе с соответствующими функциями.
- [x] **О программе** — название, версия приложения и возврат в меню.

## Разделы после входа

Вход, аватар и первый личный раздел проверены на аккаунте пользователя; актуальная разметка описана в ADR-0034. Остальные личные вкладки добавим отдельно.

### Подготовка

- [x] **Вход в аккаунт** — авторизация на Seasonvar и сохранение сессии.

### Личные списки

Данные берём из аккаунта Seasonvar. Без входа предлагаем авторизоваться; истёкшую сессию показываем отдельно от пустого списка.

- [x] **На чём остановились** — список из аккаунта; карточки и просмотр доступны, чтение/запись точного времени аккаунта — следующий этап.
- [ ] **Есть обновления** — новые серии в личном списке пользователя.
- [ ] **Нет новых серий** — сериалы личного списка без непросмотренных обновлений.
- [ ] **Хочу посмотреть** — список запланированных к просмотру сериалов.
- [ ] **Посмотрел** — список просмотренных сериалов.

### Управление аккаунтом

- [x] **Аккаунт** — сведения о текущем пользователе и выход.

## Уточнения плана

- Названия публичных подборок, поиск и фильтр сверены с главной страницей Seasonvar. Основание для личных разделов — [описание запросов сайта](docs/api/web-api.md); их поведение ещё нужно проверить после входа.
- Группы в этом списке помогают планировать работу. Вложенность и окончательный порядок пунктов уточняются при реализации меню.
- Выбор между лентой с описанием и плиткой сериалов рассматривается на будущее. На первом этапе реализуется только выбранная лента, как записано в ADR-0006.
