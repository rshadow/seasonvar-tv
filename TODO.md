# TODO: меню Seasonvar TV

План разделов левого меню. Пункт отмечается готовым, когда работает в приложении и доступен с пульта. Реализованы «Сегодня», «Настройки → Сеть» и «О программе».

Начинаем с раздела «Сегодня» с описанием выбранного сериала сверху и горизонтальной лентой миниатюр снизу, согласно [ADR-0006](docs/adr/0006-tv-navigation-and-content-layout.md).

## Общедоступные разделы — делаем сначала

Эти разделы работают без входа в аккаунт Seasonvar.

### Основные разделы

- [x] **Сегодня** — серии, добавленные сегодня на главную Seasonvar, в порядке сайта.
- [ ] **Поиск** — поиск сериалов по названию и переход к результату.
- [ ] **Каталог** — фильтр сериалов по стране, жанру, году и рейтингу, сортировка результатов.

### Подборки сайта

- [ ] **Обновления** — одноимённая подборка обновлённых сериалов из боковой панели сайта.
- [ ] **Топ** — популярные сериалы из подборки «Топ».
- [ ] **Новинки** — одноимённая подборка новых сериалов сайта.
- [ ] **Лучшие сериалы** — раздел сайта «Лучшие сериалы».
- [ ] **Скоро на нашем сайте** — сериалы, анонсированные на Seasonvar.
- [ ] **Случайный сериал** — выбор случайного сериала средствами сайта.

Перед реализацией сверить различия «Топ» и «Лучшие сериалы», а также «Сегодня» и «Обновления»: одинаковые выдачи можно объединить в один пункт после проверки.

### Служебные разделы

- [x] **Настройки → Сеть** — независимые сохранённые настройки обхода блокировок и DNS («Системный» / «Quad9 DoH»); по умолчанию обход включён, DNS — Quad9 DoH. Применяются к страницам и постерам. Другие настройки добавляются вместе с соответствующими функциями.
- [x] **О программе** — название, версия приложения и возврат в меню.

## Разделы после входа — делаем позже

К личным разделам переходим после реализации и проверки входа. Сейчас работаем с общедоступными страницами.

### Личные списки

Данные берём из аккаунта Seasonvar. Без входа предлагаем авторизоваться; истёкшую сессию показываем отдельно от пустого списка.

- [ ] **Нет новых серий** — сериалы личного списка без непросмотренных обновлений.
- [ ] **Хочу посмотреть** — список запланированных к просмотру сериалов.

### Управление аккаунтом

## Уточнения плана

- Названия публичных подборок, поиск и фильтр сверены с главной страницей Seasonvar. Основание для личных разделов — [описание запросов сайта](docs/api/web-api.md); их поведение ещё нужно проверить после входа.
- Группы в этом списке помогают планировать работу. Вложенность и окончательный порядок пунктов уточняются при реализации меню.
- Выбор между лентой с описанием и плиткой сериалов рассматривается на будущее. На первом этапе реализуется только выбранная лента, как записано в ADR-0006.
